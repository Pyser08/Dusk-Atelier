# Dusk Atelier

RisuAI 용 모듈·캐릭터 관리·업데이트 플러그인입니다.
- 모듈 켜기·끄기, 폴더, 순서, 연결, 프리셋, 편집, 에셋 관리
- 봇·모듈의 빠른 업데이트와 패치(.rbupatch) 배포
- 다른 관리 플러그인과 저장 칸을 나눠 쓰지 않습니다. 함께 설치해도 서로의 설정·꺼진 모듈·순서를 건드리지 않습니다.

## 설치와 이전
1. RisuAI 설정 → 플러그인에서 `dusk_atelier.js`를 추가합니다. API 3.0을 씁니다.
2. 예전 이름(**Dusk Manager**)으로 설치했다면 그 플러그인은 지우고 `dusk_atelier.js`를 새로 추가하세요. 설정·폴더·백업 기록은 같은 저장소를 쓰므로 그대로 이어집니다.

## 열기
- 왼쪽 사이드바(햄버거 메뉴)의 **Dusk Atelier**를 누릅니다.
- 또는 설정 메뉴에서 엽니다.
- 창 안 어디에 파일을 끌어다 놓아도 바로 가져옵니다.

## 기능

### 모듈 탭
- **목록**
  - 검색: 이름, 로어북 키, 정규식·트리거 이름으로 찾습니다.
  - 필터: 전체, 켜짐, 꺼짐, 전역, LLA, MCP
- **켜기/끄기**
  - 끈 모듈은 RisuAI 목록에서 빠지고 보관함에 들어갑니다. 끈 뒤 8초 동안 되돌릴 수 있습니다.
  - 에셋이 있는 모듈은 끌 수 없습니다. 끄면 RisuAI의 에셋 정리로 파일이 지워질 수 있기 때문입니다.
- **폴더**
  - 모듈 목록을 폴더로 묶습니다. 접기·펴기, 폴더 색, 이름 바꾸기, 순서 바꾸기를 할 수 있습니다.
  - 폴더를 만들 때 넣을 모듈을 바로 고릅니다(찾기·모두 고르기). 폴더 메뉴의 "넣을 모듈 고르기…"로 나중에 바꿉니다.
  - 모듈을 끌어서 폴더에 넣습니다.
- **이름 색**
  - 모듈마다 이름 색을 정합니다. 어느 밝기에서도 읽히도록 진하기를 자동으로 맞춥니다.
- **순서**
  - 줄 왼쪽 손잡이(점 여섯 개)를 잡고 끕니다. 모바일에서도 됩니다. PC는 줄 전체를 끌어도 되고, 키보드로 Alt+↑/↓를 누릅니다.
  - 메뉴에서 위로/아래로를 고를 수도 있습니다.
- **연결**
  - 글로벌 활성화
  - 페르소나별 자동 활성화: 그 페르소나를 쓰는 동안 지금 캐릭터에 자동으로 넣습니다.
  - 캐릭터별 연결
  - 지금 채팅에서 해제
- **메뉴**
  - 편집, 에셋 관리
  - .risum 내보내기, JSON 복사
  - 내 수정만 내보내기, 패치 적용
  - 이름 바꾸기
  - 삭제: 지우기 전 상태를 백업해서 되살릴 수 있습니다.

### 플러그인 탭
- **목록**: 설치한 플러그인을 카테고리로 묶어 봅니다. 업데이트 주소가 있는 플러그인의 새 버전을 확인하고, 목록을 JSON으로 내보냅니다.
- **연동 설정**: [DA Interop](https://github.com/Pyser08/dusk-atelier-interop) 코드를 넣은 플러그인은 설정 화면이 자동으로 생깁니다. 값·프리셋을 보내면 그 플러그인이 적용하고 결과를 알려 줍니다.
- **만들기**: 연동 코드가 들어간 플러그인 템플릿을 코드 편집기에서 고치고, 검사·내려받기·설치(RisuAI 확인 창을 거침)합니다.
- **저장소**: 모든 플러그인이 함께 쓰는 `pluginStorage`의 키를 플러그인별로 묶어 보고, 값을 보거나 내려받거나 지웁니다.
- RisuAI(PR #1572 이후)와 이를 따르는 포크는 플러그인이 다른 플러그인을 켜고 끄거나 순서·코드를 바꾸는 것을 막습니다. 그래서 그런 기능은 없습니다.

### 에디터
- 탭: 정보, 로어북, 정규식, 트리거, JSON
- 로어북 폴더: 모듈 목록과 같은 모양(접기·펴기, 폴더 메뉴)입니다. 폴더를 만들 때 넣을 항목을 고르고, 손잡이로 끌어서 넣거나 뺍니다. RisuAI 로어북 창과 같은 저장 형식이라 양쪽에서 그대로 보입니다.
- 넓은 화면에서는 창이 커지고, 로어북 내용 칸이 이름·키 바로 아래에 크게 나옵니다.
- 항목: 추가, 복제, 삭제, 순서 바꾸기
- 단축키: 찾기는 Ctrl+F, 저장은 Ctrl+S
- 검증
  - 정규식 문법 오류
  - 키가 없는 로어북 (구분선용 항목은 빼고: 이름이 `--- 인물 ---`, `=====`처럼 생겼거나 내용이 빈 항목)
  - 없는 폴더를 가리키는 항목
- CBS 사전: 누르면 지금 고치던 칸에 넣습니다.
- 코드 편집기: 정규식 IN/OUT, 트리거 Lua 코드 칸은 문법별로 색을 입히고, 괄호를 누르면 짝 괄호를 함께 표시합니다. 정규식 칸은 긴 줄을 자동으로 줄바꿈합니다.
- 적용하기 전에 바뀐 내용을 요약해서 보여 주고, 저장 전 상태를 백업합니다.

### 에셋 관리자
- **불러오기 속도**
  - 화면에 보이는 것만 읽습니다.
  - 동시에 8장씩, 화면에 가까운 것부터 읽습니다.
  - 썸네일로 줄여서 그리고, 한 번 읽은 것은 기억합니다.
- **폴더**
  - 하위 폴더를 만들 수 있습니다.
  - 폴더 구분은 플러그인 설정에 저장합니다. 모듈 데이터에는 쓰지 않습니다.
- **선택**
  - Ctrl·Shift로 여러 개를 고릅니다. Ctrl+A로 모두 고르고, Delete로 지웁니다.
  - 고른 것을 폴더 칩으로 끌어 옮길 수 있습니다.
- **편집**
  - 추가: 끌어 놓기도 됩니다.
  - 교체, 일괄 교체: 이름으로 맞추거나 순서로 맞춥니다.
  - 이름 바꾸기, 삭제: 바꾼 뒤 되돌릴 수 있습니다.
- **보기·내려받기**
  - 크게 보기: ←/→ 키로 넘깁니다.
  - 내려받기: 여러 개면 폴더 구조 그대로 ZIP으로 받습니다.
- **최적화**
  - WebP로 바꿉니다. 브라우저가 지원하면 AVIF도 됩니다.
  - 품질·크기 단계를 고르고, 미리 계산해 본 뒤 더 작아지는 것만 바꿉니다.
- **메타데이터**
  - 보기: PNG 텍스트, EXIF, XMP, WebP
  - 지우기: 그림은 그대로 두고 메타데이터만 지웁니다.

### 가져오기·업데이트
- **파일 형식**: .risum, .charx, .module.charx, PNG·JPEG 카드, 비밀번호가 걸린 카드, .json. 여러 파일을 한 번에 넣으면 차례로 처리합니다.
- **기존 항목 찾기**: 버전 표기가 달라도 같은 모듈·캐릭터로 찾습니다. 꺼 둔 모듈도 찾고, 업데이트한 뒤에도 꺼진 상태를 유지합니다.
- **연결 기억**: 한 번 고른 파일과 대상의 짝을 기억해서, 다음 버전부터 바로 그 대상을 고릅니다.
- **에셋**: 바뀐 에셋만 올립니다.
- **병합**: 3방향 병합으로 내가 고친 내용은 지키고, 제작자와 내가 둘 다 고친 곳(충돌)은 고르게 합니다.
- **되돌리기**: 업데이트 직후 "바로 되돌리기"를 누를 수 있습니다. 응답을 생성하는 중에는 적용을 막습니다.

### 캐릭터 탭
- 목록, 검색, 연결된 모듈 보기
- **폴더·순서**: RisuAI 사이드바의 캐릭터 폴더·순서(`characterOrder`)를 그대로 씁니다. 여기서 바꾸면 사이드바에도 바로 반영됩니다.
  - 폴더를 만들 때 넣을 봇을 고르고, 손잡이로 끌어서 순서를 바꾸거나 폴더에 넣고 뺍니다.
  - 폴더 메뉴: 넣을 봇 고르기, 이름, 색(RisuAI 색), 위로·아래로, 삭제(봇은 남음)
- **봇 편집**: 모듈 에디터와 같은 화면에서 봇을 고칩니다.
  - 정보: 이름, 설명, 첫 메시지, 추가 인사말, 성격, 시나리오, 시스템 프롬프트, 제작자 노트, 기본 변수, 배경 HTML 등
  - 로어북, 정규식, 트리거, JSON
  - 첫 메시지·추가 인사말: **일반 / 코드** 입력 모드. 둘 다 `<img=…>`, `{{CBS}}`, HTML 태그에 색을 입힙니다.
  - 저장 전에 변경 요약을 보여 주고 백업합니다. 채팅과 메모는 건드리지 않습니다.
- **에셋**: 에셋 관리자로 봇의 추가 에셋을 관리합니다. 폴더 구분은 플러그인 설정에 저장합니다.
- 업데이트 가져오기
- 내 수정만 내보내기, 패치 적용

### 프리셋 탭
- 모듈 켜짐·순서·글로벌 상태를 묶어 저장하고 전환합니다.
  - 만들기, 이름 바꾸기, 덮어쓰기, 삭제
  - 내보내기, 가져오기
- 디바이스 페어: 기기가 바뀌면 모바일용·데스크탑용 프리셋으로 자동 전환합니다.

### 기록 (도구 → 기록 · 되돌리기, 버전 타임라인)
- 업데이트·편집·삭제하기 전 상태를 대상별로 시간순으로 보여 줍니다.
- 지금과 비교하거나, 그 시점으로 되돌릴 수 있습니다. 되돌려도 채팅은 그대로입니다.
- 보관 개수는 항목마다 3/5/10/20개 중에서 고릅니다. 보관 개수를 넘은 백업은 요약만 남깁니다.

### 내 수정만 내보내기 (.rbupatch)
- 제작자 원본과 비교해서 내가 바꾼 부분만 파일로 저장합니다. 번역이나 직접 고친 로어 같은 것입니다.
- 바뀐 필드와 바뀐 목록 항목(추가·수정·삭제)만 담아서, 대형 봇·모듈도 패치가 작습니다. 예: 276MB 모듈에서 로어 5개 수정 → 약 20KB.
- 받는 사람이 같은 원본에 적용하면 그 사람이 고친 부분은 지키고, 패치 내용만 들어갑니다.
- 바꾼 에셋도 함께 넣을 수 있습니다.

### 개발자 모드 (도구 탭)
모듈·봇 제작자를 위한 기능입니다. 수정한 부분만 담은 업데이트 패치를 쉽게 만들어 배포할 수 있습니다. 도구 탭 맨 위 스위치로 켭니다.
- **패치 만들기**: 도구 탭, 모듈 메뉴, 봇 상세에서 엽니다.
  1. 배포한 버전(기준): 배포한 상태 그대로일 때 "지금 상태를 기준으로 표시"를 누릅니다. 이미 고쳤다면 기록에서 수정 전 상태를 고를 수 있습니다.
  2. 바뀐 내용: 기준과 비교해 정보·로어북·정규식·트리거·에셋 중 바뀐 곳을 수정/추가/삭제로 보여 주고, 패치 크기를 미리 알려 줍니다.
  3. 패치 정보: 버전, 제작자, 변경 내용을 적고 "패치 파일 만들기"를 누르면 `이름_v버전.rbupatch`가 내려받아집니다.
- 만든 뒤 지금 상태를 새 기준으로 옮길 수 있습니다. 그러면 다음 패치에는 그 뒤에 고친 것만 들어갑니다.
- 받는 사람은 "패치 적용"으로 파일을 고르면 됩니다. 적용 전에 버전과 변경 내용을 보여 주고, 받는 사람이 직접 고친 부분은 그대로 남습니다.

### 도구 탭
- 색 바꾸기
  - 테마 6개 또는 직접 고른 두 색
  - 밝기: RisuAI 따라가기 / 다크 고정 / 라이트 고정
- 전체 백업 / 전체 복원(zip)
  - 빠른 백업: 모듈과 설정만 담아서 몇 초면 끝납니다.
  - 에셋까지: 에셋 파일도 모두 담습니다. 다른 서버로 옮길 때 씁니다.
- .risum 인스펙터: 필드별 크기, 에셋 목록, ZIP으로 풀기
- 설정 정리: 이 플러그인이 저장한 순서, 꺼진 모듈, 에셋 폴더, 프리셋, 페르소나·캐릭터 연결, 폴더·이름 색 중에서 골라서 지웁니다.

## 호환
- **RisuBard**: 기준 환경입니다.
- **원본 RisuAI (kwaroran/RisuAI)**: 모든 기능이 동작합니다. 처음 쓸 때 데이터베이스 접근 권한을 물으면 허용해 주세요.
- **RisuVault**: 모듈 기능은 모두 동작합니다. 봇 편집·에셋·업데이트·패치 적용은 대화가 긴 봇에서는 RisuVault가 막습니다(채팅 보호). 이때는 안내를 보여 주고 아무것도 바꾸지 않습니다. 대화가 짧은 봇은 그대로 됩니다.

## 저장 위치
- 모듈 데이터에는 RisuAI 표준 필드만 씁니다(이름·로어북·정규식·트리거·에셋 등). 순서·폴더·꺼짐 같은 관리 정보는 모두 아래 전용 키에 둡니다.
- 플러그인 설정은 pluginStorage에 저장합니다. 다른 기기와 함께 동기화됩니다.

| 키 | 내용 |
|---|---|
| `rbm:ui:v1` | 테마, 백업 보관 수, 개발자 모드 |
| `rbm:moduleMeta:v1` | 모듈 목록 폴더, 이름 색, 에셋 폴더, 연결 기억 |
| `rbm:disabledModules:v1` | 꺼 둔 모듈 보관함 |
| `rbm:moduleOrder:v1` | 모듈 순서 |
| `rbm:personaInjected:v1` | 페르소나 연결로 넣은 기록 |
| `rbm:presets:v1` | 프리셋 |
| `rbm:persona:v1` | 페르소나 연결 |
| `rbu:index:v1` | 원본 기록, 백업 목록 |

- 백업 내용과 원본 기록은 서버에 파일(에셋)로 저장합니다.
  - RisuAI의 "사용하지 않는 에셋 정리"를 하면 지워질 수 있습니다.

## 참고
- **편집 방식**
  - 항목별 입력 화면과 JSON 편집을 씁니다.
  - 코드 에디터(CodeMirror)는 쓰지 않고 기본 편집 칸을 씁니다. 외부에서 라이브러리를 받지 않아서 서버나 오프라인에서도 동작합니다.
- **이미지 최적화**
  - 브라우저에 들어 있는 변환 기능으로 WebP·AVIF로 바꿉니다.

## 개발
```
npm install                    # esbuild 설치
node tools/build.mjs           # src/ → dusk_atelier.js (버전은 package.json)
node tools/build.mjs --check   # 빌드 결과가 저장소의 dusk_atelier.js와 같은지 확인
```

| 폴더 | 내용 |
|---|---|
| `src/engine/` | 파일 읽기·쓰기(risum·charx·png·jpeg·zip), 매칭, 3방향 병합, 업로드, 백업, 패치, 이미지 도구 |
| `src/data/` | 모듈·프리셋·페르소나·캐릭터 순서 저장 |
| `src/ui/` | 테마, 공용 부품, 화면(`screens/`), 가져오기 화면(`legacy.js`) |
| `src/tide/` | RisuTide에서 가져온 업데이트 판단 로직(세 방향 비교·필드 소유권·인사말 보호) |
