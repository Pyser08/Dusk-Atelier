# UI-GLASS — 글래스 스타일 개편 지침

> **구현 현황(2.2.0, 11-14)**: 0번(공통 기반)·1번(홈) 끝. 실제 구현이 이 문서와 다른 점:
> - 카드 바탕 토큰은 `--rb-glass-bg`(기존 `--rb-glass`는 블러 값이라 이름 유지). 어두운 카드 = `color-mix(바탕 88%+흰색) 50%`(진한 빛 번짐 위 대비 4.5:1 확보), 안쪽 칸 흰 .08, 보조 글자 .84.
> - 테마는 6종이 아니라 **22종**(`src/ui/glassthemes.js`), 기본 `dusk` = ‘Dusk 황혼’. 밝은 판도 있음(밝기 ‘밝게’ → `.rb-glass-light`).
> - 테마 고르기는 **꾸미기 탭 맨 위 ‘글래스 테마’ 카드**(설정 → 화면이 아님). 색을 직접 고르면 ‘내 강조색’(gtheme `mine`).
> - 가벼운 화면(`.rb-lite`): 꾸미기 → 모양 더 고르기 스위치, PocketRisu·RisuBard UA 자동, `prefers-reduced-transparency`.
> - 공통 클래스 `.rb-gcard`(유리 카드)·`.rb-gcell`(안쪽 칸), 팝업은 `--rb-pop-bg`. 다른 탭 세션은 이것과 섹션 색(`--sec-k`, `.sec-memory/manage/work`)을 쓰면 됨.

Dusk Atelier 화면을 **"화려하지만 직관적인"** 글래스모피즘 스타일로 바꿀 때 따르는 규칙이에요.
견본: `dusk-home-glass.html`(홈), `dusk-home-glass-colors.html`(색상 6종).
이번 개편은 **배치와 모양을 함께** 새로 짜요. 배치가 `UI-STYLE.md`와 부딪히면 이 문서를 따라요.

---

## 1. 핵심 원칙

1. **기능은 줄이지 않는다.** 배치는 새로 짜도 되지만, 있던 기능은 모두 어딘가에서 닿을 수 있어야 해요.
2. **화려함은 바깥과 포인트에만 둔다.** 배경은 화려하게 하고, 카드 안은 반투명 단색으로 둬서 글이 잘 읽히게 해요.
3. **강조는 한 화면에 한 종류만 쓴다.** 그라데이션과 발광은 켜진 스위치, 바로가기 아이콘, 로고, 새 항목 칩, 숫자에만 넣어요.
4. **카드 안쪽 여백을 충분히 둔다.** 내용이 테두리에 붙으면 안 돼요(상시 규칙). 카드 기본 여백은 `18px 20px`, 모바일은 `16px`이에요.
5. **도움말 `?` 버튼, 바로가기, '처음 둘러보기'는 모든 화면에서 유지해요.**

## 2. 레이어 구조

| 층 | 역할 | 모양 |
|---|---|---|
| 배경(stage) | 분위기 | 빛 번짐 4개(radial-gradient)와 진한 바탕색 |
| 유리 카드(glass) | 내용 묶음 | 반투명 흰색, 블러, 얇은 밝은 테두리, 위쪽 하이라이트 |
| 안쪽 칸(num·sc·chip) | 카드 속 작은 단위 | 한 단계 더 옅은 반투명, 테두리 없거나 아주 옅게 |
| 포인트 | 상태·행동 | 테마 그라데이션과 발광 |

카드 안에 카드를 두 단계 넘게 겹치지 않아요. 유리 카드 → 안쪽 칸까지만 써요.

## 3. 토큰

### 3-1. 공통(테마와 무관)

```css
--rb-glass:        rgba(255,255,255,.10);
--rb-glass-2:      rgba(255,255,255,.14);   /* 안쪽 칸·칩 */
--rb-glass-line:   rgba(255,255,255,.22);
--rb-glass-hi:     inset 0 1px 0 rgba(255,255,255,.25);
--rb-glass-shadow: 0 8px 30px rgba(0,0,0,.25);
--rb-glass-blur:   blur(22px) saturate(140%);
--rb-text:         #f2f0fa;
--rb-sub:          rgba(255,255,255,.65);
--rb-mute:         rgba(255,255,255,.55);
--rb-line:         rgba(255,255,255,.10);   /* 목록 줄 구분선 */
--rb-r2: 15px;  --rb-r3: 20px;  --rb-r4: 22px;  /* 칸 / 카드 / 배경 */
```

### 3-2. 테마 토큰(테마마다 바뀜)

| 토큰 | 뜻 |
|---|---|
| `--rb-bg` | 배경 바탕색 |
| `--rb-blob1~4` | 배경 빛 번짐 4색(왼쪽 위, 오른쪽 아래, 위, 왼쪽 아래) |
| `--rb-acc` (`--a1`) | 주 강조색 |
| `--rb-acc2` (`--a2`) | 그라데이션 끝 색 |
| `--rb-acc3` (`--a3`) | 로고 시작 색 |
| `--rb-glow` | 발광 그림자 색 |
| `--rb-tint` | 숫자·아바타의 밝은 끝 색 |
| `--rb-acc-grad` | `linear-gradient(90deg, var(--rb-acc), var(--rb-acc2))` |

기존 `--rb-acc`, `--rb-acc-grad`, `--rb-acc-soft`, `--rb-sel-ring`은 이 값을 바탕으로 다시 계산해요. 토큰 이름은 바꾸지 않아요.

## 4. 컴포넌트 규칙

| 컴포넌트 | 규칙 |
|---|---|
| **배경** | `radial-gradient` 4개(12%/18%, 88%/78%, 70%/8%, 30%/95%)와 `--rb-bg`. 플러그인 창(`--rb-win`) 전체에 깔아요. |
| **유리 카드** | `background: var(--rb-glass)`, `backdrop-filter: var(--rb-glass-blur)`, `1px solid var(--rb-glass-line)`, `radius: var(--rb-r3)`, 그림자는 glass-shadow + glass-hi. |
| **카드 제목 줄** | 왼쪽 굵은 제목(15px), 오른쪽에 스위치, `?`, '전체 보기' 중 하나만 둬요. |
| **스위치** | 꺼짐은 `rgba(255,255,255,.22)`, 켜짐은 `--rb-acc-grad`와 `0 0 12px var(--rb-glow)`. 크기는 42×24예요. |
| **숫자 칸** | `--rb-glass-2` 바탕, 숫자는 24px 굵게, 흰색 → `--rb-tint` 그라데이션 글자, 아래에 12px 설명. |
| **바로가기 칸** | 4칸 격자, 아이콘은 36px 둥근 사각형이고 칸마다 다른 그라데이션을 써요(가져오기=주황, 기억=분홍보라, 관리=하늘파랑, 작업실=민트). 모바일에서는 보조 설명을 숨겨요. |
| **칩** | 20px 둥근 알약 모양, `--rb-glass-2`. '새로'·'추천' 칩만 `--rb-acc-grad`를 써요. |
| **목록 행(최근 기록·토글)** | 행 사이에 `--rb-line` 구분선을 넣고 마지막 행은 빼요. 기록 행 앞에 8px 발광 점을 둬요. |
| **토글 행** | 제목 + 12px 설명 한 줄 + 오른쪽 스위치. 설명은 한 줄로 끝내요. |
| **보조 버튼('처음 둘러보기' 등)** | 점선 테두리 `rgba(255,255,255,.3)`, 바탕 없음. |
| **'…' 메뉴·팝업** | 유리 카드와 같은 모양에 블러를 조금 더(28px) 넣어요. |
| **경고·위험** | `--rb-warn`·`--rb-danger`는 테마와 관계없이 고정해요. 발광 없이 테두리와 글자색만 바꿔요. |

## 5. 레이아웃

- 화면별 배치는 새로 정해요. 탭마다 목업을 먼저 만들어 확인한 뒤 구현해요.
- 목업은 PC(1280)와 모바일(390)을 함께 보여 줘요. 두 크기 모두 같은 구조로 깔끔해야 해요.
- 간격 기준: 카드 사이 16px, 배경 안쪽 여백 22px이에요.
- 견본 홈(`dusk-home-glass.html`)의 2열 배치는 참고용이에요. 확정이 아니에요.

## 6. 성능·호환 (HOST-COMPAT)

- `backdrop-filter`는 모바일(포켓리스·iOS)에서 무거워요. **저사양 모드**를 꼭 둬요.
  - 조건: 설정의 '가벼운 화면' 스위치, 또는 `prefers-reduced-transparency`, 또는 PocketRisu 감지.
  - 동작: 블러를 끄고 카드 바탕을 `color-mix(in srgb, var(--rb-bg) 82%, white 8%)` 같은 불투명 색으로 바꿔요. 발광 그림자도 꺼요.
- `-webkit-backdrop-filter`도 같이 써요(Safari).
- 블러는 화면에 보이는 카드에만 써요. 긴 목록의 각 행에는 쓰지 않아요.
- 글자 대비: 본문 글자는 어느 테마에서나 카드 위에서 4.5:1 이상이어야 해요. 벚꽃·노을처럼 밝은 배경에서 모자라면 `--rb-glass`의 알파를 `.10 → .16`으로 올려요.

## 7. 테마 선택 UI

- 위치: 설정 → 화면 → '테마'.
- 모양: 둥근 버튼 줄로, 버튼마다 테마 그라데이션 동그라미(16px)와 이름을 붙여요.
- 저장: 기존 설정 저장소에 `theme: "dusk" | "night" | "sakura" | "aurora" | "sunset" | "mono"`로 저장하고, 기본값은 `dusk`예요.
- 적용: 플러그인 루트에 `.t-<이름>` 클래스를 붙여서 토큰만 갈아끼워요. 다시 그리지 않아요.

---

## 8. 하지 말 것

- 카드 안 글자나 목록 행 전체에 그라데이션 넣기
- 한 카드에 강조색 버튼 두 개 이상 두기
- 블러 카드 안에 또 블러 카드 넣기
- 배치를 바꾸면서 기능을 빼거나 찾기 어려운 곳에 숨기기
- 이모지 아이콘을 실제 구현에 그대로 쓰기(견본용이에요. 실제는 기존 SVG 아이콘에 그라데이션 바탕만 입혀요)

## 9. 적용 순서

1. `styles.js`에 공통·테마 토큰을 추가하고, 기존 `--rb-*`를 새 값에서 계산하도록 연결해요.
2. 배경과 유리 카드의 공통 클래스를 만들어요.
3. 홈 → 기억 → 작업실 → 관리 → 설정 순으로 새 배치 목업을 만들어 확인한 뒤 구현해요.
4. 저사양 모드와 테마 선택 UI를 넣어요.
5. 화면마다 PC·모바일 e2e(`tests/e2e`)와 6개 테마 대비를 확인해요.
