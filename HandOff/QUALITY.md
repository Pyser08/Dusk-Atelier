# 품질·검토 지침 (2026-11-07)

> **규칙: 작업 시작 전 이 문서를 읽고, 해당하는 항목을 확인한 뒤 진행한다. 읽지 않고 시작하지 않는다.**
> 이 문서는 (A) 외부에서 받은 "버그 잡는 방법" 제안을 코드와 대조해 검토한 결과, (B) 화면 디자인 규칙을 담는다.

## A. 버그 예방 제안 검토

제안의 큰 방향(버그 유형을 묶고, 사용자 약속을 테스트하고, 같은 값은 한 곳에서 구한다)은 타당하다. 다만 **저장소에서 직접 확인한 것과 확인 못 한 것을 구분**해 둔다.

| # | 제안 | 판단 | 근거·비고 |
|---|---|---|---|
| 1 | 테스트는 사용자 약속을 검사 | 채택 | 기능마다 "~하면 ~이다" 한 줄을 테스트 이름으로 쓴다. 예: "Cellar를 끄면 요청이 0회다"(tests/cellar.test.js에 추가됨) |
| 2 | 진짜 모양 픽스처 | 채택 | `tests/fixtures/`에 익명화한 채팅(복사·가져온·페르소나 다른 것·긴 것)을 두고, 제보가 올 때마다 하나씩 추가 |
| 3 | 같은 값은 한 곳에서 | 채택(우선순위 높음) | 페르소나 이름은 `loadPrimaryUserName`, 셀러 사용 여부는 `loadCellarEnabled`로만. 원본 필드를 직접 읽는 새 코드는 grep 검사로 막는 것을 권장(아직 미구현) |
| 4 | 호스트 동작 체크리스트 | 채택 | 아래 체크리스트를 작업 전에 훑는다. 하네스 함수화는 후속 과제 |
| 5 | 모델 응답 녹화·재생 | 채택(후속) | 형식이 깨진 응답을 `tests/fixtures/llm/`에 모으는 것부터 |
| 6 | 고치기 전 실패하는 테스트 먼저 | 이미 규칙 | 프로젝트 지침과 동일. 이번 세션에서도 지켰다(셀러 백오프·온오프) |
| 7 | 출시 절차로 막기 | **부분 확인** | `release.yml`은 `build.mjs --check`만 한다(`npm test` 없음) — 확인됨. `branch-build.yml`/`build-branch.yml`은 `npm test`를 돈다 — 확인됨. "CI가 며칠째 실패", "cellarlatest.test.js가 실제 GitHub를 읽는다"는 **이 환경에서 확인하지 못했다**(해당 테스트 앞부분은 목 저장소를 쓰는 것으로 보임). 릴리스에 `npm test` 단계 추가는 main 수정이라 사용자 지시가 있을 때만 |
| 8 | 보조 호출 진단 화면 | 채택(후속) | 스텔스 "화면 진단"처럼 사용자가 직접 복사해 줄 수 있는 형태가 제보 정확도에 가장 도움이 됐다 |

### 호스트 동작 체크리스트 (기능 만들 때 "두 턴 사이에 이게 일어나면?")
리롤 · 편집 · 메시지 삭제 · 채팅 복사·분기 · 가져오기 · 채팅 전환 · 페르소나 전환·채팅에 묶기 · 스트리밍 중 정지 · 새로고침 · 순정 RisuAI / PocketRisu / RisuBard

### 이번에 실제로 겪은 호스트 제약 (재발 방지)
- 루트 문서 래퍼의 `setAttribute`는 **`x-`로 시작하는 속성만** 허용한다(`class` 등은 오류: "Can only set attributes starting with 'x-'"). 우리가 만든 요소는 `x-dusk="<id>"`로 식별하고 CSS도 `[x-dusk="..."]`로 건다. (스텔스 0.2.3에서 수정 — 0.2.2까지는 사이드바가 그려지지 못했다)
- 꺼져 있는 서버를 짧은 간격으로 계속 확인하면 호스트 프록시(`/proxy2`)가 500을 낸다 → 실패가 이어지면 간격을 늘린다.

## B. 박스(카드) 안 디자인 규칙

**박스 안의 글·아이콘은 테두리에 붙이지 않는다.**
- 카드·박스의 안쪽 여백은 최소 `14px 16px`. 가장자리에 글이 닿는 모양은 금지.
- 박스 안 제목-설명 사이 6px 안팎, 박스끼리 간격은 8px 이상.
- 줄바꿈이 생겨도 좌우 여백이 유지되어야 한다(`min-width:0`, 긴 글은 줄바꿈).
- 새 화면을 만들면 **스크린샷 또는 DOM 확인으로 여백을 눈으로 검토**한 뒤 보고한다. 확인 못 했으면 못 했다고 적는다.
- 사례: 스텔스 프리셋 카드가 안쪽 여백 없이 글이 테두리에 붙어 보였다 → `src/ui/screens/stealth.js`에서 수정.
