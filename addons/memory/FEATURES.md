# 장기기억·관계도 애드온 — 기능 전체 목록

> 기준: 코어 v2.2.20 · 장기기억 0.3.21 + `regress-rename` 브랜치 새 기능(2026-11-20, 미배포).
> 출처: `addons/memory/index.js`, `src/ui/screens/memory/*`, 기억 관련 `src/engine/*`·`src/data/*`, 안내서 `docs/site/guide/memory.html`.
> 새 기능을 만들거나 바꾸면 이 문서도 같이 고친다.

## 0. 애드온이 붙이는 것 (index.js)
- 서비스: `memory`(장기기억 본체), `affhud`(호감도 HUD), `memoryButton`(떠 있는 관계도 버튼), `memoryui`(설정 조각 공유)
- 탭: `memory`(장기 기억), `relmap`(인물 관계도), `branches`(갈래 보기)
- 채팅 메뉴(≡) 바로가기: 장기 기억 · 회귀 / 채팅 옮기기
- 턴마다 후처리: 성인 프로필 변화 반영(`nsfwturn`) → 기본 성격·NSFW 값 채우기(`profileseed`) → 처음 등장 성인 항목 무작위(`adultseed`)
- 지난 대화 분석 앞뒤 훅: 성적 지향 옮기기, 끝나면 기본 성격(최대 8명)·성인 항목 채우기(3턴 넘게 진행된 채팅은 글 후보 생략)
- 요청 훅(beforeRequest)으로 기억 블록 주입, 사용자 프롬프트 공급자 등록(스킬)

## 1. 기록 (응답 → 기억)
- **Dusk 기록기**(`engine/recorder.js`): 장면 1번 + 인물 2~3명씩 1번 짧게 질문. 인물 카드의 켜 둔 칸(관계·평가·말투·알게 된 것·비밀·의도·절제·관계 단계·의심·개방…), 호감도·의심 수치, 장면 요약, 떡밥 기록
- 인물 여러 명 한 번에 묻기(기본 켬), 단계별 분석(최대 6명), 가벼운 모델 모드(최대 3명·한 줄 형식 `memorylines`·인용 확인)
- 내 말도 함께 읽기, 상대 날짜 → 실제 날짜, 일어난 때·말한 때 분리
- 응답 정리: HTML 태그 제거(상태창 글자는 남김), 생각 글 제거, 6,000자 넘는 응답 나눠 읽기
- 정규식 전처리(`regexui`): 분석 입력·임베딩 질의에서 군더더기 제거
- 기억 등급 D~EX(`memorygrade`), 검색 키(인물·장소·키워드, `memorykeys`), 신뢰성·출처·충돌·중복 제거(`memorytrust`)
- {{user}} 이름 통일(`memoryuser`), 이야기 시간 상태 줄 읽기(`storytime`), 시간선 날짜 직접 고치기
- 인물별 digest(압축, 기록 20개 넘으면 10턴마다 정리 호출)
- 알고 있는 정보 30개·비밀 15개 상한 자동 정리(`wikiprune`, 고정·직접 쓴 항목 보존)
- 죽음·실종·떠남 같은 상태 기록, 월경·임신 보고 별도 칸(`cyclereport`)·안전장치(`cyclescene`)·기록 연결(`cyclememo`)
- 지난 대화 분석: 묶음 크기·동시 처리, 429 자동 감속, 생성 중지, 진행 표시 유지(`bfprogress`), 함께 기록(Writer로 위키 채우기), Cellar 서버 분석
- 분기한 채팅 기억 이어받기(기본 켬), 롤백 충돌 안내(`conflictui`: 새 응답 반영·변경 비교·그대로 두기)
- 실패 기록 창(`faillog`), 복구·실행 기록(`recovery`: Writer JSON 진단·반영), 자동 기록 진단(`memorydiag`)
- 수동 Writer(`writerui`): 본문 붙여넣기 → 분석 → 변경안 검토 → 반영

## 2. 주입 (기억 → 응답)
- `[Dusk Memory]` 블록 고정 예산 조립(`memoryinject`, 척도 정리 `memoryscale`), 목표·상한 토큰, 남길 최근 턴
- 관련 기억 고르기: 최근 흐름 + 지금 말과 가까운 옛 장면, ‘관련 있는 지난 순간’ 칸
- 임베딩 의미 검색(`embed`, 설정 창·연결 테스트), 원문 회상 12조각(`rawrecall`, RRF), Jev 재정렬(오픈라우터/Vercel/직접 주소)
- 기억 토큰 절약(약 30%↓, 기본 켬), 요약된 옛 대화 빼고 보내기(기본 켬)
- 흐름 방식 ‘정확하게’: Dusk 정리 노트(응답 전 정리표 + 방향 질문 1번), 재요청 시 재호출 안 함, 진행 점 5개(`flowsteps`)
- 회상(`recall`): 고른 인물의 기록을 Director 참고 항목으로
- 주입 로어 편집(`loreeditor`/`memorylore`): 실제 들어가는 줄 고치기·숨기기·내 줄 추가
- 지식 경계·열린 항목·관계 변화·세계 시간선·강화/망각·원문 발췌 복원(`memoryplus`)
- 스킬(`skills`·`skillchat`): 코코아전트 호환 스킬을 정리 노트·기록·분석 프롬프트에 붙이기, AI와 대화로 스킬 만들기
- 캐시 진단(고급): 요청 간 앞부분 일치·깨진 위치·이유

## 3. 사람다운 기억·관계 (`memoryhuman`, `memoryemo`, `memoryinner`)
- 관계 진도 4단계(처음 봄·아는 사이·친한 사이·아주 가까운 사이)와 수치 상한 연동
- 호칭·말투(존댓말/반말, 이전 것 함께), 둘만의 추억, 오랜만의 재등장, 변화 기억(지금 B, 전에 A), 흐려지는 기억
- 갈등·사과·화해·앙금, 사람 앞 태도(둘일 때와 남들 앞)
- 감정 6태그 + 식는 속도(적대·두려움 빠름, 의존·애정 느림, 신뢰·존경은 행동으로만), 잠금 값
- 호감 이원화(인간적·이성적), 애인 인식(분홍), 소유욕·독점욕
- 썸 행동 지침(`romancecue`: 관심→호기심→설렘→썸→고백 직전 × 성격 6축), 인물끼리 끌림, 유저 편향 없애기
- 끌림 속도 제한(진도별 상한, 인간적 호감보다 3 넘게 못 앞섬, 바람 가능성)
- 연애 흐름(`romance`): 고백 수락/거절, 이별·미련, 재회·그리움, 질투·연적, 짝사랑, 비밀 연애
- 거짓말·오해 추적(기본 꺼짐), 인물 관점·내면(중요한 때만)
- 기본 성격 6축(근거와 함께 누적), 오래가는 관계(남매·연인·상사)
- 고친 값은 출발점(잠그지 않음)

## 4. 몸과 마음 (엔진 계산, 호출 없음 — `nsfwlife`, `lifecards`)
- 성욕 게이지: AI 판단으로만 오르내림, 인물 배수 × 성향 × 달아오르는 속도, 가임기·끌림·애인·밤·술 가중, 생리·적대·피로·아침 감쇠, 절정 후 하락·4턴 휴지, 대화로 ±30, 욕망·이상성향 관련 시 1.3배
- 장면 계획(`scenedrive`): 달아오를수록 ‘지금 상태’ 확률↑, 90 이상 확정, 분명히 밀어내면 2턴 쉼, 확정 계획 저장
- NSFW 탭 배경 붉어짐·60 이상 하트
- 오늘 한 줄, 기분 5종(턴마다 5씩 가라앉음), 피로(잠에 풀림·새벽 가중)
- 경험·익숙함(상대별 횟수·이야기 전 횟수·만족도), 자주 한 것(2번 목록·5번 좋아함)
- 월경·임신(주기 임신 가능성, 주기별 기분, 연호 날짜)
- 인물 비교 표(성욕·피로·기분)
- 마음 흐름: 관계 온도(최근 10번)·신뢰 그래프, 보고 싶음(30턴), 질투, 기념일(첫 만남·사귄 날·첫 관계, 100턴·1주년), 둘만의 버릇
- 사람다움: 말버릇·습관·민감한 주제·꿈·비밀·사랑 표현·화날 때·슬플 때
- 잠자리: 처음 경험·판타지·신음과 말투·끝난 뒤·좋다/싫다 신호·피임 태도
- 성감대 인체 모형 앞·뒤 19부위, 민감도 3단계, 개발도 0~100(30·60·85 단계)
- ‘왜 이렇게 됐나요?’ 변화 이유, i 설명, 직접 고치기

## 5. NSFW 위키·성인 프로필
- 성인 프로필 카드(`nsfwcard`, 채팅별 `folder.nsfw`, `nsfwprofile`), 매 턴 변화 반영(`nsfwturn`)
- 성적 욕망·이상성향 카드(`adultcands`), 무작위 다시 뽑기(`adultreroll`), 처음 등장 때 성인 항목 무작위(`adultseedmodal`, 분류별 항목 켜기·직접 추가)
- 선호·금기 태그(`erosynctagsui`), 관계 온도 그래프(`erosynctempui`), NSFW 프로필 파일 내보내기/불러오기
- NSFW 설정 화면(예전 Erosync, `erosyncpage`): 수위 SFW/NSFW/NSFW+·극단 수위, 프리셋, 집착 방지, 동작·분석, 프롬프트 편집, 검토(성격 변화 후보), 비하인드, 장면 되돌리기, 매 턴 계산, user에게도 적용, 출발값 만들기(전체/골라서), 값 편집·되돌리기·다시 분석
- (Erosync 자체는 v2.2.9부터 사용 중단 — 위 기능은 장기기억 안에서 동작)

## 6. 인물 위키 화면
- 구역 탭: 인물 위키 · 상황 · 시간선 · 열린 항목 · 관계(`mdetail`, `ledger`)
- 인물 막대: 인물 수·찾기·칩(나=파랑, 성별 색)·추가·도구
- 인물 화면: 왼쪽 프로필 열 + 탭(관계·상세 정보·NSFW·기록), 구역 이동(PC 아이콘 독, 모바일 반원 휠·진동·관성)
- 관계 탭: 상대 고르기, 감정 고리·막대·칸·하트, 관계 상태·말과 태도·추억·갈등·오해
- 상세 정보 탭(`infotab`): 바로가기, 성향 2열, 값 있는 수치만, 빈 항목 칩 → 직접 적기/AI로 채우기
- 나에 대한 기억(`mepage`), 페르소나 이름 기록 ‘나로 합치기’, {{user}}를 페르소나 이름으로 표시
- 인물 관리: 이름·별칭 고치기(대표 이름 올리기), 관계 지우기(`relremove`), 항목 추가·고치기·지우기·NPC 감정(`recordsui`), 위키 항목 전체 보기·수정·고정(`wikipanel`)
- 합치기(미리보기, `mergeui`), 같은 이름 한 번에 합치기(`peopledupe`), 합치기 되돌리기, 위키 점검(`wikihealth`), 문서 이름 맞추기
- 폴더 정리(`folderui`), 추적 인물 고르기(`trackui`), 새 인물 자동 추적, AI로 빈칸 채우기(`fillgaps`, `peoplegaps`)
- 인물 AI 도구(고급, `aitools`): 전체 다시 정리·직접 지시·항목 AI 작성·수치 제안
- 사용자 정의 게이지(`gauge`): 이름+설명 → AI 설계, 구슬·고리·막대·눈금, 특정 인물만, 8응답마다 갱신, 제안·되돌리기·내보내기
- 게이지 배수(오를 때/내릴 때 ×0~×3, 달아오르는 속도)
- 봇 로어북으로 내보내기(`lorexport`, 비밀·성적 태도 제외)
- 위키 기록 관리(고급, `wikilog`): 변경 이력 되돌리기·재시도·요약 정리, 기억 편집기(`editor`)

## 7. 장기 기억 홈·설정
- 홈(`mhome`): 상태 카드(스위치·숫자·사용 막대 `memoryusage`), 지난 대화 분석, 바로가기, 기억 옵션
- 저장소 선택(Dusk 자체 / BardWiki, `modebar`, `bardwikiadapt`), 봇별 기억(`mbots`), 채팅 목록(`chatload`)
- 처음 설정 3단계(`setup`), 작은 ? 가이드(`guide`), 임베딩 첫 소개
- 추적 수준 3종·기능 카드·AI 모델 쉬운/고급(`flowsettings`, `modeladv`), 고급 세부 3묶음(`advorganize`)
- 설정 도구(`settingstools`): 범위 칩·설정 검색·변경 이력 10개 되돌리기·프리셋 공유 코드·이 채팅 요약
- 필요한 설정 함께 켜기 + ‘동작 중이에요’ 표시, AI 호출 배지(초록·파랑·주황·보라, `aicost`)
- 최근 기록 결과(`settings`), 리수폿 화면(`potpage`: 개요·설정·자동 기록·고급, 리수폿 일괄 사용)
- 파일: 장기 기억 파일 내보내기/불러오기(전체·열린 채팅만, 다른 채팅에 넣기), Erosync 값 지우기(`memoryfileui`)
- HypaPlus에서 옮겨오기(`hypamodal`)
- 기록 삭제 연쇄 처리(`memorydelete`)

## 8. 새 채팅 만들기
- 다른 봇으로 인물 옮기기(`extracards.openMovePerson`, `memextra.personPack/insertPack`): 문서·기본 성격·성인 프로필·몸과 마음·기억·목표 복사(관계 제외)
- 회귀 / 채팅 옮기기(`regress`): 고른 인물만 기억 들고 처음부터, 전체 선택 = 이어서 하기(기억 전부 새 채팅), 시계 연출
- 기억 되감기(`memoryrewind`): 저장된 기억 시점으로 새 채팅(되감기 첫 메시지 AI 작성)
- 새 봇 합성(`compose`·`memorycompose`·`makebot`): 인물 → 범위·등급 → 카드 → 연결 → 첫 메시지, 카드 탭(`cards`)

## 새로 만들 기능 후보 (위 목록에 없는 것만)

> 0.3.22에서 만든 것: 1·2·5·6·7·8·9·10·12 (8-1절). 남은 후보: 3 모순 감지, 4 지난 이야기 카드, 11 둘 사이 약속.

### 장기기억
1. **화면 밖 근황**: 오래 안 나온 인물이 재등장할 때, 그동안 무엇을 했을지(기억·성격·관계 기반) 짧게 만들어 넣기. 지금은 ‘얼마 만인지’만 알려 줌.
2. **소문·정보 전파**: A가 B에게 말한 정보가 C에게 퍼지는 경로 기록. 지식 경계를 ‘누가 누구에게 들었나’까지 확장해 들킴·뒷담화 전개.
3. **모순 감지(호출 없음)**: 응답이 기억과 어긋나면(죽은 인물 등장, 호칭·반말 뒤바뀜, 애인 착각) 응답 아래에 경고 + 리롤 제안.
4. **지난 이야기 요약 카드**: 채팅을 오랜만에 열면 “지난 이야기” 3~5줄과 열린 떡밥을 보여 줌(기존 요약 재사용, 새 호출 없음).
5. **@인물 고정 회상**: 입력에 `@이름`을 쓰면 이번 응답에 그 인물 기억을 예산과 상관없이 넣음.
6. **인물 장기 목표·진척**: 성인 장면 계획과 별개로 일상 목표(복수·승진·고백 등)와 진척도. 정리 노트에 동기로 들어감.

### 위키
7. **장소·물건·세력 문서**: 지금 위키는 인물 중심. 자주 나오는 장소·아이템·선물·조직을 자동 문서화하고 관계도에 소속으로 연결.
8. **인물 일기 보기**: 인물 시점으로 최근 사건을 한 단락 회고(누를 때만 생성). 감정 흐름을 사람 말로 확인.
9. **다른 봇으로 인물 옮기기**: 회귀는 같은 봇만. 인물 문서·성격·말투를 다른 봇의 기억에 이식.

### NSFW 위키
10. **흔적 지속**: 키스마크·상처·옷 상태 같은 몸 흔적을 기록하고 며칠(이야기 시간) 뒤 사라지게. 장면 연속성.
11. **상대별 경계·약속**: 인물 쌍마다 하지 않기로 한 것·세이프워드·합의된 범위를 기록해 주입(지금은 인물 단위 신호만).
12. **궁합 표**: 두 인물의 취향·성감대·주도성 겹침으로 궁합과 ‘아직 안 해 본 겹치는 취향’ 보여 주기(호출 없음).

### 인간다움 계획 (11-21, 사용자 목표: 최대한 인간을 모방 — 전부 원함, 설계 고민 중)
- H1 기억의 불완전함: 오래되거나 약한 기억은 흐려지고 세부가 틀리며, 강렬한 기억은 선명하게 남음.
- H2 기분 관성·컨디션: 피로·허기·수면·날씨가 감정에 반영되고, 한 턴 만에 리셋되지 않음.
- H3 말버릇·말투 변화: 입버릇, 친밀도·기분에 따른 존댓말/반말·문장 길이.
- H4 모순·자기합리화: 말과 행동의 어긋남, 고집 뒤 슬쩍 입장 바꾸기.
- H5 화면 밖 일상(위 1번 확장): **따로 생성(보조 호출 1번)** — 기록기에 끼우면 위키 반영이 한 턴 늦어서. 실제 시간이나 이야기 날짜가 비었을 때만, 인물 1~2명·일 2~3개, 저장 뒤 짧은 줄로 주입. 추정 입력 약 2k, 출력 약 300토큰.
- H6 선제 행동: 먼저 연락하기, 지난 일 되묻기, 약속 기억.
- H7 원한·미련·고마움 누적: 쌓였다가 엉뚱한 때 터짐.
- H8 성장: 사건이 가치관·취향·두려움을 천천히 바꿈.
- H9 비밀·거짓말: 숨김, 선의의 거짓말, 들킬 위험.
- H10 취향의 구체성: 사소한 호불호를 일관되게 지킴.
- H11 방어기제·트라우마 반응: 특정 주제에서 회피, 농담, 과민 반응.
- H12 관계 깊이: 쌍마다 여러 축(신뢰·애정·긴장·부채), A→B와 B→A 비대칭(상대 마음 착각 포함), 전환점 목록(처음 만남·싸움·화해), 둘만의 것(별명·농담·싸우는 방식), 삼각 구도(질투·편들기, 소문 전파와 연결), 거리 관성(연락이 끊기면 서먹, 재회 때 어색함).
- H13 선호·불호: 인물마다 `대상·강도(좋음/집착/싫음/혐오/두려움)·이유(기억 연결)·맥락(혼자/남 앞/기분/특정인)·출처(관계·사건)`. 사람 때문에 생기거나 사라지는 취향(H8), 처음 겪은 반응이 취향으로 굳음, 기본은 지키되 기분·사람에 따른 예외(H4). 주입은 "좋아함"이 아니라 "이럴 때 이렇게 반응함". 성인 프로필 취향과 합칠지 나눌지는 미정.

#### 원칙 (비용·묘사)
- 판단은 코드가 함(호출 없음): 기억이 흐려지는 정도, 기분 관성, 컨디션, 관계 거리, 취향 예외 확률. nsfwlife 방식.
- 기록기는 변화가 생겼을 때만 사건 줄로 보고함(새 취향, 전환점 등). 수치는 코드가 계산. 지시 줄은 관련 인물이 있거나 공백이 생겼을 때만 붙임.
- 따로 생성은 H5 하나만.
- 주입은 이번 턴에 드러낼 1~2개만 코드가 고르고, 구체적인 행동으로 적음("대답이 짧고 하품을 참음"). 같은 버릇은 REST_TURNS로 쉬게 함. 틀린 기억은 코드가 정해서 지시함.
