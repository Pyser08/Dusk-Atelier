# Dusk Atelier v1.8.0 안내

## 기억 탭 통합

- 기억 상태, 지난 대화 분석, 기억 설정, 최근 기록을 한 화면에서 확인합니다.
- 인물 위키와 자동 기록 관리 화면은 접이식 패널로 이동했습니다. 패널을 펼칠 때 화면을 불러오며, 내부 조작은 해당 패널만 갱신합니다.
- 설정 탭의 `기억·리수폿 프롬프트`와 `임베딩(의미 검색)` 설정은 기억 탭에서 접근합니다.
- 인물·리수폿의 개별 설정과 기능은 기존 저장 구조를 유지합니다. 장기기억 스위치와 리수폿 자동 기록 스위치는 서로 독립입니다.

## BardWiki 선택

RisuBard의 BardWiki가 감지되고 아직 선택하지 않았다면 기억 탭에 처음 들어갈 때 저장소 선택 안내가 표시됩니다. 선택한 값은 저장되며, 기억 탭 상단의 `기억 방식`에서 나중에 변경할 수 있습니다. 저장소를 바꾼 뒤에는 안내에 따라 RisuAI를 새로고침해야 변경된 훅이 반영됩니다.

## 화면 배치

v1.7.2에서 수정한 넓은 화면의 인물 위키 전체 편집 배치를 유지했습니다. 기존 카드, 버튼, 접이식 영역과 반응형 목록·상세 화면을 재사용합니다.
