🎨 처음 열어도 바로 쓰게,

간단 모드에는 꼭 필요한 것만 두고, 세부 설정은 고급 모드로 옮겼어요. 기억과 리수폿은 따로 켜고 끌 수 있고, 인물 화면도 새로 만들었어요. 기존 기능은 빼지 않고 고급 모드나 ⋯ 메뉴로 옮겼어요.

PART 1
🎨 새 화면 · 간단 / 고급 모드
처음 쓰는 분이 글을 안 읽어도 바로 쓰도록, 첫 화면에는 스위치 하나와 주요 동작 몇 개만 둬요.
1🧭 메뉴가 4칸이 됐어요NEW
홈 · 기억 · 리수폿 · 인물 4칸이 맨 앞에 있고, 나머지(캐릭터 · 모듈 · 기억 카드 · 꾸미기 · 도구 · 플러그인 · 설정)는 더보기에 모았어요. PC는 메뉴를 왼쪽 / 위쪽 중에 골라요.
2🏠 홈에서 바로 시작해요
지금 열린 채팅 이름과 기억 · 리수폿 · 인물 상태 3줄(꺼짐 / 준비 중 / 사용 중), 그리고 바로 하기 9칸이 있어요. 꺼져 있으면 켜기 버튼이 바로 보여요.
3🎚️ 간단 모드 / 고급 모드
설정 → 화면 모드에서 바꿔요(기본 간단). 각 화면 맨 아래 고급 모드에서 더 보기로도 바꿔요. 예전 세부 설정은 사라진 게 아니라 고급 모드에 있어요.
· 개발자 모드는 고급 모드에서만 켜요. 켜면 캐릭터·모듈 오른쪽 상세 패널, 패치·개발 목록 기능, 개발 탭이 생겨요
· 처음 열면 홈에 ‘필요한 것만 먼저 보여 드려요’ 안내가 한 번 떠요
4🎨 꾸미기 · ⚙️ 설정
꾸미기는 미리보기 · 강조 색 6개 · 밝기 · 글자 크기 · 내 채팅 테마 만들기만 먼저 보여요. 설정은 화면 모드 · 메뉴 위치 · 이야기 도우미 스위치 3개(공정한 전개 · 유저 편향 없애기 · 이야기 시간)예요.
5🙋 처음 둘러보기도 새로
새 메뉴에 맞춰 12장으로 다시 만들었고, 화면 글의 어려운 말(주입 · 턴 흐름 · digest 같은)은 쉬운 말로 고쳤어요.
PART 2
🧠 기억 · 📖 리수폿 · 👥 인물
기억과 리수폿은 이제 서로 다른 스위치예요. 채팅마다 따로 켜고 꺼요.
1🧠 기억 — 스위치 하나로NEW
이 채팅에서 사용 스위치 하나, 그리고 마지막 요청에 기억 N건을 넣었어요처럼 상태를 보여 줘요. 저장된 기록은 막대로, 안 넣었으면 이유를 한 줄로 알려 줘요.
· 주요 동작: 지난 대화 분석(미처리 N개) · 카드로 만들기 · 다른 채팅 보기
· 기록 보기(인물 위키 · 상황 · 시간선 · 열린 항목 · 관계)와 봇별 기억 화면이 따로 있어요
· 저장 위치 · 분석 모델 · 제외할 이름 · 기억 초기화는 고급 모드
2📖 리수폿 — 기억과 따로NEW
리수폿(위키 정리)만 켜도 되고, 기억만 켜도 되고, 둘 다 켜도 돼요. 켜둔 것은 업데이트해도 계속 켜져 있어요. 위키 인물마다 캐릭터별 사용도 따로 고를 수 있어요.
· 주요 동작: 위키 보기 · 지금 기록 · AI로 빈칸 채우기
· 자동 기록 시점 · 롤백 충돌 안내는 기억과 따로 저장돼요
3👥 인물 — 카드와 상세NEW
인물 카드에 사진 · 이름 · 한 줄 요약 · 호감도 게이지가 보이고, 수치가 비면 수치 비어 있음 배지가 떠요. 누르면 상세에서 지금 상태 · 요약 · 성격 · 관계 · 최근 기록을 보고, 고정하기 / 기록 쉬기를 해요.
· 스위치 하나로 새 인물도 자동으로 추적할지 정해요(끄면 고른 인물만)
· 위키 전체 편집 · 추적 인물 고르기는 고급 모드
4⚔️ 변경 비교
롤백했을 때 내가 직접 고친 내용과 AI 기록이 겹치면 알려 줘요. 원래 → AI가 바꿈 → 지금을 나란히 보고 그대로 두기로 닫아요. 슬롯 이름은 호감도처럼 한글로 보여요.
5🔧 자동 기록이 덜 꼬여요
기본이 다음 입력을 보낼 때 이전 응답을 확정·분석하는 방식이라, 다시 생성하거나 넘겨 봐도 기록이 덜 꼬여요. 기억이 안 들어갔을 때 이유가 보이고, 마지막 분석 위치가 어긋나면 복구해요. 지난 대화 분석은 아직 안 한 응답만 해요.
PART 3
✨ 그 외 바뀐 점
캐릭터·모듈 화면과 테마 공유 코드를 다듬었어요.
1🔗 모듈 연결, 일반 모드에서도
개발자 모드가 아니어도 모듈 줄의 🔗 연결 · N으로 전역 · 페르소나 · 캐릭터 · 지금 채팅 연결을 바로 고쳐요(PC는 팝오버, 모바일은 아래 시트).
2🤖 AI로 봇 만들기 한 번에
캐릭터 화면의 AI로 봇 만들기 버튼(또는 줄의 AI로 만들기)을 누르면 새 봇의 편집기가 AI로 제작 탭으로 바로 열려요.
3🎨 테마 공유 코드가 짧아졌어요
공유 코드를 DTB2 형식으로 바꿔 훨씬 짧아졌어요. 예전 코드도 그대로 읽어요.
4📱 모바일 · 다크 모드 점검
폭 5종(320~768px) × 간단·고급 × 모든 탭에서 가로로 넘치지 않는지, 다크 모드에서 글자가 흐리지 않은지 확인했어요. 모듈 화면은 모바일에서 새 모듈 버튼이 가려지던 문제를 고쳤어요.
⚠️ 화면이 많이 바뀌어서 처음엔 낯설 수 있어요. 예전 세부 설정이 안 보이면 설정 → 화면 모드 → 고급을 켜 보세요. 문제나 불편한 점은 댓글로 알려 주세요.
