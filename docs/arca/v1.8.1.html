FEATURE 1 · GAUGE
📊 자동 게이지
호감도 하나로는 담기 힘든 수치(긴장감, 오염도, 피로도…)를 내가 정한 이름으로 만들어요. 설계는 AI가 하고, 저장은 내가 눌러야 해요.
1-1✏️ 이름과 설명만 적으면 돼요NEW
인물 위키의 수치 상태 아래 + 게이지 추가를 누르고 이름과 설명만 적어 보세요. AI가 범위·변화 규칙·색·모양까지 설계해 줘요.
· 저장하기 전에 미리 보고 직접 고칠 수 있어요
· 저장을 눌러야만 만들어져요. 닫으면 아무것도 남지 않아요
· 예시: 이름 “경계심” · 설명 “낯선 사람이 다가오면 올라가고, 친해지면 내려간다”
1-2🔄 값은 이렇게 갱신돼요
값과 변화 기록은 인물·채팅마다 따로 쌓여요. 같은 인물이라도 채팅이 다르면 값도 달라요.
· 켜 둔 게이지는 응답 8개마다 기존 장기기억 분석에 얹혀서 갱신돼요
· 그래서 AI 호출이 따로 늘지 않아요
1-3🎨 채팅에서는 이렇게 보여요
채팅 응답 아래, 로어북 버튼 바로 위에 게이지 박스가 붙어요. 모양은 네 가지예요.
· 구슬 · 고리 · 막대 · 눈금
· 게이지마다 색과 CSS가 달라서 분위기에 맞게 꾸밀 수 있어요
1-4🗂️ 관리: 끄고 켜고 되돌려요
게이지 관리에서 필요한 건 전부 할 수 있어요.
· 켜기/끄기 · 수정 · 삭제
· JSON 내보내기·가져오기 — 만든 게이지를 다른 채팅이나 친구와 나눠요
· 마지막 변경 되돌리기 (변경 기록은 채팅당 100건까지)
1-5💡 자동 제안 (기본 꺼짐)기본 꺼짐
켜 두면 AI가 새 게이지를 제안해 줘요. 과하게 뜨지 않도록 제한이 있어요.
· 하루 2개까지, 4시간 간격, 한 번에 1개만
· 수락하면 모든 인물에게 만들어져요
· “나중에”를 누르면 24시간 뒤에 다시 떠요
FEATURE 2 · COCOA
🥥 코코아 (스킬)
AI 응답의 방향을 잡아 주는 스킬 세트를 가져와 붙이고, 직접 만들어요. 코코아전트(cocoA(gent!))의 스킬과 그대로 호환돼요.
2-1🧭 새 탭: 기억 → 코코아NEW
사이드바 기억 섹션에 코코아 탭이 생겼어요. 장기 기억·기억 카드와 같은 단계이고, 열린 채팅이 없어도 열려요.
· 간단 모드: 코코아 기능 켜기 토글 · 스킬 목록 · 사용할 스킬 고르기만 보여요
· 고급 모드: 단계별 붙이기 · 코코아전트에서 옮겨오기 · 웹 도구 · 호출 기록까지 보여요
· 기본은 꺼짐이고, 장기기억과 따로 켜고 끌 수 있어요
2-2📦 스킬 가져오기 · 고치기 · 내보내기
코코아전트의 스킬 세트(ZIP·JSON)를 그대로 가져와 쓸 수 있어요.
· 세트 안의 파일을 바로 열어 고쳐요
· 진단 · 주입 미리보기로 실제로 어떻게 붙는지 먼저 확인해요
· 목록의 각 세트에서 바로 ZIP·JSON 내보내기
2-3🔌 어디에 붙나요?
켜면 고른 호출의 프롬프트 뒤에 스킬 지침이 붙어요.
· 관련 인물 고르기 · 정리 노트 · 기록하기 · 기억 분석
· 스킬 때문에 AI 호출이 따로 생기지 않아요
· 스킬은 메인 채팅 프롬프트에는 들어가지 않아요
2-4🤖 AI로 스킬 만들기NEW
코코아 탭 오른쪽 아래 버튼을 누르면 AI와 대화하는 창이 열려요. 말로 설명하면 스킬 초안이 실시간으로 쌓여요.
· 만들어지는 파일이 대화 중에 하나씩 쌓이는 걸 볼 수 있어요
· 점검(진단)을 거친 뒤 라이브러리에 넣거나 ZIP·JSON으로 내보내요
· 코코아전트의 스킬 가이드를 그대로 따라 규격이 맞아요
· 메시지를 보낼 때마다 AI 호출이 한 번 생겨요
💬 “이런 말투로 짧게 답하게 해 줘”처럼 원하는 걸 말하면 돼요. 규격은 AI가 알아서 맞춰요.
2-5🚚 코코아전트에서 옮겨오기 (고급)
같은 기기에 코코아전트를 쓴 기록이 있으면 스킬 세트와 에이전트별 연결을 찾아 Dusk의 단계에 이어 줘요.
· 원하면 에이전트 프롬프트도 스킬로 변환해요
· 코코아전트의 데이터는 바꾸지 않아요
2-6🌐 웹 도구와 호출 기록 (고급, 기본 꺼짐)
켜면 고른 단계(기본: 정리 노트)에서 모델이 필요하다고 판단할 때만 검색이나 페이지 읽기를 요청해요.
· 요청이 있을 때만 그 단계의 AI 호출이 1~2번 늘어요
· 검색: Wikipedia · DuckDuckGo(키 없이), Brave · Tavily · Serper · Exa(API 키), SearXNG(서버 주소)
· 페이지 읽기는 공개 http/https만, 내부 주소·로그인 정보가 든 주소는 막아요
· API 키는 이 기기에만 저장되고 내보내기·백업에 안 들어가요
· ‘시험 검색’으로 설정을 바로 확인하고, 호출 기록에서 스킬 글이 몇 자 붙었는지 봐요(저장은 안 해요)
FEATURE 3 · HYPAPLUS
🧩 HypaPlus 가져오기
HypaPlus에 쌓아 둔 기억을 버리지 않고 Dusk 장기기억으로 옮겨요.
3-1🔁 어떻게 옮겨지나요NEW
HypaPlus의 기억 종류마다 Dusk의 알맞은 자리로 가요.
· 이벤트 → 장면 + 기록
· 사실 → 기록
· 즐겨찾기 → 고정 · A등급
3-2🛡️ 안전하게 옮겨요
옮기다 꼬이지 않도록 몇 가지를 지켜요.
· 같은 기억은 두 번 들어가지 않아요
· HypaPlus의 원본은 그대로 남아요
· 백업 파일로 가져오면 원래 메시지에 연결돼서 리롤·삭제를 따라가요
3-3⚠️ 함께 쓸 땐 한쪽만
HypaPlus와 Dusk 기억은 동시에 쓸 수 없어요. 두 기능이 서로 부딪힐 수 있으니 한쪽만 켜 주세요.
· 기억 탭에 처음 들어갔을 때 HypaPlus가 보이면 안내 창이 자동으로 떠요
· 안내는 설정에서 언제든 다시 볼 수 있어요
FEATURE 4 · BOTBUILDER
🤖 봇빌더 연동
Dusk의 “AI로 봇 만들기”가 봇빌더(risu_story_workshop)로 이어지고, 만든 봇이 Dusk 개발 목록으로 돌아와요.
4-1🚪 열고, 돌아오면 이어져요NEW
봇빌더가 설치돼 있으면 AI로 봇 만들기가 봇빌더 화면을 열어요.
· 봇빌더에서 작업하고 Dusk를 다시 열면, 새로 등록한 봇(또는 고친 봇)이 개발 목록에 자동으로 들어가요
· 들어간 봇은 바로 이어서 편집할 수 있어요
· 봇으로 등록하지 않은 원고는 새 봇으로 가져올지 물어봐요
4-2🔧 연동판 봇빌더
화면을 Dusk에서 바로 열려면 코드가 조금 붙은 연동판 봇빌더가 필요해요.
· 안내 창의 ‘연동판 받기’로 지금 설치된 봇빌더를 연동판으로 바꾼 파일을 받아요 (원본 파일은 그대로)
· Dusk를 안 쓰는 사람에게는 봇빌더가 지금과 똑같이 동작해요
· 원본 봇빌더 그대로여도, 돌아왔을 때 가져오기는 돼요
· 봇빌더가 자동 업데이트되면 원본으로 돌아가요. 그땐 연동판을 다시 받아 주세요
🙏 공식 봇빌더에 반영해 주시도록 제작자분께 따로 부탁드릴 예정이에요.
4-3📚 로어북 더스크화 — 규칙 설계NEW
봇 만들기 화면의 로어북 더스크화가 한 단계 늘었어요. 소속·장소 정리 다음에 AI가 항목마다 Dusk 규칙을 설계해요.
· 조건 · 확률 · 한 번만/쉬기 · 유지 · 그룹
· 배치 깊이 · 연쇄 · 변수 · 이름 경계와 소속 확률
· 내용·키·폴더는 바꾸지 않아요
· 미리보기에서 항목별로 “이유”를 보고 골라서 적용해요
· 이미 정리된 로어북은 바로 규칙 설계로 가요

🔧 그 밖에 바뀐 것
작은 편의 기능과 화면 정리예요.
5-1🧭 처음 둘러보기가 한 번 더 떠요
이번 업데이트를 받거나 새로 설치하면 둘러보기가 자동으로 딱 한 번 떠요 (코코아 단계 추가). 그 뒤로는 홈의 ‘처음 둘러보기’나 설정에서 직접 열 때만 보여요. 화면 위쪽 ? 버튼도 팝업 대신 지금 화면을 하나씩 짚어 줘요.
5-2✍️ 내 프롬프트를 모든 AI 작업에
‘장기기억 분석’ 단계를 켠 내 프롬프트가 페르소나·AI 봇 제작 등 다른 AI 작업에도 정한 위치(앞·중간·뒤)로 들어가요. 프롬프트에 [Dusk.memory]를 적으면 기억 블록이 그 자리에 들어가요. 기억을 분석하거나 임베딩 질의를 만들 때 리수의 ‘요청 데이터 수정’ 정규식으로 상태창·HTML 군더더기를 먼저 지울 수도 있어요 (기본 꺼짐, 원본 채팅은 안 바뀌어요).
5-3🩹 고친 점·바뀐 점
· 봇·모듈 업데이트에서 정규식이 깨지던 문제를 고쳤어요
· AI로 제작은 편집 화면에서 저장해야 봇이 만들어져요
· 모바일: 위쪽 영역을 줄이고 버튼·칩·작은 글씨를 키웠어요
· 창 어디에 끌어놓아도 .rbupatch가 대상 봇·모듈을 찾아 바로 패치해요
· 페르소나 빌더에 우측 하단 AI 대화 창이 생겼어요 (대화만으로 설명을 바꾸지는 않아요)
· 인물 위키·홈 화면 반응 속도와 좁은 화면 글자 넘침을 고쳤어요
⚠️ 코코아의 세부 설정과 웹 도구는 설정 → 화면 모드 → 고급에서 보여요. 코코아·웹 도구는 기본이 꺼짐이라 켜기 전에는 아무것도 달라지지 않아요.
