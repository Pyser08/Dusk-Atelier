PART 1 · NEW
✨ 이번에 추가된 기능
네 가지 모두 기본은 꺼져 있거나, 누르기 전에는 아무것도 바뀌지 않아요.
1📊 자동 게이지 — 이름만 적으면 AI가 만들어 줘요NEW
인물 위키의 수치 상태 아래 + 게이지 추가에서 이름과 설명만 적으면 AI가 범위·변화 규칙·색과 모양까지 설계해요. 저장하기 전에 직접 고칠 수 있고, 저장해야만 만들어져요.
· 값과 변화 기록은 인물·채팅마다 따로 쌓여요
· 켜 둔 게이지는 응답 8개마다 기존 장기기억 분석에 얹혀 갱신돼요 (AI 호출이 늘지 않아요)
· 채팅 응답 아래, 로어북 버튼 바로 위에 게이지 박스가 붙어요. 모양은 구슬·고리·막대·눈금 4가지이고 게이지마다 색과 CSS가 달라요
· 게이지 관리에서 켜기/끄기·수정·삭제·JSON 내보내기·가져오기·마지막 변경 되돌리기 (변경 기록은 채팅당 100건)
· 자동 제안(기본 꺼짐): 켜면 하루 2개까지, 4시간 간격, 한 번에 1개만 새 게이지를 제안해요. 수락하면 모든 인물에게 만들어지고, “나중에”는 24시간 뒤에 다시 떠요
2🥥 코코아 — 스킬을 붙여 AI 응답의 결을 잡아요NEW
사이드바 기억 → 코코아 탭이 생겼어요. 코코아전트(cocoA(gent!))의 스킬 세트(ZIP·JSON)를 그대로 가져와 쓸 수 있고, 장기기억과 따로 켜고 끌 수 있어요. 기본은 꺼짐이에요.
· 간단 모드: 코코아 기능 켜기 토글, 스킬 목록(가져오기·새로 만들기·수정), 사용할 스킬 고르기
· 세트 안의 파일을 바로 고치고, 진단·주입 미리보기·ZIP/JSON 내보내기
· 켜면 고른 호출(관련 인물 고르기·정리 노트·기록하기·기억 분석)의 프롬프트 뒤에 스킬 지침이 붙어요. 별도 AI 호출은 없어요
· 스킬은 메인 채팅 프롬프트에는 들어가지 않아요
🤖 AI로 스킬 만들기 — 코코아 탭 오른쪽 아래 버튼을 누르면 AI와 대화하며 스킬 초안이 실시간으로 쌓여요. 점검한 뒤 라이브러리에 넣거나 ZIP·JSON으로 내보내요. 코코아전트의 스킬 가이드를 그대로 따르고, 메시지를 보낼 때마다 AI 호출이 한 번 생겨요.
고급 모드에서는 단계별 붙이기, 코코아전트에서 옮겨오기(같은 기기의 스킬 세트와 연결을 찾아 이어 줘요, 원본은 안 바꿔요), 웹 도구(검색·페이지 읽기, 기본 꺼짐, 필요할 때만 호출), 최근 호출 기록이 보여요.
3🧩 HypaPlus에서 가져오기 — 쌓은 기억을 버리지 않아요NEW
HypaPlus에 쌓아 둔 기억을 Dusk의 장면·인물 기록으로 옮겨요.
· 이벤트 → 장면 + 기록, 사실 → 기록, 즐겨찾기 → 고정·A등급
· 같은 기억은 두 번 들어가지 않고, 원본은 그대로 남아요
· 백업 파일로 가져오면 원래 메시지에 연결돼서 리롤·삭제를 따라가요
· 기억 탭에 처음 들어갔을 때 HypaPlus가 보이면 안내 창이 떠요. HypaPlus와 Dusk 기억은 동시에 쓸 수 없으니 한쪽만 켜 주세요 (설정에서 안내를 다시 볼 수 있어요)
4🤖 봇빌더 연동 — “AI로 봇 만들기”가 봇빌더로 이어져요NEW
봇빌더(risu_story_workshop)가 설치돼 있으면 AI로 봇 만들기가 봇빌더 화면을 열어요. 봇빌더에서 작업하고 Dusk로 돌아오면, 새로 등록한 봇(또는 고친 봇)이 개발 목록에 자동으로 들어가고 바로 이어서 편집할 수 있어요. 봇으로 등록하지 않은 원고는 새 봇으로 가져올지 물어봐요.
· 바로 열기는 연동판 봇빌더에서 돼요. 안내 창의 ‘연동판 받기’로 지금 설치된 봇빌더를 연동판으로 바꾼 파일을 받을 수 있어요 (원본 파일은 그대로)
· 원본 봇빌더 그대로여도 돌아왔을 때 가져오기는 돼요
· 봇빌더가 자동 업데이트되면 원본으로 돌아가요. 그땐 연동판을 다시 받아 주세요
· 공식 반영은 봇빌더 제작자분께 부탁드릴 예정이에요
📚 로어북 더스크화 — 규칙 설계 소속·장소 정리 다음 단계로, AI가 항목마다 조건·확률·한 번만·쉬기·유지·그룹·배치 깊이·연쇄·변수·이름 경계와 소속 확률을 설계해요. 내용·키·폴더는 바꾸지 않고, 미리보기에서 항목별로 이유를 보고 골라 적용해요.
PART 2
🔧 그 밖에 바뀐 것
작은 편의 기능과 화면 정리예요.
5🧭 처음 둘러보기가 한 번 더 떠요
이번 업데이트를 받거나 새로 설치하면 둘러보기가 자동으로 딱 한 번 떠요 (코코아 단계 추가). 그 뒤로는 홈의 ‘처음 둘러보기’나 설정에서 직접 열 때만 보여요. 화면 위쪽 ? 버튼도 팝업 대신 지금 화면을 하나씩 짚어 줘요.
6✍️ 내 프롬프트를 모든 AI 작업에
‘장기기억 분석’ 단계를 켠 내 프롬프트가 페르소나·AI 봇 제작 등 다른 AI 작업에도 정한 위치(앞·중간·뒤)로 들어가요. 프롬프트에 [Dusk.memory]를 적으면 기억 블록이 그 자리에 들어가요. 또 기억을 분석하거나 임베딩 질의를 만들 때 리수의 ‘요청 데이터 수정’ 정규식으로 상태창·HTML 군더더기를 먼저 지울 수 있어요 (기본 꺼짐, 원본 채팅은 안 바뀌어요).
7🩹 고친 점·바뀐 점
· 봇·모듈 업데이트에서 정규식이 깨지던 문제를 고쳤어요
· AI로 제작은 편집 화면에서 저장해야 봇이 만들어져요
· 모바일: 위쪽 영역을 줄이고 버튼·칩·작은 글씨를 키웠어요
· 창 어디에 끌어놓아도 .rbupatch가 대상 봇·모듈을 찾아 바로 패치해요
· 페르소나 빌더에 우측 하단 AI 대화 창이 생겼어요 (대화만으로 설명을 바꾸지는 않아요)
· 인물 위키·홈 화면 반응 속도와 좁은 화면 글자 넘침을 고쳤어요
⚠️ 코코아의 세부 설정과 웹 도구, 봇빌더 연동판 받기 안내 일부는 설정 → 화면 모드 → 고급에서 보여요. 코코아·웹 도구는 기본이 꺼짐이라 켜기 전에는 아무것도 달라지지 않아요.
