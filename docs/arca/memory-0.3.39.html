PART 0
🧭 사람다운 장기기억 — 한 걸음 더
처음부터 목표는 ‘기억 저장소’가 아니라 ‘사람처럼 기억하는 캐릭터’였어요.
사람의 기억은 완벽하지 않아요. 오래된 일은 흐려지고, 세부는 틀리고, 강렬했던 순간만 선명하게 남죠. 기분은 한 턴 만에 리셋되지 않고, 말버릇은 친해질수록 바뀌고, 쌓인 서운함은 엉뚱한 때 터져요. 장기기억은 이걸 하나씩 엔진으로 옮기는 중이에요.
지금까지 온 길
· 1단계 (지난 업데이트들) — 인물별 기억·감정 게이지·관계 종류·호칭과 말투·둘만의 추억·오해·몸과 마음 엔진·종족·날씨
· 2단계 (이번) — 기억을 바로잡을 수 있게. AI가 적은 모든 칸을 고치고, 지운 건 다시 안 적게. 늘어난 칸을 사람의 결대로 다시 묶은 탭. 감정·몸 묘사를 현실에 붙잡아 두는 지침
· 3단계 (다음) — 사람다움 항목을 하나씩 실험하고 통과한 것부터 넣어요
앞으로 넣을 사람다움 13가지
🌫️ 기억의 흐려짐 · 😮‍💨 기분 관성·컨디션 · 💬 말버릇 변화 · 🙃 모순·자기합리화 · 🏙️ 화면 밖 일상 · 📨 먼저 연락하기 · 🔥 쌓인 원한·고마움 · 🌱 성장 · 🤫 비밀·거짓말 · 🍓 사소한 취향 · 🛡️ 방어기제 · 💞 관계의 여러 축 · ❤️‍🔥 선호·불호
판단은 코드가(호출 없이), 기록기는 바뀐 것만 짧게, 묘사는 이번 턴에 드러낼 1~2개만 구체적인 행동으로 — 이 원칙은 그대로예요. 묘사가 실제로 잘 되는지 먼저 실험하고, 안 되는 건 넣지 않아요.
PART 1
✏️ 기억을 바로잡다 — 모든 칸 편집
AI가 잘못 적었으면, 그냥 고치면 돼요.

✎
STEP 1 · ROWS
어디서나 같은 편집 줄
칸마다 달랐던 고치는 방식을 하나로 맞췄어요. 한 번 익히면 어디서나 똑같아요.
· 줄마다 ✎ 고치기 — 여러 칸을 한 창에서 한 번에(예전처럼 작은 창이 줄줄이 뜨지 않아요)
· 줄마다 ✕ 지우기, 목록 아래 + 추가로 직접 적기
· 마지막으로 바꾼 건 ↶ 되돌리기로 한 번에 원래대로
· 날짜는 ‘3월 14일’처럼 써도 알아서 3/14로 맞춰요

STEP 2 · IGNORE
지운 건 다시 안 적어요 · 고친 건 잠그지 않아요
· 지우면 무시 목록에 들어가서, 기록기가 같은 내용을 보내도 프로그램이 걸러요
· 오래 막을 필요 없는 건 짧게 — 몸 흔적 며칠, 상태이상 며칠. 소문·목표·추억·갈등·오해·캘린더·장소는 계속
· 같은 걸 다시 직접 추가하면 막아 둔 것도 풀려요
· 고친 값은 잠그지 않아요. 거기서부터 이야기에 따라 계속 바뀌어요 — 사람이 누가 바로잡아 준 기억을 바탕으로 다시 살아가듯이
💡 편집은 로컬 저장소일 때 보여요(BardWiki 저장이면 그쪽 규칙을 따라요).
📖 새로 고칠 수 있게 된 칸 전체 보기 (눌러서 펼치기)
인물 · 기본
· 상태이상 — 상태·정도·남은 날 고치기 (예전엔 추가·지우기만)
· 옷차림 액세서리 — 고치기 추가
인물 · 관계
· 관계 연표 — 전환점 직접 적기·고치기, 기록된 사건은 연표에서 숨기기
· 둘만의 추억 — 직접 추가
· 갈등 — 무엇 때문에·상태·앙금 고치기, 직접 추가
· 오해 — 누가·잘못 아는 것·실제 고치기, 직접 추가
· 기대 차이 — 서로의 기대·말로 했는지 고치기·지우기
인물 · 기억
· 일기 — 쓴 일기 보기·고치기·지우기 (새 칸)
인물 · 성인
· 몸 흔적 — 부위·흔적·남는 날 고치기
· 출산·유산 이력 — 지우기
세계
· 소문 — 직접 추가·고치기
· 목표 — 목표 글·진척·상태 고치기, 직접 추가
· 장소·물건·세력 — 이름 고치기
· 캘린더 — 생일·연인·약속·특별한 날 (새 화면)
· 날씨·기후 — 기후대·반구·지역·달력·지금 날씨 (새 화면)
설정
· 묘사 지침 — 켜기·끄기, 조각 찾기·끄기·직접 쓰기 (새 화면)
마음 흐름·짝사랑·기억에 남은 순간·장면 계획은 다른 값으로 계산되는 칸이라, 감정·수치·항목 관리에서 원래 값을 고치면 따라 바뀌어요.

STEP 3 · RELATION
관계 연표 · 추억 · 갈등 · 오해를 직접
