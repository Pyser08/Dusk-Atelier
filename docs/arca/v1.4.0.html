플러그인 탭이 생겼어요
설치한 플러그인을 한곳에서 정리하고, 연동한 플러그인의 설정을 Dusk Atelier에서 바로 바꿔요. 연동되는 플러그인을 직접 만들 수도 있어요. 봇·모듈의 정규식과 트리거 Lua 칸도 코드 편집기처럼 바뀌었어요.
플러그인 목록 연동 설정 플러그인 만들기 저장소 코드 편집기
🙏
플러그인 개발자분들의 도움이 필요해요
이번 업데이트의 핵심인 연동 설정은 각 플러그인 제작자분이 짧은 연동 코드를 넣어 주셔야 쓸 수 있어요. 제작자분이라면 글 아래 개발자용 부분을 꼭 한 번 봐 주세요. 쓰시는 플러그인 제작자분께 이 글을 알려 주셔도 큰 도움이 돼요.
설치·업데이트
이미 쓰고 있다면 RisuAI 설정 → 플러그인에서 Dusk Atelier 옆 초록색 + 버튼을 누르면 v1.4.0으로 올라가요. 처음이라면 아래 파일을 받아 플러그인 가져오기로 넣어 주세요.
dusk_atelier.js 받기 ↓
무엇이 바뀌었나
플러그인 탭은 모듈 탭 바로 아래에 있어요. 안에서 네 가지 화면을 오가요.
01 · 목록
플러그인을 묶어서 보기
카테고리를 붙여 묶어 보고, 업데이트 주소가 있는 플러그인은 새 버전이 있는지 확인해요. 목록을 파일로 내보낼 수도 있어요.
02 · 연동 설정
다른 플러그인 설정을 여기서
연동 코드가 들어간 플러그인은 설정 화면이 자동으로 생겨요. 값을 바꾸거나 프리셋을 누르면 바로 적용돼요.
03 · 만들기
연동되는 플러그인 만들기
템플릿이 미리 들어 있어서 이름만 바꾸고 기능만 채우면 돼요. 칸마다 ? 도움말이 있어요.
04 · 저장소
플러그인 저장값 들여다보기
플러그인들이 저장해 둔 값을 플러그인별로 묶어 보고, 내려받거나 지울 수 있어요.
연동 설정은 이렇게 움직여요
1
플러그인이 스스로 등록해요. 연동 코드가 들어간 플러그인은 켜질 때 "나는 이런 설정이 있어요"를 남겨요.
2
Dusk Atelier가 화면을 만들어요. 켜기/끄기, 슬라이더, 선택지, 글 칸, 색 고르기까지 자동으로 생겨요.
3
적용을 누르면 플러그인이 받아서 반영해요. 몇 초 안에 "적용됐어요"가 뜨고, 오류가 나면 그 내용도 보여 줘요.
🧩
연동 목록이 비어 있다면? 아직 연동 코드를 넣은 플러그인이 없어서 그래요. 연동되는 플러그인이 늘어날수록 이 화면이 쓸모 있어져요. 개발자분들의 참여가 꼭 필요한 부분이에요.
플러그인 만들기
코드를 처음부터 쓸 필요가 없어요. 이름·표시 이름·버전·연동 id만 적으면 코드 안의 해당 줄이 같이 바뀌고, 플러그인 기능만 채우면 돼요.
① 머리말RisuAI가 읽는 이름·버전 줄. 위 칸을 고치면 자동으로 바뀌어요.
② 스니펫Dusk Atelier와 값을 주고받는 공용 코드. 건드리지 않아도 돼요.
③ 본체플러그인이 실제로 할 일을 쓰는 곳.
④ 등록설정 항목·프리셋·적용 방법. 예시가 미리 들어 있어요.
다 쓰면 검사로 빠진 곳을 확인하고, 설치를 누르면 RisuAI 확인 창을 거쳐 바로 들어가요. 내려받기로 파일만 받을 수도 있어요.
🛠️
만들 줄 아신다면 함께 만들어 주세요. 이미 배포 중인 플러그인에 연동 코드만 넣어 주셔도 사용자분들이 훨씬 편해져요. 새 플러그인을 만들어 공유해 주시는 것도 대환영이에요.
코드 편집기 · 괄호 짝 표시
봇·모듈 편집의 정규식 IN/OUT, 트리거 Lua 코드, 플러그인 만들기 칸이 코드 프로그램처럼 색으로 구분돼요. 괄호를 누르면 짝이 되는 괄호가 같이 표시되고, 짝이 없으면 빨간색으로 보여요.
IN (img|div)\s+src="([^"]+)" OUT <img src="$2"> {{getvar::name}}
밝게 칠해진 두 괄호가 서로 짝이에요.
플러그인 켜기/끄기는 왜 없나요?
요즘 RisuAI와 리스바드는 보안 때문에 플러그인이 다른 플러그인을 켜고 끄거나, 순서·코드를 바꾸지 못하게 막고 있어요. Dusk Atelier도 이 규칙을 지켜서 그런 기능은 넣지 않았어요. 대신 각 플러그인이 스스로 설정을 받아 적용하는 방식(연동 설정)을 만들었어요. 이 방식은 제작자분들이 함께해 주셔야 넓어질 수 있어요.
FOR DEVELOPERS
개발자용 — 연동 코드 넣는 법
플러그인 하나당 코드 블록 하나와 등록 몇 줄이면 끝나요. RisuAI 공식 플러그인 API(pluginStorage)만 쓰고, 보안 우회는 전혀 하지 않아요. Dusk Atelier가 없는 사용자 환경에서도 아무 문제 없이 돌아가요.
1생성기에서 id·설정 항목·프리셋을 적고 코드를 만들어요.
2플러그인 코드에 붙여 넣어요. 등록 코드(registerInterop)는 스니펫보다 아래에 둬요.
3getValues(지금 값 알려 주기)와 apply(받은 값 저장·반영)만 채우면 돼요.
스니펫 생성기 열기 → 규격·예제 (GitHub)
연동 확인용 테스트 플러그인(examples/da_interop_test.js)도 같은 저장소에 있어요.
