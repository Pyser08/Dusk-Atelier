📖 처음이라면 — Dusk Atelier 사용 가이드 (눌러서 펼치기)
Dusk Atelier는 RisuAI의 모듈·봇을 관리하고 업데이트하는 플러그인이에요. 수백 MB짜리 봇·모듈도 바뀐 부분만 받아 업데이트하고, 내가 고친 부분과 채팅은 그대로 지켜요. 원본 RisuAI와 PocketRisu·RisuBard에서 써요.
시작하기
1
아래 설치 버튼으로 dusk_atelier.js를 받아 RisuAI 설정 → 플러그인에 추가해요.
2
왼쪽 사이드바(햄버거 메뉴)의 Dusk Atelier를 눌러 열어요. 설정 메뉴에서도 열려요.
3
새 버전이 나오면 설정 → 플러그인의 초록색 + 버튼 하나로 업데이트돼요.
업데이트하는 세 가지 방법
리스에서 그냥 가져오기
평소처럼 봇·모듈을 가져오거나 리스 화면에 끌어다 놓으면, 기존 것의 새 버전인지 알아보고 이어 붙일지 물어요. 새 봇이면 오른쪽 위 알림으로 다른 봇과 합칠지 물어요.
새 버전 파일
Dusk의 가져오기에 .charx · .risum · PNG 카드 · .json을 넣으면 이미 있는 봇·모듈을 찾아서 업데이트해요. 여러 파일도 차례대로 처리해요.
패치 파일
제작자가 올린 작은 .rbupatch 파일이라면 모듈 ⋯ 메뉴나 봇 메뉴의 패치 적용으로 넣어요.
어느 쪽이든 지난번 받은 파일·지금·새 버전을 비교해서 제작자가 바꾼 건 새 버전으로, 내가 고친 건 그대로 둬요. 같은 곳을 둘 다 고쳤으면 충돌로 알려 주고 항목마다 골라요. 바꾸기 전 상태는 자동으로 백업돼요.
탭 다섯 개
모듈
켜기·끄기(8초 안에 되돌리기), 폴더·이름 색, 검색·필터, 끌어서 순서 바꾸기, 글로벌·페르소나별·캐릭터별 연결. ⋯ 메뉴에 편집·에셋·내보내기·패치 적용·삭제가 있어요.
캐릭터
리스 사이드바와 같은 폴더·순서를 써요. 여기서 바꾸면 사이드바도 바로 바뀌어요. 봇 편집, 에셋 정리, 업데이트·패치, 다른 봇에서 가져오기·합치기를 해요.
프리셋
켜고 끌 모듈 조합과 순서를 묶어 저장하고 버튼 하나로 바꿔요. 모바일용·PC용을 정해 두면 기기에 따라 알아서 바꿔요.
기록
업데이트·편집·삭제 전 상태가 쌓여요. 지금과 비교하거나 그 시점으로 되돌려요. 되돌려도 채팅은 그대로예요.
도구
업데이트 가져오기, 업데이트 설정(자동 감지·채팅 백업), 색 바꾸기, 전체 백업·복원, .risum 인스펙터, 설정 정리, 개발자 모드.
에디터 · 에셋 관리자
로어북·정규식·트리거를 탭으로 나눠 항목별로 고쳐요. 찾기 Ctrl+F, 저장 Ctrl+S, 정규식 오류·키 없는 로어북은 미리 알려 주고, 저장 전에 바뀐 내용을 요약해 보여 줘요. 에셋 관리자는 폴더, 여러 개 고르기, 일괄 교체, ZIP 받기, WebP 최적화, 캐릭터·의상별 목록 보기를 지원해요.
모바일에서도 그대로
탭은 아래로, 상세 정보는 아래에서 올라오는 시트로 바뀌어요. 손잡이를 잡고 끌어 순서를 바꾸거나 폴더에 넣을 수 있어요.
알아 두면 좋은 것
· 봇이 답변을 만드는 중에는 업데이트·저장을 막아요. 끝난 뒤 다시 눌러 주세요.
· 꺼 둔 모듈은 Dusk 보관함에 있어요. 플러그인을 지우기 전에 도구 → 설정 정리 → 꺼진 모듈 모두 켜기로 꺼내 주세요.
· 개발자 모드를 켜면 바뀐 부분만 담은 패치 파일을 만들어 배포할 수 있어요. 자세한 건 v1.0.0 소개글에 있어요.

🙏 플러그인 개발자분들의 도움이 필요해요
이번 업데이트의 핵심인 연동 설정은 각 플러그인 제작자분이 짧은 연동 코드를 넣어 주셔야 쓸 수 있어요. 제작자분이라면 아래 6. 개발자분들께를 꼭 봐 주세요. 쓰시는 플러그인 제작자분께 이 글을 알려 주셔도 큰 도움이 돼요.
1모듈 탭 아래에 플러그인 탭
모듈 탭 바로 아래에 새 탭이 생겼어요. 안에서 네 화면을 오가요.
목록 · 설치한 플러그인을 카테고리로 묶어 봐요. 업데이트 주소가 있는 플러그인은 새 버전이 있는지 확인하고, 목록을 파일로 내보낼 수 있어요.
연동 설정 · 연동 코드가 들어간 플러그인의 설정 화면이 자동으로 생겨요.
만들기 · 연동 코드가 들어간 플러그인을 바로 만들어요.
저장소 · 플러그인들이 저장해 둔 값을 플러그인별로 묶어 보고, 내려받거나 지울 수 있어요.
2다른 플러그인 설정을 여기서
연동 코드(DA Interop)가 들어간 플러그인은 켜질 때 스스로 "이런 설정이 있어요"를 남겨요. Dusk Atelier는 그걸 읽어서 설정 화면을 알아서 만들어요.
· 켜기·끄기, 숫자, 슬라이더, 고르기, 글 칸, 색 고르기까지 자동으로 만들어져요.
· 프리셋 버튼 하나로 여러 값을 한꺼번에 바꿔요.
· 적용을 누르면 그 플러그인이 받아서 반영하고, 몇 초 안에 "적용됐어요"를 알려 줘요. 오류가 나면 그 내용도 보여 줘요.
🙏 연동 목록이 비어 있다면, 아직 연동 코드를 넣은 플러그인이 없어서 그래요. 연동되는 플러그인이 늘어날수록 이 화면이 쓸모 있어져요. 개발자분들의 참여가 꼭 필요한 부분이에요.
3연동되는 플러그인 만들기
코드를 처음부터 쓸 필요가 없어요. 이름·표시 이름·버전·연동 id만 적으면 코드 안의 해당 줄이 같이 바뀌고, 플러그인 기능만 채우면 돼요.
① 머리말 · RisuAI가 읽는 이름·버전 줄. 위 칸을 고치면 자동으로 바뀌어요.
② 스니펫 · Dusk Atelier와 값을 주고받는 공용 코드. 건드리지 않아도 돼요.
③ 본체 · 플러그인이 실제로 할 일을 쓰는 곳.
④ 등록 · 설정 항목·프리셋·적용 방법. 예시가 미리 들어 있어요.
· 칸·구역마다 ? 버튼이 있어요. 누르면 무엇을 넣는지 예시와 함께 보여 주고, 코드에서 그 줄로 이동해요.
· 검사로 빠진 곳을 확인하고, 설치를 누르면 RisuAI 확인 창을 거쳐 바로 들어가요. 내려받기로 파일만 받을 수도 있어요.
· 쓰던 코드는 자동으로 임시 저장돼요.
🙏 만들 줄 아신다면 함께 만들어 주세요. 이미 배포 중인 플러그인에 연동 코드만 넣어 주셔도 사용자분들이 훨씬 편해져요. 새 플러그인을 만들어 공유해 주시는 것도 대환영이에요.
4코드 편집기 · 괄호 짝 표시
봇·모듈 편집의 정규식 IN/OUT, 트리거 Lua 코드, 플러그인 만들기 칸이 코드 프로그램처럼 색으로 구분돼요.
IN (img|div)\s+src="([^"]+)" OUT <img src="$2"> {{getvar::name}}
밝게 칠해진 두 괄호가 서로 짝이에요.
· 정규식은 이스케이프·문자 묶음·그룹·반복을, 바꿀 내용은 $1·{{CBS}}·HTML을, Lua는 키워드·함수·문자열을 다른 색으로 보여 줘요.
· 괄호를 누르면 짝이 되는 괄호가 같이 밝아지고, 짝이 없으면 빨갛게 보여요. 겹친 CBS도 제 짝을 찾아요.
· 줄 번호가 생기고, CBS 사전에서 누르면 커서 자리에 넣는 것도 그대로 돼요.
5플러그인 켜기·끄기는 왜 없나요?
요즘 RisuAI와 리스바드는 보안 때문에 플러그인이 다른 플러그인을 켜고 끄거나, 순서·코드를 바꾸지 못하게 막고 있어요. Dusk Atelier도 이 규칙을 지켜서 그런 기능은 넣지 않았어요.
⚠ 대신 각 플러그인이 스스로 설정을 받아 적용하는 방식(연동 설정)을 만들었어요. 이 방식은 제작자분들이 함께해 주셔야 넓어질 수 있어요.
6개발자분들께
플러그인 하나당 코드 블록 하나와 등록 몇 줄이면 끝나요. RisuAI 공식 플러그인 API(pluginStorage)만 쓰고, 보안 우회는 전혀 하지 않아요. Dusk Atelier가 없는 사용자 환경에서도 아무 문제 없이 돌아가요.
1. 만들기 · 생성기에서 id·설정 항목·프리셋을 적고 코드를 만들어요.
2. 붙이기 · 플러그인 코드에 붙여 넣어요. 등록 코드(registerInterop)는 스니펫보다 아래에 둬요.
3. 채우기 · getValues(지금 값 알려 주기)와 apply(받은 값 저장·반영)만 채우면 돼요.
스니펫 생성기 열기 → 규격·예제 (GitHub)
연동 확인용 테스트 플러그인(examples/da_interop_test.js)도 같은 저장소에 있어요.
🧩 registerInterop 예제와 설명 (눌러서 펼치기)
말투를 바꾸는 가상의 플러그인 예제예요. ① 스니펫 → ② 등록 → ③ 갱신 순서로 붙이면 돼요. 스니펫(생성기에서 받는 공용 코드)은 등록 코드보다 반드시 위에 있어야 해요.
// ① 생성기에서 받은 스니펫을 먼저 붙여 넣고, 그 아래에 씁니다 const risu = globalThis.risuai ?? globalThis.Risuai; const KEY = 'my_plugin:settings'; // 저장 키는 '플러그인이름:' 으로 시작 const DEFAULTS = { enabled: true, tone: 'soft', strength: 0.5 }; async function loadSettings() { try { return { ...DEFAULTS, ...JSON.parse((await risu.pluginStorage.getItem(KEY)) || '{}') }; } catch { return { ...DEFAULTS }; } } // ② 등록: Dusk Atelier에 설정 화면을 만들어 달라고 알려요 const interop = registerInterop({ id: 'my-plugin', // 연동 이름표 (한 번 정하면 바꾸지 않기) name: '내 플러그인', // Dusk 화면에 보일 이름 version: '1.0.0', pluginName: 'my_plugin', // //@name 과 같게 description: '답변 말투를 바꿔요', fields: [ { key: 'enabled', label: '사용', type: 'toggle', default: true }, { key: 'tone', label: '말투', type: 'select', default: 'soft', options: [{ value: 'soft', label: '부드럽게' }, { value: 'firm', label: '단호하게' }] }, { key: 'strength', label: '세기', type: 'slider', default: 0.5, min: 0, max: 1, step: 0.1, group: '고급' }, ], presets: [ { name: '단호하게', values: { tone: 'firm', strength: 0.9 } }, ], getValues: loadSettings, // 지금 값을 Dusk에 보여 줘요 apply: async (values, ctx) => { // Dusk에서 [적용]을 누르면 불려요 await risu.pluginStorage.setItem(KEY, JSON.stringify({ ...DEFAULTS, ...values })); // ctx.preset: 프리셋으로 적용했다면 그 이름 }, }); // ③ 플러그인 안에서 값을 바꿨다면 Dusk 화면도 갱신 async function onMySettingChanged() { (await interop)?.refresh(); }
항목 설명
id 필수 Dusk가 이 플러그인을 찾는 이름표예요. 영소문자·숫자로 시작하고 . - _만 써요(2~64자). 한 번 정하면 바꾸지 마세요. 바꾸면 새 플러그인으로 보여요.
apply 필수 Dusk에서 [적용]이나 프리셋을 누르면 (values, ctx)로 불려요. 받은 값을 직접 저장하고 반영하세요. 같은 값은 한 번만 와요. 여기서 오류를 던지면 Dusk 화면에 오류로 표시돼요.
name 선택 Dusk 연동 목록에 보일 이름. 없으면 id를 써요.
pluginName 선택 파일 맨 위 //@name과 같게 적으면, 플러그인 목록에서 이 플러그인 옆에 "연동" 표시가 붙어요.
version 선택 표시용 버전.
description 선택 설정 화면 위에 보일 한 줄 설명.
fields 선택 설정 칸 목록. key(값 이름), label(보일 이름), type, default. 같은 group끼리 묶이고, description은 작은 설명이 돼요.
presets 선택 버튼 한 번으로 바꿀 값 묶음. values에는 바꿀 key만 적으면 되고, 나머지는 지금 값 그대로예요.
getValues 선택 지금 값을 돌려주는 함수. 없으면 각 칸의 default를 보여 줘요.

'toggle'

'number'

'slider'

알아 둘 것
· registerInterop은 refresh()를 가진 객체를 돌려줘요. 플러그인 안에서 값이 바뀌면 불러 주세요. Dusk 화면이 새 값으로 바뀌어요.
· 플러그인 저장소(pluginStorage)는 모든 플러그인이 함께 써요. 자기 저장 키 앞에 플러그인이름:을 붙여 겹치지 않게 해 주세요.
