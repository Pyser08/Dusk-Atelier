FEATURE 1 · NEW LOOK
🎨 새 화면 · 꾸미기 · 시작 안내
모든 탭을 목업부터 다시 그려서 다듬었어요. 같은 내용은 한 번만, 자주 쓰는 것만 카드로, 가끔 쓰는 버튼은 ··· 메뉴로 모았어요. 모든 화면의 ? 도움말은 그대로예요.
1-1🧭 시작 안내NEW
처음 열면 플러그인 창을 꽉 채운 안내가 떠요.
· 화면 모드·글자 크기 → 꾸미기 → 장기 기억(기록할 AI·수준·임베딩) → 이야기 도우미 → 이미 쓰던 것(HypaPlus·코코아전트·RisuPot) → 요약
· 고르는 즉시 적용되고, 이미 쓰던 분은 지금 설정이 골라진 채로 시작해요(아무것도 초기화하지 않아요)
· 이 버전을 처음 열 때 한 번만 떠요. 설정 → 도움말 → ‘시작 안내 다시 보기’로 다시 볼 수 있어요
1-2🖌️ 플러그인 꾸미기 대폭 확장NEW
· 테마 묶음 12개(+🎲 아무거나) · 강조 색 18개(따뜻한/차분한/파스텔) · 그라데이션 8개와 방향
· 밝기 ‘시간 따라’, 글자 크기 ‘아주 크게’
· 모서리·그림자·테두리·글꼴·글자 굵기·줄 높이·아이콘 굵기·바탕 무늬·카드 유리 효과·움직임 줄이기
· 고급 모드에서는 바탕·카드·글자·사이드바 색을 직접 골라요(읽기 어려운 조합은 대비를 자동으로 맞춰요)
· 내 테마를 여러 개 저장하고, 밝을 때/어두울 때 따로 쓰고, 테마 코드로 주고받아요. 예전 테마는 그대로 열려요
1-3🏠 홈 · 개요
· 맨 위 카드에 장기 기억 상태·스위치와 숫자, 작은 바로가기 4칸, ‘이어서 하기’ 칩
· 기억·관리·작업실 개요는 목록 줄에 한 줄 요약과 개수
· 위쪽 설정 버튼 아이콘을 새 톱니바퀴로 바꿨어요
1-4🗂️ 탭마다 정리
· 장기 기억: 상태 카드 하나에 스위치·숫자·막대, ‘지난 대화 분석’만 큰 버튼. 채팅을 안 열어도 기억 설정을 바꿀 수 있어요
· 코코아: ‘사용할 스킬’과 ‘스킬 세트’를 한 목록으로, ZIP·JSON·삭제는 ··· 메뉴
· 기억 카드: 봇·채팅은 한 줄 카드, 단계는 동그라미 진행 표시, PC는 오른쪽 미리 보기
· 캐릭터·모듈: 줄에는 ‘편집’과 ···만, 지금 채팅의 봇에 ‘지금 채팅’ 라벨, 모듈 필터 ‘전체·켜짐·꺼짐’ + ‘종류’
· 도구: 자주 쓰는 도구·확인·복구 목록, 도움 주신 분들은 스페셜 땡스 카드로
· 설정·AI로 봇 만들기·AI로 페르소나 만들기도 같은 방식으로 정리했어요
FEATURE 2 · MEMORY
🧠 사람다운 기억
장기 기억이 ‘무슨 일이 있었나’만이 아니라 사람 사이에서 실제로 일어나는 일을 기억해요. AI 호출은 늘지 않아요 — 기존 분석에 짧게 얹었어요.
2-1🤝 관계가 천천히 쌓여요NEW
두세 턴 만에 갑자기 친해지는 일을 줄여요.
· 관계 진도 — 함께한 장면 수와 애정·신뢰로 ‘처음 봄 · 아는 사이 · 친한 사이 · 아주 가까운 사이’를 알려 줘요
· 호칭·말투 — 누가 누구를 뭐라고 부르는지, 존댓말인지 반말인지. 바뀌면 이전 것도 함께
· 둘만의 추억 — 둘이 함께 나오면 다시 꺼낼 만한 순간을 하나 슬쩍
· 갈등·사과·앙금 — ‘안 풀림 → 사과함 → 화해함’을 따라가고, 깊은 앙금은 남아요
· 사람 앞 태도 — 둘이 있을 때와 남들 앞에서 태도가 다른 인물
· 오래 안 나오던 인물의 재등장, 외모·성격·처지 변화(‘지금은 B, 전에는 A’), 흐려지는 사소한 기억
2-2🌡️ 감정이 시간이 지나면 식어요NEW
적대감·두려움은 빨리, 의존·애정은 천천히 누그러지고, 신뢰·존경은 행동으로만 바뀌어요.
· 깊은 원한은 조금 남아요
· 직접 정한(잠근) 값은 그대로예요
2-3🕵️ 거짓말·오해 추적NEW
기본 꺼짐. 켜면 누가 무엇을 잘못 믿고 있는지(진실은 무엇인지, 누가 속였는지)를 기억해서, 속은 인물이 진실을 알기 전까지 그 믿음대로 행동하게 해요.
· 추리·드라마 봇에 알맞아요. 분석 모델이 약하면 틀릴 수 있어요
· 세 기능 모두 기억 화면의 ‘기억 옵션’ 카드에서 켜고 꺼요(간단 모드에서도)
2-4🙋 나에 대한 기억NEW
장기 기억 화면의 나에 대한 기억에서 다른 인물들이 나를 어떻게 보는지 한눈에 봐요.
· 인물마다 관계 진도, 나에게 느끼는 감정, 나를 부르는 말·말투, 둘이 있을 때/남들 앞 태도, 둘만의 추억, 갈등·오해
· 고치기로 호칭·말투·감정 수치를 바로 고쳐요. 고친 값은 잠겨서 다음 분석이 바꾸지 않아요
· 예전에 페르소나 이름(또는 user·유저)으로 따로 쌓인 기록이 있으면 맨 위에 알려 주고, 미리 보기를 확인한 뒤 나로 합치기로 모을 수 있어요
· 장기 기억이 {{user}}를 ‘나’로 분명히 알아들어요. AI가 페르소나 이름으로 적어도 한 사람으로 모아 기록해요
2-5📖 인물 위키 개편NEW
정보가 많아져도 보기 쉽게 ‘요약 / 관계 / 상세 정보 / 기록’ 탭으로 나눴어요.
· 요약: 지금 모습, 달라진 점, 상대별 관계 진도, 기억에 남은 순간, 수치 한눈에
· 관계: 상대를 고르면 진도·감정(식은 정도 포함)·호칭·추억·기대 차이·오해·갈등·사람 앞 태도
· 상세 정보: 값 있는 것만 카드로, 비어 있는 항목은 맨 아래 칩으로. 카드 높이가 달라도 빈 공간 없이 붙어요
· 감정·호칭·추억은 직접 고칠 수 있고 잘못된 기록은 지울 수 있어요
FEATURE 3 · STORY
🎲 이야기 도우미
‘유저 편향 없애기’가 주사위로 성패를 가르는 기능이었다면, 이번엔 그 주사위를 믿을 수 있게 만들었어요. 강도를 고르고, 리롤로 결과를 바꿀 수 없고, 판정이 다음 턴까지 이어져요.
3-1🎚️ 강도 고르기NEW
홈 빠른 설정의 유저 편향 없애기가 스위치 대신 박스가 됐어요. 누르면 상세 창이 열려요.
· 약하게 · 보통 · 강하게 — 강할수록 난이도 목표치가 높아 실패가 늘어요. ‘보통’은 예전과 똑같아요
· 고급 모드에서는 난이도 수치(쉬움·보통·어려움·극악)와 주사위 개수(1~6)를 직접 넣을 수 있어요
· ?를 누르면 작동 방식을 볼 수 있고, 시작 안내 4단계에서도 같은 창이 열려요
· 켜면 공정한 전개도 함께 켜져요(그 위에서 작동하는 기능이라서요)
3-2🔒 리롤해도 같은 주사위NEW
같은 턴을 다시 생성하면 같은 주사위 값을 써요. 마음에 드는 판정이 나올 때까지 리롤하는 걸 막아요.
· 새 입력을 보내야 새로 굴려요
· 장기 기억·이야기 시간처럼 Dusk가 넣는 내용이 조금 달라져도 대화가 같으면 같은 턴으로 봐요
· 프롬프트가 그대로라 캐시도 덜 깨져요
3-3📌 판정 결과 이어 주기NEW
AI가 응답 끝에 판정한 행동마다 화면에 안 보이는 표식을 남겨요. 다음 턴에 그 결과를 다시 알려 줘서, 실패한 일을 없던 일처럼 넘기지 않게 해요.
· 예: 경비병 설득 · 어려움 · 62 · 실패 → 다음 턴에 “지난 판정: 설득 실패”
· 표식은 장기 기억 분석에는 보내지 않아요
· 모델이 표식을 남기지 않으면 예전처럼 동작해요(모델에 따라 달라요)
3-4🎯 주사위 결과 표시 · 판정 기록NEW
홈 주사위 결과 표시(기본 꺼짐)를 켜면 응답 아래에 주사위가 굴러가는 모양과 판정이 나와요.
· 판정 표식이 있으면 실제 행동·난이도·목표치와 결과를, 없으면 난이도별 ‘대실패·실패·애매·성공·대성공’ 표를 보여 줘요
· 유저 편향 상세 창의 최근 판정 기록에서 이 채팅/전체로 굴린 값과 평균·판정 개수를 볼 수 있어요
· 저장된 채팅 글은 바뀌지 않아요(화면에만 붙어요)
3-5💬 채팅 메뉴에서 바로 켜고 끄기NEW
채팅 입력창 옆 메뉴(≡)에 공정한 전개 · 꺼짐 같은 버튼이 생겨요. 누를 때마다 켜고 끄고, 이름도 그 자리에서 바뀌어요.
· 공정한 전개 · 유저 편향 없애기 · 주사위 결과 표시
· 설정 → 로어북 · 채팅 메뉴에서 숨길 수 있어요
FEATURE 4 · CACHE
⚡ 프롬프트 캐시 지키기
‘캐시 잘 되는 프롬을 써도 이상하게 캐시가 박살 난다’는 제보의 원인을 찾아 고쳤어요. 그리고 캐시가 깨지면 바로 알 수 있게 했어요.
4-1🩹 유저 편향을 켜면 캐시가 깨지던 문제FIX
요청마다 바뀌는 주사위 값이 프롬프트 앞쪽에 들어가서, 그 뒤 채팅 기록 전체가 매번 새 프롬프트가 됐어요. 공정한 전개만 켰을 때는 지침이 매번 같아서 괜찮았던 거예요.
· 이제 바뀌지 않는 규칙은 앞에, 주사위 값만 마지막 입력 바로 앞에 따로 넣어요
· Claude는 리스가 마지막 입력과 합쳐 보내기 때문에, 주사위 바로 앞 응답에 캐시 지점을 하나 찍어 그 앞까지는 다음 턴에 다시 쓰이게 했어요(최대 4개 안에서)
· 결과 처리 ‘재해석·존중’ 어느 쪽이든 같아요
4-2⏱️ 모델 호출 표시NEW
홈 모델 호출 표시(기본 꺼짐)를 켜면 요청할 때 화면 구석에 상태가 떠요.
· 메인/보조 구분 · 모델 이름 · 추론 중/출력 중 · 흐른 시간

4-4🚪 탭 이동이 가벼워졌어요

· 시작 안내 위에서 여는 창이 뒤에 가려지던 문제, 창 위에 창을 연 상태에서 Esc가 둘 다 닫던 문제
· 모바일에서 페르소나 ‘AI 대화’ 버튼이 아래 탭바를 가리던 문제, 아이콘이 엉뚱하게 보이던 문제
· 봇별 기억에서 스위치를 바꾼 뒤 검색하면 예전 값으로 보이던 문제
· 장기 기억 분석에서 ‘내 프롬프트 · 뒤’가 맨 끝에 오지 않던 문제
· 모델 호출 표시의 칩이 응답이 안 오면 사라지지 않던 문제 등
