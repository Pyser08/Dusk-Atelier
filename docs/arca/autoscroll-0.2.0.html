ADDON · 📜 오토 스크롤
긴 응답,
이제 스크롤은 맡겨 두세요.
오토 스크롤은 AI 응답을 정한 속도로 천천히 내려 주는 애드온이에요. 응답 맨 위의 버튼을 한 번 누르면, 손가락이나 휠을 대지 않아도 읽는 속도에 맞춰 화면이 부드럽게 내려가요. PC·모바일 모두 돼요.
버튼 1번
누르면 끝까지
10~400
초당 픽셀 속도
PC·모바일
어디서나

⬇️
STEP 1 · INSTALL
준비하기 — 받고 빠른 설정에서 켜기
· Dusk 화면에서 홈 → 애드온 → 관리의 오토 스크롤을 받아요
· 홈 빠른 설정 맨 아래 ‘오토 스크롤’ 줄을 눌러 사용하기를 켜요
· 처음 켤 때 리스가 화면 접근 허락을 한 번 물어봐요 — 허락해야 채팅에 버튼을 달 수 있어요
[ 이미지: 빠른 설정의 오토 스크롤 줄과 설정 창 ]

▶️
STEP 2 · READ
읽기 — 버튼 누르고 그냥 보기만
켜 두면 채팅의 마지막 AI 응답 맨 위에 ▼ 오토 스크롤 버튼이 생겨요.
· 새 응답이 오면 생성이 끝난 뒤 그 응답으로 버튼이 옮겨 가요
· 누르면 정한 속도로 내려가고, 화면 위에 − 속도 + ■ 막대가 떠요 — 읽다가 바로 빠르게·느리게
· ■를 누르거나, 버튼을 다시 누르거나, 채팅을 터치·클릭하면 멈춰요
· 응답 끝에 닿으면 저절로 멈춰요
[ 이미지: 응답 위 버튼과 내려가는 중 막대 ]

⚙️
STEP 3 · TUNE
설정 — 속도와 좌우 스크롤 막기
빠른 설정의 오토 스크롤 줄을 누르면, 유저 편향 없애기처럼 설정 창이 열려요. 설정 탭에서도 같은 걸 바꿀 수 있어요.
느리게보통빠르게아주 빠르게
· 속도 — 네 단계 중에 고르거나, 슬라이더로 초당 10~400px 사이에서 맞춰요
· 좌우 스크롤 막기 — 넓은 상태창·표 때문에 채팅이 옆으로 밀리거나 흔들릴 때 켜요. 대신 넓은 표·코드도 옆으로 밀어 볼 수 없어서 기본은 꺼짐이에요

🧈
STEP 4 · SMOOTH
끊김 없이 부드럽게
플러그인이 “조금 내려가”를 계속 보내는 방식은 리스와 주고받는 사이 지연 때문에 멈칫멈칫 끊겼어요. 그래서 내려가는 움직임 자체를 브라우저가 그리게 바꿨어요.
· 시험 화면에서 재 보니, 예전 방식은 화면이 프레임의 64%에서 멈춰 있다 한꺼번에 뛰었어요
· 지금은 매 프레임 똑같은 거리로 내려가요 — 멈출 때도 튀지 않아요
