UPDATE · v1.5.3
⚡ 메인 화면에서 바로,
더 빠르게 가져와요.
이번 업데이트부터 PC 리스 메인 화면 오른쪽 아래에 빠른 가져오기 상자가 생겨요. 누르면 메뉴를 찾아 들어갈 필요 없이 Dusk 가져오기 화면이 바로 열리고, 여기에 봇·모듈 파일을 끌어 놓으면 리스 기본 가져오기보다 빨리 들어가요. 이번 업데이트에서 가져오기 속도도 한층 빨라졌어요.

1상자 하나로 바로 가져오기
리스 메인 화면 오른쪽 아래에 이렇게 떠요
⚡빠른 가져오기에셋을 여러 개씩 동시에 올려서 리스 기본 가져오기보다 빨라요눌러서 연 뒤 파일을 끌어 놓으세요 →
×
× 누르면 → ⚡
① 상자 누르기 · 오른쪽 아래 빠른 가져오기 상자를 누르면 Dusk 가져오기 화면이 바로 열려요.
② 파일 넣기 · 열린 화면에 봇·모듈 파일을 끌어 놓거나 [파일 고르기]로 골라요. 여러 개를 한 번에 넣어도 돼요.
③ 알아서 처리 · 이미 있는 봇의 새 버전이면 채팅은 그대로 두고 업데이트하고, 처음 보는 봇이면 새로 추가해요. 올라가는 동안 진행률과 남은 시간이 보여요.
⚠️ 파일을 상자 위에 바로 놓으면 리스 기본 가져오기로 들어가요. 꼭 상자를 누른 뒤 열린 화면에 놓아 주세요.
2🫧 접기 · ✋ 옮기기
· 접기: 상자 옆 ×를 누르면 동그란 ⚡ 아이콘으로 작아져요. 아이콘을 누르면 다시 상자로 펼쳐져요.
· 옮기기: 상자나 아이콘을 마우스로 누른 채 끌면 원하는 자리로 옮겨져요. 화면 밖으로는 나가지 않아요.
· 기억: 접어 둔 상태와 옮긴 위치는 다음에 리스를 열어도 그대로예요.
3상자가 안 보인다면
· 상자는 메인 화면 접근을 허락해야 보여요. 리스가 권한을 물으면 허락해 주세요.
· 설정 → 업데이트 설정의 [PC 메인 화면에 빠른 가져오기 상자]가 켜져 있는지 확인하세요. 필요 없으면 여기서 끌 수 있어요.
· 모바일에서는 상자를 띄우지 않아요. 지금처럼 봇 추가 + 메뉴의 Dusk 버튼을 쓰세요.
4🎲 로어북 확률 만들기
로어북 편집에서 내용 일부를 고르면 [🎲 확률로 만들기] 버튼이 떠요. 나올 확률(1~99%)과 안 나올 때 대신 넣을 글을 정하면, 그 부분만 확률로 나오게 바뀌어요.
· 리스 기본 문법으로 바꿔 넣어서 플러그인이 없어도 그대로 동작해요.
· 프롬프트를 만들 때마다 새로 굴려지고, 리롤하면 다시 정해져요.
· 만든 부분은 내용 칸에 상자로 표시돼요. 그 안에 커서를 두면 확률을 고치거나 풀 수 있어요.
