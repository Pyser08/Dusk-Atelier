📖 처음이라면 — Dusk Atelier 사용 가이드 (눌러서 펼치기)
Dusk Atelier는 RisuAI의 모듈·봇을 관리하고 업데이트하는 플러그인이에요. 수백 MB짜리 봇·모듈도 바뀐 부분만 받아 업데이트하고, 내가 고친 부분과 채팅은 그대로 지켜요. 원본 RisuAI와 PocketRisu·RisuBard에서 써요.
시작하기
1
아래 설치 버튼으로 dusk_atelier.js를 받아 RisuAI 설정 → 플러그인에 추가해요.
2
왼쪽 사이드바(햄버거 메뉴)의 Dusk Atelier를 눌러 열어요. 설정 메뉴에서도 열려요.
3
새 버전이 나오면 설정 → 플러그인의 초록색 + 버튼 하나로 업데이트돼요.
업데이트하는 세 가지 방법
리스에서 그냥 가져오기
평소처럼 봇·모듈을 가져오거나 리스 화면에 끌어다 놓으면, 기존 것의 새 버전인지 알아보고 이어 붙일지 물어요. 새 봇이면 오른쪽 위 알림으로 다른 봇과 합칠지 물어요.
새 버전 파일
Dusk의 가져오기에 .charx · .risum · PNG 카드 · .json을 넣으면 이미 있는 봇·모듈을 찾아서 업데이트해요. 여러 파일도 차례대로 처리해요.
패치 파일
제작자가 올린 작은 .rbupatch 파일이라면 모듈 ⋯ 메뉴나 봇 메뉴의 패치 적용으로 넣어요.
어느 쪽이든 지난번 받은 파일·지금·새 버전을 비교해서 제작자가 바꾼 건 새 버전으로, 내가 고친 건 그대로 둬요. 같은 곳을 둘 다 고쳤으면 충돌로 알려 주고 항목마다 골라요. 적용하기 전에 어디에 닿는지(켜진 모듈·쓰는 봇·채팅 수) 미리 보여 주고, 바꾸기 전 상태는 자동으로 백업돼요.
탭 다섯 개
모듈
켜기·끄기(8초 안에 되돌리기), 폴더·이름 색, 검색·필터, 끌어서 순서 바꾸기, 글로벌·페르소나별·캐릭터별 연결. ⋯ 메뉴에 편집·에셋·내보내기·패치 적용·삭제가 있어요.
플러그인
설치한 플러그인 목록·업데이트 확인, 연동(DA Interop) 플러그인의 설정 바꾸기, 연동 플러그인 만들기, 플러그인 저장소 보기.
캐릭터
리스 사이드바와 같은 폴더·순서를 써요. 여기서 바꾸면 사이드바도 바로 바뀌어요. 봇 편집, 에셋 정리, 업데이트·패치, 다른 봇에서 가져오기·합치기를 해요.
도구
로어북 로그(응답마다 들어간 로어북), 프리셋(모듈 조합·순서 저장, 모바일·PC 자동 전환, 공유 코드), 기록·되돌리기, 업데이트 가져오기, 합치기, 전체 백업·복원, .risum 인스펙터.
설정
로어북(규칙 설정·로어북 로그), 색 바꾸기, 업데이트 설정, 설정 정리, 개발자 모드.
에디터 · 에셋 관리자
로어북·정규식·트리거를 탭으로 나눠 항목별로 고쳐요. 찾기 Ctrl+F, 저장 Ctrl+S, 되돌리기 Ctrl+Z. 정규식 오류·키 없는 로어북은 미리 알려 주고, 저장 전에 바뀐 내용을 요약해 보여 줘요. 로어북 항목마다 Dusk 규칙을 켤 수 있어요(아래 본문). 우측 하단 규칙 시험 버튼으로 가상 대화 시험도 해요. 에셋 관리자는 폴더, 여러 개 고르기, 일괄 교체, ZIP 받기, WebP 최적화, 중복 찾기, 캐릭터·의상별 목록 보기를 지원해요.
모바일에서도 그대로
탭은 아래로, 상세 정보는 아래에서 올라오는 시트로 바뀌어요. 손잡이를 잡고 끌어 순서를 바꾸거나 폴더에 넣을 수 있어요.
알아 두면 좋은 것
· 봇이 답변을 만드는 중에는 업데이트·저장을 막아요. 끝난 뒤 다시 눌러 주세요.
· 꺼 둔 모듈은 Dusk 보관함에 있어요. 플러그인을 지우기 전에 도구 → 설정 정리 → 꺼진 모듈 모두 켜기로 꺼내 주세요.
· 개발자 모드를 켜면 바뀐 부분만 담은 패치 파일을 만들어 배포할 수 있어요. 자세한 건 올인원 가이드 글에 있어요.

1로어북 로그 — 어떤 로어북이 들어갔지?
AI가 답할 때마다 어떤 로어북 항목이 프롬프트에 들어갔는지 기록해요. Dusk 규칙을 안 쓰는 일반 봇도 돼요. 왜 이 항목이 안 들어갔는지, 왜 엉뚱한 항목이 들어갔는지 찾을 때 써요.
어디서 보나
Dusk 도구 → 로어북 로그. [지금 채팅]과 [전체]로 나눠 보고, 로어북 이름·입력·봇 이름으로 찾아요.
무엇이 남나
보낸 입력, 시각, 몇 턴째인지, 들어간 항목 이름, 출처(캐릭터·채팅·모듈 이름), 이유(키 일치 · 항상 켜짐 · Dusk 규칙).
어떻게 알아내나
리스가 보내려는 프롬프트를 직접 보고 항목 본문이 들어 있는지 확인해요. 리스가 프롬프트를 못 보여 주면 키·규칙으로 추정하고, 기록에 그렇게 적어 둬요.
끄기
설정 탭 → 로어북 → 로어북 로그. 최근 300개까지만 남기고 [모두 지우기]도 있어요.
💡 채팅 내용은 건드리지 않아요. 기록은 플러그인 저장 칸에만 쌓여요.
2응답 아래 📖 로어북 버튼
AI 응답 맨 아래에 📖 로어북 N개 접는 버튼이 붙어요. 누르면 그 응답에 들어간 로어북이 출처·이유와 함께 펼쳐져요. 로그 화면까지 가지 않고 바로 확인하는 용도예요.
· 화면에만 붙고 저장된 채팅은 그대로예요. Dusk를 끄면 버튼도 사라져요.
· 리롤하면 새 응답에 새 기록이 따로 생겨요.
· 설정 탭에서 [숨기기]로 버튼만 끌 수 있어요(로그는 계속 쌓여요).
· 출력 정규식으로 응답 앞부분을 많이 바꾸는 봇에서는 버튼이 안 뜰 수 있어요.
3규칙에 추가된 것 — 누적 · 유지 · 변수
로어북 규칙에 쌓이는 이벤트를 만들 도구 세 가지가 들어왔어요. 호감도, 방문 횟수, 며칠간 이어지는 상태 같은 걸 만들 수 있어요.
단어 누적 N번 이상
대화 전체에서 그 단어가 나온 메시지 수를 세요. 사용자 말/봇 말을 가를 수 있어요. 예) "사과"가 3번 나오면 켜기.
N번 이상 켜짐
이 항목(또는 다른 항목)이 지금까지 켜진 턴 수로 정해요. 최근 50번까지 기억해요.
유지
한 번 켜지면 N턴 동안(켜진 턴 포함) 조건·확률을 보지 않고 계속 켜 둬요. 유지 중에 조건이 또 맞으면 다시 N턴부터 세요.
켜질 때 변수
새로 켜질 때 채팅 변수를 정하거나 더하고·빼고·곱하고·나눠요. "수식"을 고르면 직접 계산식을 써요. 유지로 이어진 턴에는 다시 바꾸지 않아요.
⚠ "단어 누적"처럼 한 번 맞으면 계속 맞는 조건은 매 턴 켜져요. 한 번만 켜고 싶으면 반복을 채팅에서 한 번이나 쉬었다가로 같이 걸어 주세요.
4변수 수식 — ? 버튼에서 쓰는 법을 봐요
켜질 때 변수에서 연산을 수식으로 고르면 입력칸 옆에 ? 쓰는 법 버튼이 생겨요. 변수 이름을 그대로 쓰면 지금 값으로 계산해요(숫자가 아니거나 없으면 0).
+  -  *  /
더하기 · 빼기 · 곱하기 · 나누기
%  ^  ( )
나머지 · 거듭제곱 · 먼저 계산할 부분 묶기
min max abs
가장 작은 값 · 가장 큰 값 · 절댓값
floor ceil round
내림 · 올림 · 반올림
clamp(x, 최소, 최대)
범위 안으로 맞추기
rand(a, b)
a~b 사이 정수 난수 (rand()는 0~1 소수)
turn  /  턴
지금 턴(사용자 메시지 수)
· love + 5 — love를 5 올려요
· clamp(love*1.5, 0, 100) — 1.5배로 하되 0~100 안에서
· max(hp - 10, 0) — 10 깎되 0 아래로는 안 내려가게
· rand(1, 6) — 주사위를 굴려 저장
0으로 나누거나 수식이 틀리면 그 항목만 건너뛰고 값은 그대로 둬요. 틀린 부분은 입력칸 아래에 빨갛게 알려 주고, 검증에도 걸려요. 위쪽 항목부터 차례로 계산해서 앞에서 바꾼 값을 뒤 수식이 바로 써요.
🔁 리롤해도 변수가 맞아요. 확률 때문에 리롤 결과가 달라지면 변수도 리롤된 결과 기준으로 다시 맞춰지고, 리롤하지 않으면 원래 결과로 돌아가요. 그 사이 Lua·CBS가 직접 바꾼 값은 건드리지 않아요.
5규칙 시험 — 가상 대화로 미리 돌려 보기
봇·모듈 편집 화면 우측 하단 [규칙 시험] 버튼을 누르면 창이 그 자리에서 펼쳐져요. 정보·로어북·정규식·트리거·JSON 어느 탭에서나 보여요. 창이 떠 있어도 뒤쪽 편집 화면을 그대로 쓸 수 있어서, 규칙을 고치고 바로 다시 시험할 수 있어요.
1
입력을 쓰고 Enter(또는 [보내기]). 한 턴씩 쌓이고, 한 번만·쿨다운·유지·누적은 보낸 순서대로 이어서 계산돼요.
2
카드에 켜진 항목과 이유, 변수가 어떻게 바뀌었는지가 나와요.
3
안 켜진 항목은 [왜?]를 눌러 이유를 봐요. 안 맞은 조건과 지금 값, 확률 실패, 쿨다운, 같은 그룹이 먼저 켜짐 같은 것이 나와요.
지금 턴
맨 위에 "지금 N턴 · 다음 입력은 N+1턴"이 떠 있어요. 숫자를 고치면 그 턴까지 진행된 채팅처럼 계산해요(턴 범위 조건).
현재 변수
직접 고치고 Enter. 변수 비교 조건을 시험해요.
이전 대화
이미 오간 대화를 넣어요("나:"로 시작하면 사용자). 단어 누적·최근 대화 조건용이에요.
켜진 기록
항목마다 켜졌던 턴을 직접 넣어요. 한 번만·쿨다운·유지·"N번 이상 켜짐" 시험용이에요.
확률
그대로 / 확률 항목 모두 켜짐 / 모두 안 켜짐 중에서 골라 연쇄와 확률을 고정해요.
봇 답변
입력칸 아래에 적으면 다음 턴에 "봇 말" 조건이 볼 수 있어요.
저장 전 편집 내용 그대로 계산하고, 실제 채팅과 변수는 건드리지 않아요. [마지막 턴 취소]와 [처음부터]도 있어요.
6그 밖에
· 규칙 편집 화면을 정리했어요. 변수 행과 선택칸 글자가 잘리던 곳, 반복·유지 줄 간격을 다듬었어요.
· 설정 탭 → 로어북에 로그 켜기·끄기와 응답 아래 버튼 숨기기가 생겼어요.
· 아직 실험 기능이에요. 그룹 채팅과 수식은 충분히 시험하지 못했어요. 이상한 점은 댓글로 알려 주세요.
