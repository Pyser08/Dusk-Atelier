PART 1
🎯 플러그인 없이 되는 Dusk 규칙
규칙 화면에서 고를 수 있던 것, 거의 전부예요.
켜지는 조건
· 이 항목의 키가 최근 대화에 있음 (보조 키 포함)
· 특정 단어가 있음 / 없음 — 내 말만·봇 말만·방금 입력만 고르기
· 채팅 변수 비교 (이상·이하·같음·글자 포함…)
· 턴 범위 · 단어가 대화 전체에 N번 이상 · 항목이 지금까지 N번 이상 켜짐
· 다른 항목이 이번 턴에 켜짐 / 안 켜짐
· 모두 만족 / 하나라도 만족
켜지는 방식
· 확률 · 채팅에서 한 번만 · 쿨다운 · 켜진 뒤 N턴 유지
· 그룹: 같은 그룹은 한 턴에 하나만
· 연쇄: 켜지면 다른 항목도 확률로 같이
· 소속 폴더: 구성원별 확률, 최대 N명 무작위 · 장소가 켜지면 그 소속도
· 켜질 때 변수 바꾸기: 정하기·더하기·빼기·곱하기·나누기·수식(min·max·rand·turn…)
· 다시 생성하면 확률을 새로 굴리기 (변수는 두 번 더해지지 않아요)
이름 경계도 그대로예요. ‘마리’가 마리가·마리야·마리였는데에는 켜지고 히마리에는 안 켜져요. ‘하늘’·‘유리’ 같은 흔한 낱말 이름은 부르거나 확인 단어가 있을 때만 켜지는 것까지 같아요.

PART 2
🛠️ 따로 할 건 없어요
평소처럼 만들고 저장하면 들어가요.
봇·모듈 편집에서 Dusk 규칙을 켜고 저장하면 Lua 트리거가 자동으로 들어가요. 트리거 탭에 ‘Dusk 로어북 규칙 (자동 생성)’으로 보이고, 내가 만든 트리거는 건드리지 않아요.
· 저장할 때 지금 규칙으로 다시 만들어요
· 편집기를 열 때 규칙과 다르면(리스에서 직접 고친 경우 등) 바로 맞춰요
· .risum·.charx로 내보낼 때 항상 지금 규칙으로 넣어요
· 넣고 싶지 않은 봇은 로어북 탭 위쪽 ‘플러그인 없이 동작’을 눌러 꺼요 — 봇·모듈마다 기억해요
📷 [이미지 2] 여기에 lore-pc.png (로어북 탭 ‘플러그인 없이 동작: 켜짐’)
정규식 키는 Lua에서 못 써서, 규칙을 켠 항목의 정규식 키를 이름 키로 바꿔요(‘키만 정리’와 같은 방식). 예) /마리|마리쨩/ → 마리, 마리쨩
📌 알아 두면 좋은 것
· 이름 키로 바꾸지 못한 정규식(괄호로 묶은 것 등)과 정규식 조건은 Dusk가 없으면 안 맞는 것으로 봐요. 어느 항목인지 알려 줘요
· 그룹 채팅은 리스가 입력 트리거를 돌리지 않아서, Dusk가 없으면 직전 결정을 그대로 써요(Dusk가 있으면 Dusk가 계산해요)
· 이름 경계·다시 생성 방식은 넣을 때의 내 설정(설정 탭)을 따라요
· 쉬운 로어북으로 고친 봇도 Dusk로 내보내면 Lua가 들어가서, 이제 남에게 줄 때 되돌릴 필요가 없어요
처음이라면 dusk_atelier.js를 받아 RisuAI 설정 → 플러그인에 추가하세요.
이미 쓰고 있다면 본체를 v2.2.44로 업데이트하면 돼요(애드온 업데이트는 필요 없어요).
봇을 받는 사람은 아무것도 설치하지 않아도 돼요.
