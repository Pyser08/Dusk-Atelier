🚀 시작하기
설치
•RisuAI 설정 → 플러그인에서 dusk_atelier.js를 추가해요.
•예전 이름 Dusk Manager로 설치했다면 그건 지우고 새로 추가하세요. 설정·폴더·백업 기록은 그대로 이어져요.
•원본 RisuAI에서 처음 열 때 데이터베이스 접근 권한을 물으면 허용해 주세요.
•새 버전이 나오면 RisuAI 플러그인 업데이트로 바로 받을 수 있어요.
열기
•왼쪽 사이드바(햄버거 메뉴)의 Dusk Atelier를 누르거나, 설정 메뉴에서 열어요.
•창 안 아무 데나 파일을 끌어다 놓으면 바로 가져오기가 시작돼요.
화면 구성
•모듈 · 플러그인 · 캐릭터 · 프리셋 · 기록 · 도구 여섯 탭이에요.
•개발자 모드를 켜면 개발 탭이 하나 더 생겨요. (아래 개발자용에서 설명해요)
어디서 되나요
•RisuBard: 기준 환경이에요. 모든 기능이 돼요.
•원본 RisuAI: 모든 기능이 돼요.
•RisuVault: 모듈 기능은 모두 돼요. 대화가 긴 봇은 RisuVault가 채팅 보호로 막아서 봇 편집·에셋·업데이트·패치 적용이 안 돼요. 이때는 안내만 보여 주고 아무것도 바꾸지 않아요.
🔄 모듈·봇 사용자용 업데이트·패치 받기 (눌러서 펼치기)
봇·모듈을 받아서 쓰는 분을 위한 부분이에요. 새 버전이 나왔을 때 내가 고친 건 지키면서 업데이트하는 방법을 정리했어요. 탭별 기능은 아래 일반 사용자용에 있어요.
같은 업데이트, 받아야 하는 크기
276MB 모듈을 고쳤을 때
새 버전 파일을 통째로 다시 받기276MB
패치 · 이미지 2장 포함1.8MB (약 1/150)
패치 · 글만 수정21.4KB (약 1/13,000)
측정 예: 로어북 1,500개 · 이미지 400장(장당 약 700KB) 모듈. 글만 수정 = 로어 5개 수정 + 로어·정규식 1개씩 추가, 이미지 2장 포함 = 여기에 이미지 1장 교체·1장 추가. 막대는 로그 눈금이에요.
01 · 바뀐 것만
작게 받고, 적게 올려요
패치에는 바뀐 로어·정규식·트리거·설정과 새 이미지만 들어가요. 새 버전 파일을 통째로 넣어도 서버에 이미 있는 이미지는 다시 올리지 않아요.
02 · 내 수정은 그대로
번역·직접 고친 설정 유지
지난번 받은 것 · 지금 내 것 · 새 버전을 비교해서 합쳐요. 내가 고치고 추가한 항목은 남고, 같은 곳을 둘 다 고쳤으면 따로 알려 줘요.
03 · 되돌리기
자동 백업, 채팅은 안전
적용하기 전 상태를 자동으로 백업해요. 업데이트 직후 바로 되돌리기를 누르거나 기록 탭에서 원하는 시점으로 돌아가요.
업데이트하는 두 가지 방법
A패치 파일(.rbupatch)을 받았을 때
제작자가 올린 작은 패치 파일 하나로 끝나요. 모듈은 모듈 메뉴(⋯) → 패치 적용, 봇은 캐릭터 탭 → 패치 적용을 누르고 파일을 고르세요.
적용하기 전에 버전, 제작자, 변경 내용, 바뀌는 개수를 먼저 보여 줘요. 패치 안에 원본 정보가 들어 있어서 따로 준비할 건 없어요.
B새 버전 파일을 통째로 받았을 때
.risum · .charx · PNG/JPEG 카드 · .json을 도구 → 업데이트 가져오기에 넣거나 창에 끌어다 놓으세요. 새로 추가하지 않고 이미 있는 모듈·봇을 찾아서 업데이트해요. 리스에서 평소처럼 가져와도 "이어 붙일까요?"라고 물어봐요.
B 방법에서 알아서 해 주는 것
•바뀐 에셋만 올려요: 이미지가 수백 장인 봇도 바뀐 것만 올라가서 금방 끝나요.
•알아서 찾아요: 버전 표기가 달라도 같은 모듈·봇으로 찾아요. 꺼 둔 모듈도 찾고, 업데이트한 뒤에도 꺼진 채로 둬요.
•연결 기억: 한 번 고른 짝을 기억해서 다음 버전부터는 바로 그 대상을 골라요.
•여러 파일 한 번에: 넣은 순서대로 차례차례 처리해요.
•충돌 고르기: 같은 곳을 제작자와 내가 둘 다 고쳤으면 어느 쪽을 쓸지 항목마다 골라요.
•내 설정 보호: TTS·음성, 메모리, 번역 노트 같은 설정과, 채팅마다 고른 추가 인사말을 그대로 지켜요.
💡 패치(A)는 원본 정보가 파일 안에 있어서 바로 적용돼요. 새 버전 파일(B)은 그 봇·모듈을 Dusk Atelier로 한 번 가져온 뒤부터 원본이 기록돼서, 그다음 업데이트부터 내 수정을 정확히 지켜 줘요.
📌알아 두면 좋은 것업데이트·백업을 쓸 때
쓰는 중에
•봇이 답변을 만드는 중에는 업데이트·저장을 막아요. 끝난 뒤 다시 눌러 주세요.
•적용한 뒤 마음에 안 들면 기록 탭에서 그 전 시점으로 되돌려요. 채팅은 그대로예요.
•설정(테마·폴더·프리셋)은 다른 기기와 함께 동기화돼요.
플러그인을 지울 때
•꺼 둔 모듈은 이 플러그인 보관함에 있어요. 지우기 전에 도구 → 설정 정리 → 꺼진 모듈 모두 켜기로 꺼낸 다음 지워 주세요.
🛠️ 봇·모듈 제작자라면, 수정할 때마다 수백 MB 파일을 다시 올릴 필요가 없어요. 패치 만드는 방법은 맨 아래 개발자용을 펼쳐 보세요.
👤 일반 사용자용 탭별 기능 전체 (눌러서 펼치기)
탭 이름 순서대로 정리했어요. 큰 줄기만 보려면 각 탭의 굵은 제목만 훑어보세요.
📦모듈 탭모듈을 켜고 끄고, 묶고, 고치는 곳
찾기·거르기
•이름, 로어북 키, 정규식·트리거 이름으로 검색해요.
•필터: 전체 · 켜짐 · 꺼짐 · 전역 · LLA · MCP
켜기·끄기
•끈 모듈은 RisuAI 목록에서 빠지고 보관함에 들어가요. 끈 뒤 8초 안에 되돌릴 수 있어요.
•에셋이 있는 모듈은 끌 수 없어요. 끄면 RisuAI의 에셋 정리로 파일이 지워질 수 있어서예요.
폴더
•접기·펴기, 폴더 색, 이름 바꾸기, 순서 바꾸기를 할 수 있어요.
•폴더를 만들 때 넣을 모듈을 바로 골라요(찾기·모두 고르기). 나중엔 폴더 메뉴의 넣을 모듈 고르기…로 바꿔요.
•모듈을 끌어서 폴더에 넣을 수도 있어요.
이름 색
•모듈마다 이름 색을 정해요. 어떤 밝기에서도 읽히도록 진하기를 자동으로 맞춰요.
순서
•줄 왼쪽 손잡이(점 여섯 개)를 잡고 끌어요. 모바일에서도 돼요.
•PC에서는 줄 전체를 끌어도 되고, Alt+↑ / Alt+↓로도 옮겨요. 메뉴의 위로·아래로도 있어요.
연결
•글로벌 활성화: 모든 채팅에서 켜요.
•페르소나별 자동 활성화: 그 페르소나를 쓰는 동안 지금 캐릭터에 자동으로 넣어요.
•캐릭터별 연결, 지금 채팅에서 해제
모듈 메뉴
•편집, 에셋 관리
•.risum 내보내기, JSON 복사, 이름 바꾸기
•삭제: 지우기 전 상태를 백업해서, 기록 탭에서 되살릴 수 있어요.
•내 수정만 내보내기, 패치 적용 (아래 '내 수정 나누기' 참고)
편집기
•탭: 정보 · 로어북 · 정규식 · 트리거 · JSON
•로어북 폴더: RisuAI 로어북 창과 같은 저장 형식이라 양쪽에서 그대로 보여요. 손잡이로 끌어서 넣고 빼요.
•항목 추가·복제·삭제·순서 바꾸기
•Ctrl+F 찾기, Ctrl+S 저장
•코드 편집기: 정규식 IN/OUT과 트리거 Lua 칸에 문법별 색이 들어가요. 괄호를 누르면 짝 괄호도 같이 표시돼요.
•CBS 사전: 누르면 지금 고치던 칸에 바로 넣어요.
•검사: 정규식 문법 오류, 키가 없는 로어북(구분선용 항목은 빼고), 없는 폴더를 가리키는 항목을 알려 줘요.
•적용하기 전에 바뀐 내용을 요약해서 보여 주고, 저장 전 상태를 백업해요.
에셋 관리자
•화면에 보이는 것만, 가까운 것부터 8장씩 읽어요. 썸네일로 그리고 한 번 읽은 건 기억해서 빨라요.
•하위 폴더를 만들 수 있어요. 폴더 구분은 플러그인 설정에 저장하고, 모듈 데이터에는 쓰지 않아요.
•Ctrl·Shift로 여러 개 고르기, Ctrl+A 모두 고르기, Delete 지우기. 고른 것을 폴더 칩으로 끌어 옮겨요.
•추가(끌어 놓기 가능), 교체, 일괄 교체(이름 또는 순서로 맞춤), 이름 바꾸기, 삭제. 바꾼 뒤 되돌릴 수 있어요.
•크게 보기(←/→로 넘기기), 내려받기(여러 개면 폴더 구조 그대로 ZIP)
•최적화: WebP(지원하면 AVIF)로 바꿔요. 품질·크기를 고르고 미리 계산한 뒤, 더 작아지는 것만 바꿔요.
•메타데이터: PNG 텍스트·EXIF·XMP·WebP 정보를 보고, 그림은 두고 메타데이터만 지워요.
🧩플러그인 탭설치한 플러그인을 정리하고, 연동되는 플러그인의 설정을 바꾸는 곳
목록
•설치한 플러그인을 카테고리로 묶어서 봐요.
•업데이트 주소가 있는 플러그인은 새 버전이 있는지 확인해요.
•플러그인 목록을 JSON으로 내보내 백업해 둘 수 있어요.
연동 설정
•DA Interop에 맞춘 플러그인은 설정 화면이 여기에 자동으로 생겨요.
•값을 바꾸거나 프리셋을 고르면 그 플러그인이 받아서 적용하고, 적용됐는지 알려 줘요.
•그 플러그인이 켜져 있어야 하고, RisuAI 화면이 열려 있을 때 몇 초 안에 반영돼요.
ℹ️ 플러그인을 켜고 끄거나 순서·코드를 바꾸는 건 RisuAI가 플러그인끼리 못 하게 막아 뒀어요. 이건 RisuAI 설정 → 플러그인에서 해 주세요.
🧑캐릭터 탭봇을 정리하고 고치는 곳
목록
•목록, 검색, 봇에 연결된 모듈 보기
폴더·순서
•RisuAI 사이드바의 캐릭터 폴더·순서를 그대로 써요. 여기서 바꾸면 사이드바에도 바로 반영돼요.
•폴더를 만들 때 넣을 봇을 고르고, 손잡이로 끌어서 순서를 바꾸거나 폴더에 넣고 빼요.
•폴더 메뉴: 넣을 봇 고르기, 이름, 색(RisuAI 색), 위로·아래로, 삭제(봇은 남아요)
봇 편집
•모듈 편집기와 같은 화면에서 봇을 고쳐요.
•정보: 이름, 설명, 첫 메시지, 추가 인사말, 성격, 시나리오, 시스템 프롬프트, 제작자 노트, 기본 변수, 배경 HTML 등
•로어북 · 정규식 · 트리거 · JSON
•저장 전에 변경 요약을 보여 주고 백업해요. 채팅과 메모는 건드리지 않아요.
에셋
•에셋 관리자로 봇의 추가 에셋을 관리해요. 모듈과 기능이 같아요.
업데이트·패치
•업데이트 가져오기, 내 수정만 내보내기, 패치 적용
🎚️프리셋 탭모듈 구성을 통째로 저장하고 바꾸는 곳
프리셋
•어떤 모듈을 켜고 끌지, 순서, 글로벌 활성화를 묶어서 저장해요.
•지금 상태는 사용 중인 프리셋에 자동으로 저장돼요.
•새 프리셋, 전환, 덮어쓰기, 이름 바꾸기, 삭제(모듈은 그대로 남아요)
•전체 내보내기·가져오기
디바이스 페어
•모바일용·데스크탑용 프리셋을 정해 두면, 기기가 바뀔 때 자동으로 전환해요.
🕰️기록 탭바꾸기 전 상태로 되돌리는 곳
버전 타임라인
•업데이트·편집·삭제하기 전 상태를 대상별로 시간순으로 보여 줘요.
•전체 · 모듈 · 캐릭터로 걸러 볼 수 있어요.
되돌리기
•고른 시점으로 되돌려요. 되돌리기 전에 지금 상태도 먼저 백업해요.
•되돌려도 채팅은 그대로예요. 지운 봇도 되돌리면 새 봇으로 되살아나요.
•모듈은 그 시점과 지금을 비교해 볼 수 있어요.
보관
•보관 개수는 항목마다 3/5/10/20개 중에서 골라요. 넘은 백업은 요약만 남아요.
•필요 없는 백업은 하나씩 지울 수 있어요.
•백업은 압축해서 같은 내용은 한 번만 저장해요. RisuAI의 에셋 정리를 해도 지워지지 않아요.
🧰도구 탭업데이트, 합치기, 백업, 색 같은 나머지 기능

🔗DA Interop — 플러그인 연동여러분의 플러그인 설정을 Dusk 연동 설정 화면에 띄우기
링크
•스니펫 생성기: 플러그인 정보와 설정 항목을 넣으면 코드를 만들어 줘요.
•저장소 · 명세 · 예제 플러그인
•Dusk 플러그인 탭의 만들기에서도 같은 코드로 시작할 수 있어요.
붙이는 순서
•스니펫은 플러그인 맨 위에, registerInterop({...})은 맨 아래에 둬요. 등록은 스니펫보다 뒤에 있어야 동작해요.
•apply 안에 받은 값을 반영하고 플러그인이 직접 저장하는 코드를 채워요. 같은 패치는 한 번만 전달돼요.
•getValues는 지금 값을 돌려주고, 플러그인 쪽에서 값이 바뀌면 refresh()를 불러 주세요.
// 1) 생성기에서 받은 스니펫을 플러그인 맨 위(머리말 아래)에 붙여요
// 2) 플러그인 본문
const risu = globalThis.risuai ?? globalThis.Risuai;
const KEY = 'my_plugin:settings'; // 저장 키는 '플러그인이름:'으로 시작
let settings = { enabled: true, tone: 'soft', strength: 0.5 };

// 3) 맨 아래에 등록 코드
const handle = registerInterop({
  id: 'my-plugin', // 소문자·숫자·.-_ (2~64자)
  name: '말투 바꾸기',
  version: '1.0.0',
  pluginName: 'my_plugin', // //@name 과 같게
  fields: [
    { key: 'enabled', label: '켜기', type: 'toggle', default: true },
    { key: 'tone', label: '말투', type: 'select', options: [
      { value: 'soft', label: '부드럽게' }, { value: 'dry', label: '건조하게' } ] },
    { key: 'strength', label: '세기', type: 'slider', min: 0, max: 1, step: 0.1 }
  ],
  presets: [{ name: '기본', values: { enabled: true, tone: 'soft', strength: 0.5 } }],
  getValues: () => settings, // 지금 값을 돌려줘요
  apply: async (values, ctx) => { // Dusk에서 보낸 값
    settings = { ...settings, ...values };
    await risu.pluginStorage.setItem(KEY, JSON.stringify(settings)); // 직접 저장
  }
});
// 플러그인 쪽에서 값이 바뀌면: handle.refresh()
toggle켜기·끄기
number숫자 칸 (min·max·step)
slider슬라이더 (min·max·step)
select고르기 — options: [{ value, label }]
text / textarea한 줄 / 여러 줄 글
color색 고르기
공통 속성key · label · type · default · description · group
동작 방식
•플러그인이 da_interop:reg:<id>에 자기 정보·항목·지금 값을 올려요.
•Dusk가 da_interop:patch:<id>에 바꿀 값과 번호(rev)를 써요.
•플러그인은 화면이 보일 때 3초마다 확인하고, 새 번호면 apply 후 적용 번호와 오류를 다시 올려요. Dusk는 이걸 보고 적용됐는지 알려 줘요.
•모두 공식 pluginStorage만 써요. 샌드박스를 우회하지 않아요.
•플러그인 자체 설정 키에도 플러그인이름: 같은 접두어를 붙여 다른 플러그인과 겹치지 않게 해 주세요.
📜플러그인 머리말 주의설치가 안 되거나 버전이 0으로 읽힐 때
머리말
•//@name //@display-name //@api 3.0 //@version //@update-url
•//@version은 0.0.1 이상이어야 하고 파일 앞 512바이트 안에 있어야 해요. //@update-url을 쓰면 버전이 꼭 필요하고, 주소는 https만 돼요.
•RisuAI는 파일 전체에서 마지막으로 나온 //@ 줄을 읽어요. 코드 안 문자열이라도 줄 맨 앞이 //@version이면 그 값으로 덮여요. 템플릿 문자열에 머리말을 넣을 땐 줄 맨 앞에 오지 않게 이어 붙이세요.
