UPDATE · v1.5.2
🎨 고르기만 하면
채팅 테마가 완성돼요.
CSS를 몰라도 스타일·색·분위기만 고르면 리스 채팅 테마(커스텀 HTML·CSS)가 만들어져요. 원하는 느낌을 글로 적으면 AI가 새 스타일을 디자인해 주고, 마음에 안 드는 곳만 말로 고칠 수도 있어요. 일반 리스와 PocketRisu·RisuBard 같은 포켓 계열 모두에서 같은 모양으로 보여요.

💡 이런 분께 특히 좋아요
남이 만든 테마를 받아 쓰기만 했거나, 직접 만들어 보고 싶었지만 CSS가 막막했던 분. 그리고 일반 리스용 테마가 포켓 계열에서 깨져서 못 쓰던 분.
1어디서 여나요
설정 탭 → 테마에서 테마 스튜디오가 열려요. 테마가 없으면 바로 [빌더로 쉽게 만들기]가 보이고, 있으면 위쪽 버튼으로 빌더에 들어가요.
2테마 빌더 — 고르기만 하기
① 스타일 · 편지(종이·우표 프로필) · 메신저(말풍선) · 미니멀 카드 · 밤의 일기(날짜 배지·별) · 비주얼 노벨(이름표 대사창) 중에서 골라요.
② 대표색 · 색 하나만 고르면 배경·카드·선·글자색까지 맞춰 만들고, 글자가 잘 읽히도록 대비를 자동으로 맞춰요. [사진에서]를 누르면 캐릭터 사진에서 색을 뽑아요.
③ 밝기 · 밝게 / 어둡게.
④ 분위기 다이얼 · 차분↔화려, 각지게↔둥글게, 촘촘↔여유. 한 번에 여러 값이 같이 움직여요.
⑤ 본문 너비 · 좁게·보통·넓게·꽉 차게. 카드는 넓어도 글줄은 읽기 좋은 길이로 모을 수 있어요.
⑥ 장식 · 프로필 · 글꼴 · 스타일마다 장식 4개를 켜고 끄고, 프로필 모양(원·우표·폴라로이드·없음)과 글꼴 짝(감성 명조·깔끔 고딕·동글 고딕·손글씨·타자기)을 골라요.
오른쪽 미리보기는 실제 리스 채팅 구조로 그려지고, PC·모바일 크기로 바꿔 볼 수 있어요. 프로필은 캐릭터·내 글 모두 자기 카드 안에 들어가요.
3✨ AI로 만들기 · AI로 고치기
새 스타일 만들기 · "비 오는 밤 카페에서 쓰는 손편지 느낌"처럼 적으면 AI가 색·글꼴을 고르고 모양까지 새로 디자인해요.
있는 스타일에서 고르기 · 작은 모델이라면 이쪽이 안정적이에요. AI는 스타일·색·다이얼만 골라요.
AI로 고치기 · "이름을 더 크게", "내 말풍선은 각지게"처럼 말하면 그 부분만 바꿔요. 기본 스타일도 고칠 수 있어요.
되돌리기 · AI가 바꾸기 전으로 10번까지 돌아가요. [기본 스타일로]로 AI 스타일을 끌 수도 있어요.
AI가 쓴 CSS는 메시지 카드 안쪽만 꾸미도록 자동으로 걸러요. 리스 화면 전체를 깨뜨리는 코드(다른 화면 선택자, 외부 파일 불러오기, !important 등)는 지워져요. 모델은 합치기 AI 설정과 같이 쓰고, 빌더에서 바꿀 수 있어요.
⚠️ AI 스타일 품질은 모델에 따라 많이 달라요. 결과가 아쉬우면 모델 칸에서 메인 모델을 골라 보세요.
4테마 스튜디오 — 직접 다듬기
· 빌더로 만든 테마는 스튜디오에서 그대로 열려요. CSS·HTML을 직접 고치고, 다시 [빌더에서 고치기]로 돌아갈 수도 있어요. (빌더에서 다시 저장하면 직접 고친 부분은 덮어써져요)
· 테마 붙여넣기: 받은 테마의 HTML·CSS를 붙여 넣으면 실제 구조로 미리 보고 적용해요.
· CSS --변수 편집: 테마 안의 색·크기 변수를 칸으로 바로 바꿔요.
· 일반 리스 / 포켓 계열 따로 저장: 원본 RisuAI가 아니면(PocketRisu·RisuBard 등) 자동으로 포켓 계열로 잡아요. 설정 탭의 계열 토글로 직접 바꿀 수도 있어요.
5🔗 공유 코드
[공유 코드 복사]를 누르면 DTB1:…로 시작하는 한 줄이 복사돼요. 받은 사람은 [코드로 불러오기]에 붙여 넣으면 같은 테마가 열려요. AI가 만든 스타일도 같이 담겨요.
6📜 이제 업데이트하면 패치노트가 떠요
업데이트한 뒤 Dusk를 처음 열면 "이전 버전 → 지금 버전" 패치노트 창이 한 번 떠요. 여러 버전을 건너뛰었으면 그 사이 변경점을 모두 보여 줘요. 사이드바 아래 버전 글자를 누르면 언제든 다시 볼 수 있어요.
