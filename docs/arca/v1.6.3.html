UPDATE · v1.6.3
🎨 처음 써도 편한 새 화면.
⚡ 더 가볍게, 📚 로어북은 더 쉽게.
새 기능보다 쓰기 편하게 다듬는 데 집중한 업데이트예요. 화면을 새로 꾸미고, 탭 전환을 줄이고, 로어북 편집을 한 단계 편하게 만들었어요.
1🎨 새 화면
밝은 회백 바탕에 코랄 포인트가 새 기본이에요. 첫 화면은 "무엇을 하고 싶으세요?" 홈 카드이고, 모바일은 아래쪽 탭 5개로 바뀌었어요. 설정 → 화면 꾸미기에서 색 프리셋·밝기·메뉴 위치·줄 간격·글자 크기·고대비를 고르면 바로 적용돼요. 예전 색은 “황혼” 프리셋으로 남아 있어요.
2🧭 처음 쓰는 분을 위해
처음 열면 다섯 장짜리 둘러보기가 떠요(건너뛰기 가능). 비어 있는 화면에는 무엇을 하는 곳인지와 첫 버튼이 나오고, 아이콘 버튼은 마우스를 올리면(모바일은 길게 누르면) 이름이 말풍선으로 떠요. 지우면 되돌릴 수 없는 것은 확인창이 먼저 떠요.
3⚡ 빨라진 탭
플러그인·도구·설정 탭은 한 번 그리면 숨기기만 하고, 다시 들어오면 그대로 보여요. 기억 탭도 오른쪽 칸만 다시 그려서 탭·채팅을 바꿀 때 덜 버벅여요.
4✍️ 로어북·정규식 편집
폴더 모두 접기/펴기, 검색해도 유지되는 폴더 트리, 저장해도 그대로인 목록 위치, 2분 자동 저장, Ctrl+P 빠른 이동, Ctrl+H 찾아 바꾸기, 정규식 바로 시험까지 들어갔어요. 이름순 버튼은 폴더 구조를 그대로 두고 폴더 안에서만 정렬하고, 조건·같이 켜기의 항목 고르기는 폴더 트리 + 검색으로 바뀌었어요. 항목 내용 아래에는 약 N 토큰(추정)이 보여요.
5📚 로어북 더스크화
기존 로어북 탭의 더스크화 버튼 하나로 -- 이름 -- 구분선을 [소속] 이름 폴더로 바꾸고, AI가 사람·소속·장소를 나눠 제안해요. 미리보기에서 체크한 것만 적용되고 적용 전 내용은 기록으로 남아요. 장소와 소속의 연결은 AI 추측이니 미리보기에서 확인해 주세요.
6🛠️ 고친 점
구성원 때문에 따라 켜진 소속이 다른 구성원·연쇄까지 데려오던 문제를 고쳤고, v1.6.0에서 빠져 있던 같이 켜기(연쇄)가 다시 동작해요.
⚠️ 알아 두세요. 장소는 이제 폴더상 가장 가까운 소속만 켜요. 위쪽 소속까지 한꺼번에 켜지던 동작에 기대어 만든 로어북은 달라질 수 있으니, 위쪽 소속도 필요하면 장소의 ‘같이 켜질 소속’에 직접 연결해 주세요.
