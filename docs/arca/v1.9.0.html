FEATURE 1 · DUSK CELLAR
🗄️ Dusk Cellar — 백업·복원이 약 1/7
리스를 직접 돌리는 서버에 함께 설치하는 선택 서버예요. 없어도 모든 기능은 그대로고, 있으면 세이브 백업·복원이 압축 방식보다 훨씬 빨라져요.
⏱️ 시험 결과 (파일 2만 개, 약 1GB)
· 처음 백업 4.8초  /  tar.gz 압축 34.6초 → 약 1/7
· 복원 1.0초  /  tar.gz 풀기 7.2초 → 약 1/7
· 몇 개만 바뀐 뒤 백업 3.0초 → 약 1/11
시험용 폴더 기준이에요. 실제 세이브는 파일 수와 디스크 속도에 따라 달라요.
1-1⚡ 바뀐 파일만 복사하는 백업NEW
설정 → 서버 → Dusk Cellar → 세이브 백업에서 캐릭터·채팅·에셋·설정 전체와 서버 기억을 한 번에 백업해요.
· 압축하지 않아요. 세이브 대부분은 이미 압축된 이미지라 다시 압축해도 안 줄고 시간만 걸려요
· 두 번째 백업부터는 바뀐 파일만 복사해서 훨씬 빨리 끝나요
· 리스가 도는 중에도 백업할 수 있어요
· 기본 5개를 보관해요
1-2🛟 복원이 망가지지 않게NEW
복원은 리스를 잠깐 껐다 켜요. 그 사이에 문제가 생겨도 세이브가 반쯤 바뀐 채 남지 않게 안전장치를 넣었어요.
· 복원 전에 백업이 온전한지 먼저 확인해요(이상하면 리스를 끄지 않고 거절해요)
· 지금 상태는 '복원 전 자동' 백업으로 남겨요
· 복원이 실패하면 그 백업으로 자동으로 되돌리고, 화면에 실패 이유를 보여 줘요
· 세이브가 비어 있거나 디스크가 부족하면 백업을 하지 않아요
· 백업하는 동안 세이브가 계속 바뀐 백업에는 경고가 떠요
· 복원한 뒤에는 리스를 열어 둔 화면을 모두 새로고침해 주세요
1-3🧠 장기 기억을 서버에 저장NEW
Cellar가 있으면 채팅별 장기 기억을 처음 한 번 서버로 옮기고, 그다음부터는 서버에만 저장해요. 플러그인 저장소가 가벼워져요.
· 서버와 잠깐 끊기면 바뀐 기억을 이 기기에 모아 뒀다가 다시 연결되면 올려요
· 다른 기기에서 같은 기억을 동시에 바꿔도 기록을 합쳐서 잃지 않아요
· '기억을 이 기기로 되돌리기'로 언제든 예전 방식으로 돌아갈 수 있어요
1-4✏️ 플러그인 수정 · 베타NEW
RisuBard·PocketRisu·순정 리스AI에서 플러그인 코드 수정, 켜기/끄기, 순서, 추가/삭제를 할 수 있어요. 기본으로 켜진 베타 기능이에요.
· 리스가 막아 둔 플러그인 목록을 Cellar가 서버에서 대신 고쳐 줘요
· 고친 뒤에는 리스 화면을 새로고침(F5)해야 반영돼요. 걸리는 시간은 서버에 따라 달라요
· 열려 있던 리스 화면이 옛 목록으로 다시 저장해 버리면 알려 드려요(그땐 새로고침하고 다시 해 주세요)
1-5🔄 자동 연결 · 업데이트 버튼NEW
주소나 토큰을 넣을 필요 없이 플러그인이 알아서 Cellar를 찾아요(리스 암호로 보호).
· 설정 → 서버 → Dusk Cellar에서 '연결됨'을 확인해요
· '업데이트 확인'을 누르면 Cellar만 잠깐 다시 켜지고 리스는 그대로 돌아요
· 새 버전이 안 불러지면 자동으로 이전 버전으로 돌아가요(git으로 설치한 서버에서만)
· 설치: Pyser08/Dusk-Cellar

2-1🌙 마스코트 루네NEW
창 왼쪽 위 로고가 루네가 됐어요.
· 시작 안내에서 손을 흔들며 인사해요
· 빈 화면에서는 상황에 맞는 표정으로 알려 줘요(채팅 없음=놀람, 준비 전=미안한 얼굴 등)

2-2🧭 시작 안내NEW
처음 열면 플러그인 창을 꽉 채운 안내가 떠요.

· 고르는 즉시 적용되고, 지금 설정이 골라진 채로 시작해요(초기화 없음)
· 설정 → 도움말 → ‘시작 안내 다시 보기’로 다시 볼 수 있어요
2-3🖌️ 꾸미기 대폭 확장NEW

· 모서리·그림자·글꼴·굵기·줄 높이·바탕 무늬·카드 유리 효과·움직임 줄이기
· 고급: 바탕·카드·글자·사이드바 색 직접(대비 자동 맞춤)
· 내 테마 여러 개 저장, 밝을 때/어두울 때 따로, 테마 코드로 주고받기

FEATURE 3 · MEMORY
🧠 사람다운 기억
장기 기억이 ‘무슨 일이 있었나’만이 아니라 사람 사이에서 실제로 일어나는 일을 기억해요. AI 호출은 늘지 않아요.
3-1🤝 관계가 천천히 쌓여요NEW
두세 턴 만에 갑자기 친해지는 일을 줄여요.
· 관계 진도 — 처음 봄 · 아는 사이 · 친한 사이 · 아주 가까운 사이
· 호칭·말투 — 누가 누구를 뭐라고 부르는지, 존댓말인지 반말인지
· 둘만의 추억 — 둘이 함께 나오면 다시 꺼낼 만한 순간을 슬쩍
· 갈등·사과·앙금 — 안 풀림 → 사과함 → 화해함, 깊은 앙금은 남아요
· 사람 앞 태도 — 둘이 있을 때와 남들 앞에서 다른 인물
· 오랜만의 재등장, 외모·성격·처지 변화, 흐려지는 사소한 기억
3-2🌡️ 감정이 시간이 지나면 식어요NEW
적대감·두려움은 빨리, 의존·애정은 천천히 누그러지고, 신뢰·존경은 행동으로만 바뀌어요.
· 깊은 원한은 조금 남아요
· 직접 정한(잠근) 값은 그대로예요
3-3🕵️ 거짓말·오해 추적NEW
기본 꺼짐. 누가 무엇을 잘못 믿고 있는지 기억해서, 속은 인물이 진실을 알기 전까지 그 믿음대로 행동하게 해요.
· 추리·드라마 봇에 알맞아요. 분석 모델이 약하면 틀릴 수 있어요
· 세 기능 모두 기억 화면의 ‘기억 옵션’에서 켜고 꺼요
3-4🙋 나에 대한 기억NEW
다른 인물들이 나를 어떻게 보는지 한눈에 봐요.
· 인물마다 관계 진도, 나에게 느끼는 감정, 나를 부르는 말·말투, 태도, 추억, 갈등·오해
· 고치기로 호칭·말투·감정을 바로 고치고, 고친 값은 잠겨요
· 예전에 페르소나 이름으로 따로 쌓인 기록은 미리 보고 나로 합치기
· {{user}}를 ‘나’로 분명히 알아듣고, 기록 보기에서는 페르소나 이름으로 보여 줘요
3-5📖 인물 위키 개편NEW
‘요약 / 관계 / 상세 정보 / 기록’ 탭으로 나눴어요.
· 요약: 지금 모습, 달라진 점, 관계 진도, 기억에 남은 순간, 수치 한눈에
· 관계: 진도·감정·호칭·추억·기대 차이·오해·갈등·사람 앞 태도
· 상세 정보: 값 있는 것만 카드로, 빈 공간 없이 붙어요
· 감정·호칭·추억은 직접 고치고, 잘못된 기록은 지워요
3-6🪄 봇 로어북으로 내보내기NEW
인물 위키에 정리된 정보를 그 봇의 로어북에 넣을 수 있어요. 누를 때만 동작해요.
· 인물 위키 화면 → 더보기 → ‘봇 로어북으로 내보내기’에서 원하는 인물만 체크해요
· 위키에 정리된 개요·관계·말투와 기본 성격만 들어가요(기억 기록·사건 목록은 안 들어가요)
· 키는 이름·별칭이라 그 인물이 나올 때만 켜져요. 비밀·성적 태도·의심 항목은 빼요
· 들어갈 글을 미리 보고, 다시 내보내면 같은 인물 항목만 갱신해요(내가 고친 키는 그대로)
FEATURE 4 · STORY DICE
🎲 이야기 도우미
‘유저 편향 없애기’의 주사위를 믿을 수 있게 만들었어요. 강도를 고르고, 리롤로 결과를 바꿀 수 없고, 판정이 다음 턴까지 이어져요.
4-1🎚️ 강도 고르기NEW
홈 빠른 설정의 유저 편향 없애기가 스위치 대신 박스가 됐어요. 누르면 상세 창이 열려요.
· 약하게 · 보통 · 강하게 — 강할수록 난이도 목표치가 높아 실패가 늘어요. ‘보통’은 예전과 똑같아요
· 강도 위에 내가 결과까지 적었을 때(재해석 · 존중)가 있어요. 재해석은 내가 적은 결과도 시도로 보고 주사위로 가리고, 존중은 내가 적은 대로 따라요
· 고급 모드에서는 난이도 수치와 주사위 개수(1~6)를 직접 넣을 수 있어요
· ?로 작동 방식을 보고, 시작 안내 4단계에서도 같은 창이 열려요
· 켜면 공정한 전개도 함께 켜져요
4-2🔒 리롤해도 같은 주사위NEW
같은 턴을 다시 생성하면 같은 주사위 값을 써요. 마음에 드는 판정이 나올 때까지 리롤하는 걸 막아요.
· 새 입력을 보내야 새로 굴려요
· Dusk가 넣는 기억·이야기 시간이 조금 달라져도 대화가 같으면 같은 턴으로 봐요
· 프롬프트가 그대로라 캐시도 덜 깨져요
4-3📌 판정 결과 이어 주기NEW
AI가 응답 끝에 판정한 행동마다 화면에 안 보이는 표식을 남기고, 다음 턴에 그 결과를 다시 알려 줘요. 실패한 일을 없던 일처럼 넘기지 않게요.
· 예: 경비병 설득 · 어려움 · 62 · 실패 → 다음 턴에 “지난 판정: 설득 실패”
· 표식은 장기 기억 분석에는 보내지 않아요
· 모델이 표식을 안 남기면 예전처럼 동작해요
4-4🎯 결과 표시 · 판정 기록NEW
홈 주사위 결과 표시(기본 꺼짐)를 켜면 응답 아래에 주사위가 굴러가는 모양과 판정이 나와요.
· 표식이 있으면 실제 행동·난이도·결과를, 없으면 난이도별 ‘대실패~대성공’ 표를 보여 줘요
· 상세 창 최근 판정 기록에서 이 채팅/전체로 굴린 값·평균·판정 개수를 봐요
· 저장된 채팅 글은 바뀌지 않아요
4-5💬 채팅 메뉴에서 바로NEW
채팅 입력창 옆 메뉴(≡)에 공정한 전개 · 꺼짐같은 버튼이 생겨요. 누를 때마다 켜고 끄고, 이름도 바로 바뀌어요.
· 공정한 전개 · 유저 편향 없애기 · 주사위 결과 표시
· 설정 → 로어북 · 채팅 메뉴에서 숨길 수 있어요
FEATURE 5 · CACHE
⚡ 프롬프트 캐시 지키기
‘캐시 잘 되는 프롬을 써도 캐시가 박살 난다’는 제보의 원인을 찾아 고쳤어요. 그리고 캐시가 깨지면 바로 알 수 있게 했어요.
5-1🩹 유저 편향을 켜면 캐시가 깨지던 문제FIX
요청마다 바뀌는 주사위 값이 프롬프트 앞쪽에 들어가서, 그 뒤 채팅 기록 전체가 매번 새 프롬프트가 됐어요.
· 바뀌지 않는 규칙은 앞에, 주사위 값만 마지막 입력 바로 앞에 따로
· Claude는 주사위 바로 앞 응답에 캐시 지점을 하나 찍어 그 앞까지 다음 턴에 다시 써요(최대 4개 안에서)
· 재해석·존중 어느 쪽이든 같아요
5-2⏱️ 모델 호출 표시NEW
홈 모델 호출 표시(기본 꺼짐)를 켜면 요청할 때 화면 구석에 상태가 떠요.
· 메인/보조 · 모델 이름 · 추론 중/출력 중 · 흐른 시간
· 끝나면 걸린 시간, 입력·출력 토큰(어림), 캐시로 다시 쓸 수 있는 정도(어림)
· 펼치면 들어간 로어북 목록, 응답 아래에도 접힌 줄로
· RisuBard에서는 동작하지 않아요
5-3⚠️ 캐시 깨짐 알림NEW
앞부분이 직전 요청과 절반도 안 같으면화면 구석에 이유를 잠깐 알려 줘요.
· 예: Dusk ‘장기 기억’에서 달라졌어요
· 옛 메시지를 고쳤다면 깨지는 게 자연스러워요
· 고급 설정 → 이야기 도우미에서 끌 수 있어요(기본 켜짐)
5-4🚪 탭 이동이 가벼워졌어요
홈·기억 탭에 들어갈 때마다 봇의 모든 채팅을 통째로 다시 읽던 것을, 같은 채팅이면 30초 동안 다시 써요.
· 홈은 모양을 먼저 그리고 읽은 정보만 칸에 채워요
· 캐릭터·모듈·플러그인 탭은 읽은 목록을 탭끼리 나눠 쓰고, 처음 읽을 때는 12개씩 끊어서 읽어 ‘응답 없음’이 덜 떠요
· 모듈의 ‘연결 · N’ 숫자는 1분 동안 기억해서 모듈을 켜고 끌 때마다 봇을 다시 읽지 않아요
🔧 그 밖에 바뀐 것
+🩹 그 밖에 고친 점
· 홈의 ‘장기 기억(모든 채팅)’ 스위치를 끄면 다시 켤 수 없던 문제
· 호감도 HUD가 오른쪽 위 다른 버튼과 겹치던 문제(다시 설치하면 적용)
· 기억 카드 단계 번호가 두 번 보이던 문제, 카드가 없을 때 만들기가 안 되던 문제
· 시작 안내 위 창이 가려지던 문제, 창 위 창에서 Esc가 둘 다 닫던 문제
· 모바일 페르소나 ‘AI 대화’ 버튼이 탭바를 가리던 문제, 엉뚱한 아이콘
· 봇별 기억 검색 뒤 스위치가 예전 값으로 보이던 문제
· 기억 분석에서 ‘내 프롬프트 · 뒤’가 맨 끝에 오지 않던 문제
· 모델 호출 칩이 응답이 안 오면 사라지지 않던 문제 등
업데이트 뒤 처음 열면 시작 안내가 한 번 떠요. 지금 설정은 그대로 골라져 있으니 ‘나중에 하기’를 눌러도 괜찮아요. 주사위 결과 표시·모델 호출 표시·거짓말·오해 추적은 기본이 꺼짐이에요. 판정 표식·캐시 어림은 모델과 프로바이더에 따라 다를 수 있어요.
