🧩
FEATURE 1 · ADDONS
🧩 애드온 — 원하는 기능만 골라, 새로고침 없이
Dusk의 기능을 애드온이라는 작은 꾸러미로 나눴어요. 홈·코코아·꾸미기·도구·설정 같은 기본은 본체에 남고, 장기 기억·관계도·기억 카드·Erosync·위젯 홈·스텔스·프로바이더 같은 기능은 필요한 것만 받아서 써요.
1-1📉 본체가 가벼워졌어요NEW
기능을 애드온으로 빼면서 Dusk 본체가 절반쯤 줄었어요(지금 약 2.1MB).
· 안 쓰는 기능은 받지 않으니 리스에 올라가는 양 자체가 줄어요
· 받은 애드온은 리스 플러그인 목록에 따로 뜨지 않아요 — 목록은 Dusk 하나 그대로예요
· 애드온이 하나도 없어도 본체는 그대로 돌아가요
1-2⚡ 새로고침 없이 바로 바뀌어요NEW
새 버전이 나오면 자동으로 받아서 켜 둔 채로 바로 바꿔 끼워요. 리스를 새로고침하지 않아도 돼요.
· 장기 기억·Erosync·프로바이더처럼 요청에 끼어드는 애드온도 바로 바뀌어요
· 1시간마다, 그리고 Dusk 창을 열 때 새 버전을 확인해요. 업데이트 확인을 누르면 방금 올라온 것도 바로 받아요
· 새 버전에서 오류가 나면 알아서 전 버전으로 돌아가요
1-3🎛️ 원하는 기능만 켜요NEW
설정 → 애드온에서 받기·켜고 끄기·지우기를 해요. 처음 켜면 시작 안내에서 쓸 기능을 골라 바로 받을 수 있어요.
· 안 받은 기능은 메뉴·버튼·안내에서도 보이지 않아 화면이 깔끔해요
· 꺼도 기억·설정 데이터는 그대로 남아요 — 다시 켜면 이어서 써요
· 기억 카드·Erosync처럼 장기 기억이 필요한 애드온은 받을 때 함께 받아요
· 예전에 쓰던 기능은 처음 켤 때 자동으로 받아요
1-4💬 건의가 더 빨리 들어가요NEW
애드온만 고쳐 올리면 바로 전해져서, 본체를 다시 내려받을 필요가 없어요.
· 건의받은 기능을 애드온으로 바로 만들어 올릴 수 있어요
· 버그도 그 애드온만 고쳐서 금방 고쳐져요
· 필요한 분만 받으니 다른 분 화면은 그대로예요

🕶️
FEATURE 2 · DUSK STEALTH
🕶️ 더스크 스텔스 — 회사에서도, 밖에서도 편하게
리스 채팅 화면을 주요 AI 앱 공식 화면과 아주 비슷하게 바꿔요. 옆에서 봐도 그냥 AI 앱으로 일하는 화면처럼 보여서, 회사나 카페에서도 눈치 보지 않고 채팅할 수 있어요. 끄면 원래 모양으로 그대로 돌아가요.
2-1🎭 6가지 모양NEW
작업실 → 더스크 스텔스에서 골라요. 켜 둔 채로 다른 모양을 누르면 바로 바뀌어요.
· 클로드 · 클로드 코드 · GPT · 코덱스 · 제미나이 · 딥시크
· 모양마다 그 앱처럼 왼쪽 사이드바가 붙고, 지금 봇의 채팅 목록이 최근 항목으로 떠요 — 누르면 그 채팅으로 가요
· 휴대폰에서는 위 줄과 입력창도 각 앱 휴대폰 화면처럼 바뀌어요
· 밝게·어둡게·기기 설정 따라 중에서 골라요
2-2🖼️ 이미지는 접어서NEW
답변 속 큰 그림은 파일 N개 읽음, 명령어 N개 실행함 줄 아래로 접혀요. 누르면 그 그림만 펼쳐져요.
· 봇 상태창·작은 아이콘은 그대로 두고 큰 일러스트만 접어요
· 따옴표로 감싼 대사는 작업 기록처럼 회색으로 보여요
· 사이드바 캐릭터 얼굴은 흐리게 할 수 있어요
2-3🧷 쓰기 쉽게NEW
맨 위 토글 하나로 켜고 끄고, 자세한 건 접어 뒀어요.
· 상단 제목·입력창 옆 문구·사용자 이름 같은 문구를 바꿀 수 있어요(세부 설정)
· 사이드바 이름 앞 머리 아이콘 그림을 고를 수 있어요 — 이 기기에만 저장돼요
· 홈 화면도 바꾸기를 끄면 채팅 화면만 바꾸고 리스 홈은 그대로 둬요(기본)
· 원래 테마로 되돌리기를 누르면 켜기 전 리스 설정으로 돌아가요
스텔스는 리스의 커스텀 CSS·채팅 HTML 칸을 써요. 켜기 전 값은 따로 보관했다가 끌 때 그대로 되돌려요. 모양이 덜 바뀌어 보이면 리스를 한 번 새로고침해 주세요.

🧠
FEATURE 3 · MEMORY
🧠 장기기억 강화 — 더 싸게, 더 정확하게
장기 기억을 기록하고 정리하는 방식을 새로 만들었어요. 모델에게 보내던 쓸모없는 긴 지침을 걷어 내서 보조 모델 비용이 줄었고, 모델이 중요한 걸 놓치지 않아 기억이 더 확실해졌어요.
응답 1번당 기록에 보내는 글 (인물 2명 기준)
예전 (리수폿 지침 한 번)약 123,000자 · 약 3만 토큰

지금 (짧은 질문 3번 합계)약 10,000자 · 약 2,600 토큰

약 92% 줄었어요
인물이 1명 늘 때마다 지금 방식은 약 3,500자가 더해져요(인물 6명이어도 예전의 약 5분의 1). 본편 전 정리 노트도 8만 자 안팎 → 짧은 질문 1번으로 바뀌었어요. 토큰은 모델마다 달라서 대략값이에요.
3-1✂️ 긴 지침 대신 짧은 질문NEW
예전에는 응답마다 11만 자가 넘는 지침 하나로 한꺼번에 물었어요. 이제 장면 1번 + 인물마다 1번, 짧은 질문으로 나눠 물어요.
· 보내는 글이 확 줄어서 토큰·요금이 덜 들어요
· 좋은 모델도 무엇이 중요한지 놓치던 문제가 줄었어요 — 게이지·요약을 빼먹지 않아요
· 인물 카드(관계·평가·말투·알게 된 것·비밀)·호감도·장면 요약·떡밥을 기록해요
· 켜 둔 칸은 전부 채워요 — 의도·태도·숨긴 마음·의심·개방성까지
3-2📋 정리 노트도 가볍게NEW
본편 응답 전에 보내던 8만 자 안팎의 지침도 없앴어요.
· 저장된 값(상태·호감도·관계·말투·비밀 등)은 프로그램이 정리표로 그대로 넣어요 — 값이 바뀌어 전달되지 않아요
· 모델에게는 짧은 질문 1번으로 ‘이번 응답 방향’ 몇 줄만 받아요
· 응답이 끊겨(검열·오류) 다시 요청해도 보조 모델을 또 부르지 않아요 — 같은 요청이면 결과를 다시 써요
3-3🎯 더 확실한 기억NEW
틀린 기억이 대화에 섞이던 일을 막았어요.
· 죽음·실종·떠남 같은 상태는 본문 인용과 함께 따로 남기고, 예전 기록보다 우선해요 — 죽은 인물이 살아 있는 것처럼 나오지 않아요
· 인물 게이지가 제대로 움직여요 — 8턴마다 그동안의 글을 보고 작은 호출로 바꿔요
· 기억 설정에서 ‘최근 기록 결과’(새 인물·갱신·호감도 변화·상태)를 볼 수 있어요
· 예전 방식이 좋으면 기억 설정 → 고급 → 분석 → ‘기록 방식’에서 고를 수 있어요

🔌
FEATURE 4 · PROVIDER
🔌 프로바이더 (실험) — 내 API를 리스 모델 목록에
내 API 키와 모델을 프로필로 만들어 두면, 리스 모델 목록에 Dusk 자동과 Dusk · 프로필 이름으로 나타나요. 키 보관부터 비용 아끼기까지 한곳에서 다뤄요. 설정 → 실험 기능을 켜고 프로바이더 애드온을 받으면 써요.
4-1🔑 연결·프로필NEW
공급자를 연결하고 모델을 골라 프로필을 만들어요.
· API 키는 키 보관함에 저장하고, 키를 여러 개 돌려 쓰거나 실패했을 때만 다음 키로 넘어가게 할 수 있어요
· AWS Bedrock(API 키)·NovelAI·OpenCode Zen·Gemini Express Mode 연결도 돼요
· 다시 시도할 오류(서버 오류·429)와 키 쉬는 시간을 고를 수 있어요
4-2💸 비용 아끼기NEW
같은 대화라도 덜 내게 도와줘요.
· Claude 캐시: 몇 메시지마다 고정하는 격자 캐시, 직전 요청과 같은 앞부분을 찾는 캐시 학습
· Claude 배치로 보내기(값 절반)
· 라우터: 글자 수·들어 있는 글·용도 조건에 따라 알맞은 프로필로 보내요
· 사용량: 기간별·날짜별·모델별 표, 캐시로 아낀 돈까지
4-3🧰 그 밖에NEW
더 깊게 쓰고 싶은 분을 위한 기능이에요.
· 진행 창: 리스 화면 오른쪽 아래에 요청마다 카드가 떠서 진행·다시 시도·받은 글자 수(약 N토큰)를 보여 줘요
· 로그: 최근 요청과 오류를 한 줄씩(키는 가려요)
· 확장: MCP 서버 도구 쓰기, 보내기 전·받은 글 바꾸기 훅, 다른 플러그인이 Dusk 프로바이더를 쓰게 하는 창구(기본 꺼짐)
프로바이더는 아직 실험 기능이에요. 일부 연결(Bedrock IAM 서명 등)은 아직 안 되고, 모든 공급자를 실제로 확인하지는 못했어요. 문제가 있으면 알려 주세요.
