FEATURE 1 · GLASS UI
🪟 글래스 화면 & 테마 22가지
빛이 번지는 배경 위에 유리 카드로 보이는 새 화면이에요. 카드 안은 글이 잘 읽히게 반투명 단색으로 두고, 화려함은 배경과 포인트에만 썼어요. 밝게·어둡게 모두 되고, 모든 테마에서 본문 글자 대비를 4.5:1 이상으로 맞췄어요.

1-1🎨 테마 22가지 — 꾸미기 맨 위에서 골라요NEW
기본 ‘Dusk 황혼’과 나이트 다이어리·벚꽃·오로라·노을·은하·네온·숲 등 22가지예요. 플러그인 꾸미기 맨 위 큰 칸에서 누르면 바로 바뀌어요. 처음엔 8가지만 보이고 ‘더 보기’로 전부 펼쳐요.
· 색을 직접 고르면 ‘내 강조색’으로 저장돼요
· 나머지 설정(밝기·글자·화면·고급)은 펼치는 줄로 정리했고, 줄 오른쪽에 지금 값이 보여요

1-2🪶 가벼운 화면 — 느린 기기는 빛만 끄고NEW
꾸미기 → 모양에서 글래스 화면을 끄거나 가벼운 화면을 켤 수 있어요. 가벼운 화면은 흐림·빛 효과를 빼서 PocketRisu·RisuBard 같은 기기에서 가볍게 돌아요(이 두 앱은 자동으로 켜져요).
· 시스템의 ‘투명도 줄이기’ 설정도 따라가요
· 스크롤할 때 화면이 가끔 깜빡이던 문제도 고쳤어요
1-3💡 기능 색 빛 막대DESIGN
카드·타일 왼쪽에 기능 색 빛 막대가 붙어서 어떤 칸인지 한눈에 구분돼요. 기억은 분홍, 관리·설정은 파랑, 작업실은 민트예요. 대화상자·메뉴 같은 팝업도 유리 모양이에요.

FEATURE 2 · HOME & MENU
🏠 새 홈 & 메뉴
홈은 지금 열린 채팅과 장기 기억 상태를 가운데 크게 보여 주고, 바로가기·숫자·최근 기록·빠른 설정·이어서 하기·추천을 위젯으로 모았어요. 왼쪽 메뉴도 깔끔해졌어요.

‘홈 꾸미기’를 누르면 위젯을 끌어 옮기고, 모서리를 잡아 크기를 바꿔요. 칸에 딱 붙고, 겹치면 알아서 비켜요.
· 숨기기·다시 넣기·기본 배치로 돌아가기
· PC·모바일 배치를 따로 기억해요
2-2🧭 아이콘 레일 & 섹션 색NEW
왼쪽 메뉴는 평소엔 아이콘만 보이고, 마우스를 올리면 펼쳐져요. 기억·관리·작업실은 색으로 구분하고, 지금 있는 섹션만 펼쳐요. ⋯ 메뉴에서 ‘늘 펼침’을 고를 수 있어요.
· 위쪽 메뉴를 쓰면 섹션 알약 3개 + 칩 줄로 바뀌어요
· 모바일 아래 탭바는 섹션 색 동그라미 아이콘이에요
· 기능 찾기: 홈은 가운데, 다른 화면은 오른쪽 위

FEATURE 4 · FEATURES & ADD-ONS
🧩 기능·애드온 변화
화면 말고 동작이 바뀌거나 새로 생긴 것을 모았어요. 애드온은 본체 2.2.0 이상이 필요해요. 홈의 애드온 카드에서 ‘모두 받기·업데이트’를 누르면 한 번에 받아요.
4-1💗 Erosync 매 턴 계산NEW
NSFW 설정 → 분석·관리에서 켜면, 장기기억이 턴을 기록할 때마다 그 턴에 나온 인물의 성향 값을 대화에 맞게 조금씩 고쳐요. 바뀐 항목만 한 번 호출하고, 한 턴에 15까지만 바뀌어요.
· 8가지 성향·성적 항목 중 계산할 것을 골라요
· 최근 바뀐 값과 이유를 카드에서 봐요
· 직접 고친 값과 잠근 인물은 그대로예요
· 예전 ‘인물 분석’은 출발값 만들기로 이름이 바뀌어 매 턴 계산 아래에 있어요

자동 재분석도 다시 돌아가요. Dusk 모델 설정으로 분석할 때 늘 ‘수동 재분석 필요’로 멈추던 걸 고쳤어요. 이제 내용이 바뀐 자료를 쓰는 인물만 다시 분석해서 호출이 크게 줄고, 새 인물을 찾아야 할 만큼 바뀌면 직접 분석하라고 알려 줘요. (Erosync 0.1.5)
4-2🗄️ Dusk Cellar 연동 & 에셋 제작NEW
백그라운드 서버 Dusk Cellar가 있으면 에셋 제작의 예약한 그림을 Cellar가 대신 그려요. 리스 창을 닫아도 계속 그리고, 다시 열면 그동안 그린 그림이 씬에 붙어요.
· 그림은 리스 에셋에 바로 들어가서 봇·모듈에 넣을 때 빨라요
· Cellar가 리스와 따로 돌아서 연결이 덜 끊겨요(잠깐 느려도 세 번은 기다려요)
· 세이브 복원은 예약해 두면 리스를 끌 때 바로 해요
· Cellar가 없어도 플러그인은 지금처럼 동작해요(선택 기능)
4-3🧠 장기 기억 기록이 더 안정적이에요FIX
장기기억 애드온 0.2.13으로 업데이트하면 적용돼요.
· 월경 추적을 켠 채 기록이 통째로 실패하던 것 — 한 턴이 Writer 묶음 2개 이상으로 나뉘면 같은 새 문서 참조가 겹쳐 그 턴 기록이 전부 실패했어요. 이제 한 인물은 한 묶음에서만 월경 보고를 붙여요
· ‘저장된 기록’ 막대의 ‘예산 제한’이 크게 나오던 것 — 끔으로 둔 인물과 이번 장면에 안 나온 인물은 ‘관련 없음’, 토큰이 모자라 빠진 것만 ‘예산 제한’이에요
· 로어북 로그가 실제로 들어간 항목을 빠졌다고 하던 것 — {{user}}를 지금 쓰는 페르소나 이름으로 대조해요
· 분기 채팅에서 인물 이름 바꾸기·통합이 반만 적용돼 위키 쓰기가 막히던 것 — 옛 연결만 버리고 읽어요. 남은 두 인물은 인물 위키의 인물 합치기로 합치면 돼요

4-4💬 응답 아래 표시 & 이미지 태그FIX
· 이매진 같은 플러그인이 응답 끝에 붙인 데이터를 지워도 응답 아래 로어북·주사위·모델 호출 표시가 나와요(글 가운데로도 응답을 찾아요)
· 이미지 태그 알림이 .webp 같은 확장자를 퍼뜨리던 것 — 이제 실제 에셋 이름으로 알려 주고, 확장자를 붙이지 말라고도 알려요
4-5📥 기억 넣기 & 저장CHANGE
· 장기 기억 블록이 기본으로 프롬프트 맨 뒤에 들어가요(설정 → 삽입 위치)
· 기억 저장이 실패하면 어느 기억이 몇 MB였는지 알려 줘요
· 인물 위키 설정 → 고급의 ‘자동 기록 세부’는 장기 기억 → 설정으로 옮겼어요. ‘자동 기록 입력 예산’은 ‘기억 넣기 토큰’ 바로 밑에 따로 있고, 값은 그대로예요
4-6🏷️ 이름·자리가 바뀐 기능CHANGE
