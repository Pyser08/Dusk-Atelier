PART 1 · NEW
✨ 이번에 추가된 기능
기억을 더 정확하게 쌓고, 더 알맞게 꺼내고, 내가 직접 고칠 수 있게 했어요. 새 칸은 전부 필요할 때만 써서 토큰을 아껴요.
1🧪 믿을 수 있는 기억 — 사실과 추측을 구분해요NEW
기록마다 확정된 사실인지 AI의 짐작인지, 얼마나 확실한지(높음·중간·낮음)를 같이 적어요. 짐작은 프롬프트에 [추정] 표시가 붙어서 AI가 사실처럼 믿지 않아요.
· 취향이 바뀌면 옛 값은 이력으로 남기고 새 값을 써요 (예: 커피 → 차)
· 조건부(“비 올 때만”)·과거 이야기는 현재 사실과 구분해요
· 확실도가 비슷해 판단이 안 서는 건 보류으로 두고 덮어쓰지 않아요
· 같은 응답을 다시 분석하거나 리롤해도 횟수가 중복으로 늘지 않아요
2💗 감정 6가지 게이지 — 호감도 하나가 아니에요NEW
신뢰 · 애정 · 적대 · 의존 · 존경 · 두려움을 0~10으로 따로 기록해요. 사랑하면서 두려워하는 것처럼 여러 감정이 동시에 있을 수 있어요. 값이 없으면 ‘미설정’이에요.
· AI는 “신뢰 +2, 이유: 도와줌”처럼 변화량과 근거만 내요. 숫자는 코드가 계산해요
· 감정이 서로 충돌하면 [충돌]로 표시해요
· 기존 호감도 수치는 다음 기억 분석 때 ‘애정’으로 한 번 옮겨져요 (되돌리기 가능, 위키 호감도 원본은 그대로)
3🔑 검색 키 — 단어로 기억을 불러와요NEW
기억마다 열쇠·편지·금요일처럼 나중에 다시 나올 단어를 저장해요. 지금 장면에 그 단어가 나오면 등급이 낮은 기억도 끌어올리고, 장면에 없던 인물의 기억도 불러와요.
4🔎 임베딩(의미 검색) — 단어가 달라도 뜻으로 찾아요NEW
“검은 열쇠”와 “낡은 자물쇠 열쇠”처럼 표현이 달라도 뜻이 비슷한 기억을 찾아 넣어요. 무료 임베딩 API를 쓰면 돼요.
· 기억 설정 → 임베딩 설정에서 API 주소 · 모델 · 키를 넣어요 (OpenAI 호환 주소, 로컬 서버도 가능)
· 기본으로 사용 토글과 대기 시간(초)을 직접 정해요 (기본 꺼짐 · 4초)
· 연결 테스트 버튼으로 바로 확인해요
· 기억 넣기와 리수폿 회상 모두에 적용돼요. 느리거나 실패하면 그 요청은 원래 방식으로 넘어가서 채팅이 막히지 않아요
· 키는 이 기기에만 저장돼요 (백업·공유에 안 들어가요)
5🎭 인물 시점 · 속마음 · 기대 어긋남 (중요한 장면만)NEW
같은 사건을 인물마다 다르게 받아들인 것, 겉과 다른 속마음과 그 짐작 원인, 서로 다르게 기대하고 있던 것을 기록해요. 장면이 크게 바뀌거나 중요한 일(B등급 이상)일 때만 받아서 토큰을 아껴요.
· 속마음은 항상 “짐작”으로 표시돼요 (확정 사실 아님)
· 기억 설정에서 이 줄들을 프롬프트에 넣을지 끌 수 있어요
6✏️ 주입 로어 편집 — 대화에 들어가는 기억을 내가 고쳐요NEW
고급 모드 → 기억 탭 → ‘기억 방식’ 바로 아래. AI에게 실제로 들어가는 [Dusk Memory] 내용을 줄 단위로 보고 고쳐요.
· 고치기 · 숨기기 · 원래대로 (저장된 기억은 안 바뀌고, 요청에 넣을 때만 적용돼요)
· 내 로어: 직접 쓴 한 줄을 항상 넣어요 (기억이 없어도 들어가요)
· 기억이 새로 분석돼 줄이 바뀌면 수정은 ‘적용 안 됨’으로 내려가고, ‘내 로어로 옮기기’를 고를 수 있어요
· 총 토큰 수 표시 · 복사 · 수정 모두 지우기
7🛠️ 기억 데이터 편집(상세) — 저장된 기록 자체를 고쳐요NEW
고급 모드에서 기록 · 상황·관점 · 감정 · 기대 4탭으로 직접 고쳐요. 내가 고친 칸은 잠겨서 자동 분석이 덮어쓰지 않고, 바로 한 단계 되돌리기도 돼요.
8🪙 토큰을 아끼는 장치NEW
새 칸은 전부 해당될 때만 써요. 분석 프롬프트가 호출마다 약 430토큰 늘고, 요청마다 들어가는 기억은 평범한 장면에서 약 7%만 늘어요(가상 시나리오 추정). 이전 버전 기억은 그대로 이어져요 (다시 나온 기록만 새 칸을 채워요).
PART 2
🧠 장기기억, 이런 기능이 있어요
예전부터 있던 기능을 한눈에 정리했어요. 각 항목을 눌러 펼쳐 보세요.
1📝 자동 기록 — 응답이 끝날 때마다
보조 모델이 등장인물의 행동과 지금 상황을 짧게 기록해요. 기본은 내가 다음 말을 보낼 때 직전 응답을 확정해서, 다시 생성하거나 넘겨 봐도 기록이 덜 꼬여요. 지난 대화는 ‘지난 대화 분석’으로 한꺼번에(안 한 응답만) 해요.
2🏅 등급 6단계 — 중요한 것만 오래
기록마다 D · C · B · A · S · EX 등급을 매겨요. 얼마나 오래가는지 · 얼마나 바뀌는지 · 얼마나 널리 영향을 주는지로 정해요. 오래 안 쓰인 D·C는 알아서 빠지고, 자주 쓰인 기억은 강해져요.
3📚 기록 보기 — 인물 · 상황 · 시간선 · 열린 항목 · 관계
인물별 기록, 장면 요약, 시간순 흐름, 아직 안 풀린 약속·복선(열린 항목), 두 인물 사이 변화(관계)를 한 화면에서 봐요. 기록을 지울 땐 확인창이 먼저 떠요.
4💉 기억 넣기 — 요청마다 필요한 만큼
이야기 요약(Story so far) · 현재 상태 · 관련 인물 기억을 정해진 토큰 예산(목표 1,200 / 상한 2,500) 안에서 넣어요. 최근 메시지와 겹치는 건 빼고, 삽입 위치와 예산은 고급 모드에서 바꿔요. 안 들어갔으면 이유를 한 줄로 알려 줘요.
5🕵️ 지식 경계 · 확장 기억
누가 아는지를 기록해서 모르는 인물이 아는 척하지 않게 해요. 그 밖에 열린 항목, 관계 변화, 원문 발췌, 이야기 시간까지 한꺼번에 넣고, 설정에서 확장 기억만 따로 끌 수 있어요.
6📖 리수폿 인물 위키 병합
인물마다 호감·의심·마음 열기 수치, 관계·호칭·말투, 첫인상·현재 평가를 위키로 정리해요. 기억과 리수폿은 따로 켜고 끌 수 있고, 인물별 사용 여부도 정해요. 비어 있는 인물은 AI로 채울 수 있어요.
7🔄 한 번에 도는 장기기억 흐름
요청 직전엔 관련 인물 고르기 → 기록 회상 → 정리 노트 → 주입, 응답 뒤엔 위키와 사건 기록을 AI 호출 한 번으로 처리해요. 처음 설정은 3단계(AI 고르기 → 무엇을 기억할까요 → 켜기)예요.
8🔌 내 API · 내 프롬프트
리스 보조 모델 또는 내 API(OpenAI · Anthropic · Gemini · OpenRouter · DeepSeek 등)로 기억을 돌리고 연결 테스트를 해요. 기억·리수폿에 덧붙일 내 프롬프트도 단계·위치(앞/중간/뒤)를 정해 넣어요.
9🃏 기억 카드 · 새 봇 만들기
인물 1명의 기록을 카드 한 장(이미지+정보)으로 만들고, 그 카드로 새 봇을 만들어요. 기억 연결(이미 겪은 일) / 운명 연결(아직 겪지 않은 앞날) 중에 골라요. 기록 지점에서 여기서 새 채팅으로 이어가기도 돼요.
10📦 저장소 · 리스바드 · 되돌리기
저장소는 자동 · 플러그인 · BardWiki · 끔 중에 고르고, 설정 바꾼 이력은 10개까지 되돌려요. 롤백했을 때 내가 고친 내용과 AI 기록이 겹치면 변경 비교로 알려 줘요. 다시 생성·삭제한 응답의 기억은 프롬프트에서 자동으로 빠져요.
11⚖️ 이야기 도우미
기억과 별개로 켜는 스위치예요. 공정한 전개(내 캐릭터에게만 유리하게 풀리는 걸 줄여요), 이야기 시간(지금 날짜·시각·장소를 요청 맨 위에 적어 줘요).
⚠️ 기억 데이터 편집·주입 로어 편집은 설정 → 화면 모드 → 고급에서 보여요. 이미 쌓인 기억은 그대로 이어지고, 호감도 수치는 해당 채팅에서 기억 분석이 한 번 돌 때 ‘애정’ 게이지로 옮겨져요.
