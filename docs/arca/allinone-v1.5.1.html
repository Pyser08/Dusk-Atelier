ALL-IN-ONE GUIDE · v1.5.1
Dusk Atelier 올인원
RisuAI용 모듈·캐릭터·플러그인 관리 플러그인이에요. 쓰는 분께 필요하고 좋은 기능만 골라 탭 순서대로 모았어요. 개발 기능은 개발자용 글에 따로 있어요.
⬇ dusk_atelier.js 받기
📚 가이드 글  📘 일반 사용자용 올인원 · 🛠️ 개발자용
🚀 시작하기
설치
•RisuAI 설정 → 플러그인에서 dusk_atelier.js를 추가해요.
•예전 이름 Dusk Manager로 설치했다면 그건 지우고 새로 추가하세요. 설정·폴더·백업 기록은 그대로 이어져요.
•원본 RisuAI에서 처음 열 때 데이터베이스 접근 권한을 물으면 허용해 주세요.
•새 버전이 나오면 RisuAI 플러그인 업데이트로 바로 받을 수 있어요.
열기
•왼쪽 사이드바(햄버거 메뉴)의 Dusk Atelier를 누르거나, 설정 메뉴에서 열어요.
•창 안 아무 데나 파일을 끌어다 놓으면 바로 가져오기가 시작돼요.
화면 구성
•탭은 다섯 개예요. 모듈 · 플러그인 · 캐릭터 · 도구 · 설정 다섯 탭이에요. 프리셋과 기록은 도구 탭 안에 있어요.
어디서 되나요
•RisuBard: 기준 환경이에요. 모든 기능이 돼요.
•원본 RisuAI: 모든 기능이 돼요.
•RisuVault: 모듈 기능은 모두 돼요. 대화가 긴 봇은 RisuVault가 채팅 보호로 막아서 봇 편집·에셋·업데이트·패치 적용이 안 돼요. 이때는 안내만 보여 주고 아무것도 바꾸지 않아요.
✨ 이것만 알아도 돼요

폴더·순서
모듈·봇을 폴더로 묶고 끌어서 정리해요. 사이드바와 같이 바뀌어요.
🖼️
에셋 관리
일괄 교체, WebP 줄이기, 같은 그림 찾기를 한 화면에서 해요.
📖
로어북 로그
이번 응답에 어떤 로어북이 들어갔는지 바로 확인해요.
🔄 모듈·봇 사용자용 업데이트·패치 받기 (눌러서 펼치기)
봇·모듈을 받아서 쓰는 분을 위한 부분이에요. 새 버전이 나왔을 때 내가 고친 건 지키면서 업데이트하는 방법을 정리했어요. 탭별 기능은 아래에 있어요.
같은 업데이트, 받아야 하는 크기
276MB 모듈을 고쳤을 때
새 버전 파일을 통째로 다시 받기276MB

패치 · 이미지 2장 포함1.8MB (약 1/150)

패치 · 글만 수정21.4KB (약 1/13,000)

측정 예: 로어북 1,500개 · 이미지 400장(장당 약 700KB) 모듈. 글만 수정 = 로어 5개 수정 + 로어·정규식 1개씩 추가, 이미지 2장 포함 = 여기에 이미지 1장 교체·1장 추가. 막대는 로그 눈금이에요.
01 · 바뀐 것만
작게 받고, 적게 올려요
패치에는 바뀐 로어·정규식·트리거·설정과 새 이미지만 들어가요. 새 버전 파일을 통째로 넣어도 서버에 이미 있는 이미지는 다시 올리지 않아요.
02 · 내 수정은 그대로
번역·직접 고친 설정 유지
지난번 받은 것 · 지금 내 것 · 새 버전을 비교해서 합쳐요. 내가 고치고 추가한 항목은 남고, 같은 곳을 둘 다 고쳤으면 따로 알려 줘요.
03 · 되돌리기
자동 백업, 채팅은 안전
적용하기 전 상태를 자동으로 백업해요. 업데이트 직후 바로 되돌리기를 누르거나 도구 → 기록에서 원하는 시점으로 돌아가요.
업데이트하는 두 가지 방법
A패치 파일(.rbupatch)을 받았을 때
제작자가 올린 작은 패치 파일 하나로 끝나요. 모듈은 모듈 메뉴(⋯) → 패치 적용, 봇은 캐릭터 탭 → 패치 적용을 누르고 파일을 고르세요.
적용하기 전에 버전, 제작자, 변경 내용, 바뀌는 개수를 먼저 보여 줘요. 패치 안에 원본 정보가 들어 있어서 따로 준비할 건 없어요.
B새 버전 파일을 통째로 받았을 때
.risum · .charx · PNG/JPEG 카드 · .json을 도구 → 업데이트 가져오기에 넣거나 창에 끌어다 놓으세요. 새로 추가하지 않고 이미 있는 모듈·봇을 찾아서 업데이트해요. 리스에서 평소처럼 가져와도 "이어 붙일까요?"라고 물어봐요.
B 방법에서 알아서 해 주는 것
•바뀐 에셋만 올려요: 이미지가 수백 장인 봇도 바뀐 것만 올라가서 금방 끝나요.
•알아서 찾아요: 버전 표기가 달라도 같은 모듈·봇으로 찾아요. 꺼 둔 모듈도 찾고, 업데이트한 뒤에도 꺼진 채로 둬요.
•연결 기억: 한 번 고른 짝을 기억해서 다음 버전부터는 바로 그 대상을 골라요.
•여러 파일 한 번에: 넣은 순서대로 차례차례 처리해요.
•충돌 고르기: 같은 곳을 제작자와 내가 둘 다 고쳤으면 어느 쪽을 쓸지 항목마다 골라요.
•내 설정 보호: TTS·음성, 메모리, 번역 노트 같은 설정과, 채팅마다 고른 추가 인사말을 그대로 지켜요.
💡 패치(A)는 원본 정보가 파일 안에 있어서 바로 적용돼요. 새 버전 파일(B)은 그 봇·모듈을 Dusk Atelier로 한 번 가져온 뒤부터 원본이 기록돼서, 그다음 업데이트부터 내 수정을 정확히 지켜 줘요.
📌알아 두면 좋은 것업데이트·백업을 쓸 때
쓰는 중에
•봇이 답변을 만드는 중에는 업데이트·저장을 막아요. 끝난 뒤 다시 눌러 주세요.
•적용한 뒤 마음에 안 들면 도구 → 기록에서 그 전 시점으로 되돌려요. 채팅은 그대로예요.
•설정(테마·폴더·프리셋)은 다른 기기와 함께 동기화돼요.
플러그인을 지울 때
•꺼 둔 모듈은 이 플러그인 보관함에 있어요. 지우기 전에 설정 → 설정 정리 → 꺼진 모듈 모두 켜기로 꺼낸 다음 지워 주세요.
🛠️ 봇·모듈을 만드는 분이라면, 수정할 때마다 수백 MB 파일을 다시 올릴 필요가 없어요. 패치 만드는 방법은 개발자용 가이드 글에 있어요.
👤 탭별 기능 큰 줄기만 보려면 각 탭의 굵은 제목만 훑어보세요
📦모듈 탭모듈을 켜고 끄고, 묶고, 고치는 곳
찾기·켜기·끄기
•이름, 로어북 키, 정규식·트리거 이름으로 검색하고, 전체 · 켜짐 · 꺼짐 · 전역으로 걸러요.
•끈 모듈은 RisuAI 목록에서 빠져 보관함에 들어가요. 끈 뒤 8초 안에 되돌릴 수 있어요.
•에셋이 있는 모듈은 끌 수 없어요. 끄면 RisuAI의 에셋 정리로 파일이 지워질 수 있어서예요.
폴더·순서·이름 색
•폴더를 만들고 접고 펴고 색을 줘요. 만들 때 넣을 모듈을 바로 고르거나, 모듈을 끌어서 폴더에 넣어요.
•줄 왼쪽 손잡이(점 여섯 개)를 잡고 끌어 순서를 바꿔요. 모바일에서도 돼요. PC는 Alt+↑/↓도 돼요.
•모듈마다 이름 색을 정해요. 어떤 밝기에서도 읽히게 진하기를 자동으로 맞춰요.
연결
•글로벌: 모든 채팅에서 켜요. 페르소나별: 그 페르소나를 쓰는 동안 자동으로 넣어요. 캐릭터별: 특정 봇에만 연결하고, 지금 채팅에서만 뺄 수도 있어요.
고치기 · 메뉴
•모듈 ⋯ 메뉴: 편집, 에셋 관리, .risum 내보내기, 이름 바꾸기, 패치 적용, 삭제. 삭제해도 지우기 전 상태가 남아 도구 → 기록에서 되살려요.
•편집기는 로어북·정규식·트리거를 탭으로 나눠 고쳐요. Ctrl+F 찾기, Ctrl+S 저장, Ctrl+Z 되돌리기.
•저장 전에 바뀐 내용을 요약해 보여 주고, 정규식 오류나 키 없는 로어북은 미리 알려 줘요. 저장 전 상태는 자동 백업돼요.
에셋 관리자
•한 번에 여러 개 고르기, 끌어 놓아 추가, 교체·일괄 교체(이름 또는 순서로 맞춤), 폴더로 정리, 바꾼 뒤 되돌리기.
•내려받기(여러 개면 폴더 구조 그대로 ZIP), WebP 최적화(더 작아지는 것만 바꿔요), 중복 찾기(같은 그림을 묶어 보여 주고, 묶음마다 하나는 꼭 남겨요).
🧩플러그인 탭설치한 플러그인을 정리하고, 연동되는 플러그인의 설정을 바꾸는 곳
목록
•설치한 플러그인을 카테고리로 묶어서 봐요. 업데이트 주소가 있는 플러그인은 새 버전이 있는지 확인해요. 목록을 JSON으로 내보내 백업할 수 있어요.
연동 설정
•Dusk와 연동되는 플러그인은 설정 화면이 여기에 자동으로 생겨요. 값을 바꾸거나 프리셋을 고르면 그 플러그인에 적용돼요.
•그 플러그인이 켜져 있고 RisuAI 화면이 열려 있어야 해요. 몇 초 안에 반영돼요.
•ℹ️ 플러그인을 켜고 끄거나 순서·코드를 바꾸는 건 RisuAI가 플러그인끼리 못 하게 막아 뒀어요. RisuAI 설정 → 플러그인에서 해 주세요.
🧑캐릭터 탭봇을 정리하고 고치는 곳
폴더·순서
•RisuAI 사이드바의 폴더·순서를 그대로 써요. 여기서 바꾸면 사이드바에도 바로 반영돼요.
•폴더를 만들 때 넣을 봇을 고르고, 손잡이로 끌어 순서를 바꾸거나 폴더에 넣고 빼요. 폴더를 지워도 봇은 남아요.
봇 편집 · 에셋 · 업데이트
•모듈 편집기와 같은 화면에서 정보(이름·설명·첫 메시지·시나리오 등)·로어북·정규식·트리거를 고쳐요. 채팅과 메모는 건드리지 않아요.
•에셋 관리자로 봇의 추가 에셋을 관리해요. 모듈과 기능이 같아요.
•봇 메뉴에서 업데이트 가져오기, 패치 적용을 바로 할 수 있어요.
🧰도구 탭프리셋, 기록, 업데이트, 합치기, 백업 같은 작업 도구
프리셋
•켤 모듈과 순서, 글로벌 활성화를 묶어 저장해요. 새로 만들기, 전환, 덮어쓰기, 이름 바꾸기, 삭제(모듈은 남아요), 전체 내보내기·가져오기가 돼요.
•공유 코드: ⋯ 메뉴의 공유 코드 복사로 한 줄 코드를 만들어 친구에게 줘요. 받는 쪽은 가져오기 → 공유 코드 붙여넣기. 모듈 id가 달라도 이름이 같으면 이어 줘요.
•디바이스 페어: 모바일용·데스크탑용 프리셋을 정해 두면 기기가 바뀔 때 자동으로 전환해요.
기록 · 되돌리기
•업데이트·편집·삭제하기 전 상태가 대상별로 시간순으로 쌓여요. 고른 시점으로 되돌리면 지금 상태도 먼저 백업해요.
•되돌려도 채팅은 그대로고, 지운 봇도 새 봇으로 되살아나요. 모듈은 그 시점과 지금을 비교해 볼 수 있어요.
업데이트 가져오기
•.risum · .charx · PNG·JPEG 카드 · .json을 넣으면 이미 있는 모듈·봇을 찾아서 업데이트해요. 여러 파일도 차례로 처리해요.
•지난번 받은 것 · 지금 · 새 버전을 비교해 내가 고친 건 지키고, 둘 다 고친 곳만 직접 골라요.
•적용 전에 영향 미리보기(켜진 모듈·쓰는 봇·채팅 수)를 보여 주고, 적용 직후 바로 되돌리기를 누를 수 있어요.
다른 봇에서 가져오기 · 합치기
•다른 봇이나 모듈에서 인물만, 인물과 세계관, 또는 전체를 가져와 합쳐요. 겹치는 이름은 자동으로 바꾸고, 항목마다 넣기·빼기를 정해요.
로어북 로그
•응답마다 어떤 로어북 항목이 프롬프트에 들어갔는지 기록해요. 일반 봇도 돼요. [지금 채팅] / [전체]로 나눠 보고 이름·입력으로 찾아요.
•AI 응답 아래 📖 로어북 N개 버튼을 누르면 바로 보여요. 화면에만 붙고 저장된 채팅은 그대로예요.
전체 백업 · 복원
•빠른 백업은 모듈 내용·켜짐·순서·프리셋·폴더·색 설정만, 에셋까지는 에셋 파일도 모두 담아요. 서버를 옮길 때 써요. 전체 복원은 백업 zip에서 되살려요.
