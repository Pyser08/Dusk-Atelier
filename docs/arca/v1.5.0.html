1 Dusk Atelier 소개 — 패치 업데이트 + 모듈·봇 관리 v1.0.0
📖 처음이라면 — Dusk Atelier 사용 가이드 (눌러서 펼치기)
Dusk Atelier는 RisuAI의 모듈·봇을 관리하고 업데이트하는 플러그인이에요. 수백 MB짜리 봇·모듈도 바뀐 부분만 받아 업데이트하고, 내가 고친 부분과 채팅은 그대로 지켜요. 원본 RisuAI와 PocketRisu·RisuBard에서 써요.
시작하기
1
아래 설치 버튼으로 dusk_atelier.js를 받아 RisuAI 설정 → 플러그인에 추가해요.
2
왼쪽 사이드바(햄버거 메뉴)의 Dusk Atelier를 눌러 열어요. 설정 메뉴에서도 열려요.
3
새 버전이 나오면 설정 → 플러그인의 초록색 + 버튼 하나로 업데이트돼요.
업데이트하는 세 가지 방법
리스에서 그냥 가져오기
평소처럼 봇·모듈을 가져오거나 리스 화면에 끌어다 놓으면, 기존 것의 새 버전인지 알아보고 이어 붙일지 물어요. 새 봇이면 오른쪽 위 알림으로 다른 봇과 합칠지 물어요.
새 버전 파일
Dusk의 가져오기에 .charx · .risum · PNG 카드 · .json을 넣으면 이미 있는 봇·모듈을 찾아서 업데이트해요. 여러 파일도 차례대로 처리해요.
패치 파일
제작자가 올린 작은 .rbupatch 파일이라면 모듈 ⋯ 메뉴나 봇 메뉴의 패치 적용으로 넣어요.
어느 쪽이든 지난번 받은 파일·지금·새 버전을 비교해서 제작자가 바꾼 건 새 버전으로, 내가 고친 건 그대로 둬요. 같은 곳을 둘 다 고쳤으면 충돌로 알려 주고 항목마다 골라요. 적용하기 전에 어디에 닿는지(켜진 모듈·쓰는 봇·채팅 수) 미리 보여 주고, 바꾸기 전 상태는 자동으로 백업돼요.
탭 다섯 개
모듈
켜기·끄기(8초 안에 되돌리기), 폴더·이름 색, 검색·필터, 끌어서 순서 바꾸기, 글로벌·페르소나별·캐릭터별 연결. ⋯ 메뉴에 편집·에셋·내보내기·패치 적용·삭제가 있어요.
플러그인
설치한 플러그인 목록·업데이트 확인, 연동(DA Interop) 플러그인의 설정 바꾸기, 연동 플러그인 만들기, 플러그인 저장소 보기.
캐릭터
리스 사이드바와 같은 폴더·순서를 써요. 여기서 바꾸면 사이드바도 바로 바뀌어요. 봇 편집, 에셋 정리, 업데이트·패치, 다른 봇에서 가져오기·합치기를 해요.
도구
프리셋(모듈 조합·순서 저장, 모바일·PC 자동 전환, 공유 코드), 기록·되돌리기, 업데이트 가져오기, 합치기, 전체 백업·복원, .risum 인스펙터.
설정
로어북 규칙(리롤 때 확률 새로 굴리기/유지), 색 바꾸기, 업데이트 설정, 설정 정리, 개발자 모드.
에디터 · 에셋 관리자
로어북·정규식·트리거를 탭으로 나눠 항목별로 고쳐요. 찾기 Ctrl+F, 저장 Ctrl+S, 되돌리기 Ctrl+Z. 정규식 오류·키 없는 로어북은 미리 알려 주고, 저장 전에 바뀐 내용을 요약해 보여 줘요. 로어북 항목마다 Dusk 규칙을 켤 수 있어요(아래 본문). 에셋 관리자는 폴더, 여러 개 고르기, 일괄 교체, ZIP 받기, WebP 최적화, 중복 찾기, 캐릭터·의상별 목록 보기를 지원해요.
모바일에서도 그대로
탭은 아래로, 상세 정보는 아래에서 올라오는 시트로 바뀌어요. 손잡이를 잡고 끌어 순서를 바꾸거나 폴더에 넣을 수 있어요.
알아 두면 좋은 것
· 봇이 답변을 만드는 중에는 업데이트·저장을 막아요. 끝난 뒤 다시 눌러 주세요.
· 꺼 둔 모듈은 Dusk 보관함에 있어요. 플러그인을 지우기 전에 도구 → 설정 정리 → 꺼진 모듈 모두 켜기로 꺼내 주세요.
· 개발자 모드를 켜면 바뀐 부분만 담은 패치 파일을 만들어 배포할 수 있어요. 자세한 건 올인원 가이드 글에 있어요.

실험 기능
🎯 로어북이 내가 정한
조건대로 켜져요.
리스 활성화 키만으로는 안 되던 것들 — 키 하나만 맞아도 켜기, 이름 겹침 막기, A가 켜지면 B는 끄기, A가 켜지면 B도 확률로 켜기 — 를 로어북 항목마다 정할 수 있어요. 리스를 고치거나 포크하지 않고 공식 기능만으로 돌아가요.

💡 이런 분께 특히 좋아요
NPC가 수십·수백 명인 시뮬봇처럼 로어북 토큰이 감당이 안 되는 봇. 그 장면에 필요한 인물만 들어가고, 안 켜진 항목은 내용이 비어 토큰을 거의 먹지 않아요.
1어떻게 돌아가나요
플러그인이 리스의 로어북 엔진을 바꿀 방법은 없어요. 그래서 켜질지만 Dusk가 정하고, 나머지는 리스가 평소대로 하게 만들었어요.
① 규칙을 켜면 · 항목 내용이 @@activate + {{#if 변수}}로 감싸져요.
② 입력하는 순간 · 리스가 프롬프트를 만들기 전에 Dusk가 규칙을 계산해서 그 변수를 켜고 꺼요.
③ 그다음은 리스가 · CBS·변수·#if 파싱, 배치, 토큰 계산까지 평소처럼 해요. 그래서 변수와 #if를 주렁주렁 단 대형 봇에서도 내용이 깨지지 않아요.
· 규칙은 로어북 항목 안에 저장돼요. .charx·PNG·.risum으로 내보내도 따라가요. 봇에 규칙을 넣어 배포하면 Dusk를 쓰는 사람은 누구나 같은 동작을 얻어요.
· Dusk가 없는 사람에게는 규칙 항목이 꺼진 항목으로 보일 뿐, 봇이 깨지지 않아요.
· 캐릭터 로어북, 모듈 로어북 모두 돼요. 추가 권한도 필요 없어요.
2켜는 법
1
Dusk에서 봇(또는 모듈) 편집 → 로어북 탭에서 항목을 골라요.
2
맨 아래 Dusk 규칙 스위치를 켜요. 활성화 키는 원래 칸에 그대로 두면 돼요. 기본 조건이 "이 항목의 키가 최근 대화에 있음"이에요.
3
카드 네 개(언제 켜질까 · 얼마나 자주 · 같이 켜기 · 어디에 넣을까)에서 원하는 만큼 정하고 저장해요.
4
목록의 규칙 시험에 대화를 붙여 넣으면 어떤 항목이 켜지는지 바로 볼 수 있어요. 채팅 중에는 F12 콘솔에 [Dusk 규칙] 턴 N: …으로 찍혀요.
⚠ 본문을 고칠 때는 {{#if …}}와 {{/if}} 사이만 고치세요. 바깥 줄은 저장할 때 자동으로 맞춰져요.
3언제 켜질까 — 조건
조건을 여러 개 걸고 모두 만족 또는 하나라도 만족을 골라요.
키가 최근 대화에 있음
활성화 키 칸의 키 중 하나만 나와도 켜져요. 둘 다 필요하면 "보조 키 사용"에 적어요.
특정 단어가 있음
키와 따로 단어를 지정. 누구 말이든 / 사용자 말만 / 봇 말만, "모두 있어야", 정규식도 골라요.
특정 단어가 없음
그 단어가 나오면 안 켜요. 예) 마리 항목에 "마리아".
채팅 변수 비교
봇이 {{setvar}}나 트리거로 쌓은 값을 = · > · < · 있음 · 없음으로 비교. 예) 호감도 50 이상.
턴 범위
사용자 입력 횟수로 범위를 정해요. 예) 10턴 이후에만 등장.
다른 항목이 켜짐 / 안 켜짐
이번 턴에 다른 항목이 켜졌는지로 정해요. A가 켜지면 B는 금지 같은 상호 배제가 돼요.
· 찾는 범위: 최근 몇 개 메시지에서 찾을지 정해요(기본 4). 방금 말한 것만 보려면 1로 두세요.
4이름 겹침 — 김민 / 김민수
이름 경계 스위치를 켜면 이름 앞뒤에 다른 글자가 붙은 경우를 걸러요. 한국어 조사는 허용해요.
키: 김민 (이름 경계 켬)
✔ 김민이 왔다  ✔ 김민에게 말했다  ✔ 안녕 김민!
✘ 김민수가 왔다  ✘ 이김민

키: 마리 (이름 경계 켬) + 조건 "단어 없음: 마리아"
✔ 마리가 왔다  ✘ 히마리가 왔다  ✘ 마리아가 왔다
'아·야·이' 같은 한 글자도 조사로 보기 때문에 "마리아"는 "마리+아"로 읽혀요. 이럴 땐 위처럼 "단어 없음"을 같이 걸어 주세요.
5얼마나 자주 · 같이 켜기 · 어디에 넣을까
켜질 확률 · 조건이 맞아도 N% 확률로만 켜요.
반복 · 제한 없음 / 채팅에서 한 번 / 켜진 뒤 N턴 쉬기. 기록은 채팅마다 따로라서 새 채팅에선 다시 처음부터예요.
중복 금지 그룹 · 같은 그룹 이름끼리는 한 턴에 하나만 켜져요(삽입 순서가 큰 것). 예) 날씨 항목 여러 개 중 하나만.
같이 켜기 (연쇄) · 이 항목이 켜지면 다른 항목도 N% 확률로 켜요. 대상 항목도 규칙을 켜 두세요. 연쇄로만 켜질 항목은 조건을 모두 지우고 확률 0으로 두면 돼요.
어디에 넣을까 · 로어북 자리(기본) / 대화 끝에서 N개 위 / 대화 맨 끝, 역할(system·user·assistant).
6알아 둘 것
· 다시 생성(리롤): 응답이 끝나면 Dusk가 같은 턴을 미리 한 번 더 계산해 둬요. 리롤하면 확률이 새로 굴려진 결과가 쓰여요. 설정 탭에서 "이전 결과 유지"로 바꿀 수 있어요.
· 키가 없는 항목은 저장할 때 자동으로 "항상 켜짐"이 돼요(리스가 키 없는 항목을 건너뛰기 때문). 실제로 켜질지는 그대로 Dusk가 정해요.
· 로어북 방식은 일반으로 두세요. "하위" 방식 항목에는 규칙을 켜지 마세요.
· 항목을 복제할 때는 Dusk 편집기의 복제 버튼을 쓰세요. 리스에서 복제했다면 저장할 때 자동으로 고쳐져요(연쇄 대상은 다시 골라 주세요).
· 아직 실험 기능이에요. 그룹 채팅에서는 충분히 시험하지 못했어요.
7그 밖에
· 설정 탭이 생겼어요. 색 바꾸기·업데이트 설정·설정 정리·개발자 모드가 도구에서 설정으로 옮겨 갔고, 프리셋 탭은 도구 안으로 들어갔어요.
· 봇 저장이 빨라졌어요. 한 번만 읽고 바로 저장하고, "편집 전" 백업은 뒤에서 남겨요.
