FEATURE 1 · MODULE MERGE
🧩 모듈 병합 — 여러 모듈을 켜도 봇처럼
봇에 인물 추가·DLC 같은 확장 모듈을 켰는데 모듈 그림이 안 나오거나 지워진 적 있나요? 봇마다 이미지를 그리는 방식이 제각각이라, 봇이 모르는 이름은 지워지거나 그려지지 않았어요. 새 애드온 모듈 호환이 봇이 어떻게 만들어졌든 모듈 이미지를 그 봇 이미지와 같은 모양으로 나오게 맞춰요. 봇·모듈 파일은 하나도 바꾸지 않아요.
1-1🖼️ 모듈 이미지가 봇 이미지 모양 그대로NEW
봇이 자기 이미지를 그리는 방식을 읽어서 모듈 이미지에도 그대로 써요. 카드·테두리·접기 같은 봇 꾸밈이 모듈 그림에도 똑같이 입혀져요.
· 봇 그리기 정규식이 그대로 그려요 — 가장 원본과 같은 모양
· 봇이 ‘자기 에셋 목록’만 확인하는 방식이면 같은 정규식을 모듈 이미지에 대신 적용해요
· AI가 봇과 다른 태그 모양으로 써도 봇 모양으로 바꿔서 그려요
· 그리는 정규식이 아예 없는 봇은 리스 기본 방식으로 그려요
· 봇에 같은 이름이 있으면 봇 그림을 먼저 써요
1-2🛡️ 봇 정규식이 지워도 남아요NEW
정해 둔 이름 외 이미지 태그를 지우는 봇에서도 모듈 이미지 태그는 응답에 남아요. 지워질 태그만 살짝 감싸 두고, 화면·요청에서는 원래 태그로 되돌려요.
· 지울 정규식이 없는 봇에서는 아무것도 바꾸지 않아요
· 이름이 조금 틀리면 같은 인물의 가장 가까운 표정으로 고쳐요(없으면 기본 표정)
1-3💬 모델이 모듈 인물 이름을 알아요NEW
요청에 모듈 인물·표정 이름을 그 봇의 태그 예시 모양으로 짧게 알려 줘요. 글로벌 노트에 ‘이 이름만 허용’처럼 닫혀 있는 봇에서도 모듈 이름을 함께 허용해요.
· 최근 대화에 나온 인물부터 넣고, 길이는 정해 둔 만큼만
· 자기 이미지를 스스로 안내하는 모듈은 빼요 — 겹치지 않게
· 저장되는 채팅은 그대로, 요청 사본에만 들어가요
1-4👥 인물 감지 변수NEW
모듈 로어북이 {{getvar::인물}}로 인물 소개를 숨기고 보이는데, 봇 Lua가 그 인물을 몰라 늘 비어 있던 경우를 채워요. 최근 대화에 그 인물이 나왔는지로 값을 정해요.
· ‘나오면 0 / 1’ 규칙은 봇이 채운 변수에서 알아서 읽어요(못 읽으면 나오면 0)
· 봇·다른 모듈 Lua가 직접 다루는 인물과 설정 변수는 건드리지 않아요
· 화면에서 자동 / 나오면 0 / 나오면 1 / 끔을 골라요
1-5🔍 봇마다 살펴보고 끄고 켜기NEW
홈 → 애드온 → 모듈 호환 열기에서 지금 연 봇을 살펴봐요.
· 모듈마다 그리기·지키기·안내를 어떻게 하는지
· 모델에게 넣는 안내 미리보기
· 모듈끼리 겹치는 정규식·로어북·Lua 알려 주기
· 봇마다 따로 끄고 켜기, 세부 기능별 스위치
봇의 Lua가 직접 하는 일(호감도·상태창 등)은 모듈 인물에 적용되지 않을 수 있어요. 애드온을 끄기 전에는 세부 설정 → 이 채팅의 지킴 표식 풀기를 눌러 두면 좋아요.

FEATURE 2 · PERSONA
🎭 페르소나 제작 강화 — SOP 3단계
AI로 페르소나 만들기를 SOP: Sort Of Persona 기준으로 다시 짰어요. 한 번에 쓰고 끝이 아니라, 넓게 채우고 → 검토하고 → 고른 것만 다듬는 세 단계예요. 화면도 페르소나 공방처럼 한 섹션씩 채우는 모양으로 바뀌었어요.
2-1📝 초안 → 검토 보고서 → 최종 다듬기NEW
새 기본 양식 SOP 기본 규칙(원문 그대로)으로 써요.
· 1 초안 쓰기 — 칸을 줄이지 않고 넓게, 형용사 대신 ‘계기 → 해석 → 행동 → 대가’ 꼴로
· 2 검토 보고서 — 유지·삭제·합치기·명확히·작동 방식으로·반복 위험·토큰 낭비로 나눠 보여 줘요
· 3 최종 다듬기 — 체크한 항목과 메모대로만 다시 쓰고, ‘바뀐 점 보기’로 전후 비교
· 단계별 지침은 AI 프리셋 편집에서 고칠 수 있고 공유 코드에도 담겨요
2-2🧭 공방식 화면NEW
위에 기본 정보 카드, 그 아래 ‘설명으로 AI 전체 생성’, 그다음 번호 탭으로 한 섹션씩 채워요(채운 섹션은 ✓).
· 섹션 아래 요청 칸 — ‘요청대로 고치기’ / ‘이 섹션 새로 쓰기’
· SOP 규칙 버튼 — 빠짐없이 채우기·작동 방식으로·장면 재료로·자리표시 지우기
· 오른쪽 실시간 시트 미리보기(글자·대략 토큰 수), 늘 보이는 저장 막대
· NAI 캐릭터 태그 뽑기·복사, 백업과 지금 내용 줄 단위 비교
2-3🤖 봇 기본 페르소나NEW
‘현재 채팅’ 카드에서 이 봇의 기본 페르소나를 고르면, 페르소나를 연결하지 않은 그 봇의 채팅에서 요청에 그 설명을 넣어요.
· 설명은 요청마다 읽어서, 페르소나를 고치면 바로 따라가요
· 저장된 채팅·봇·페르소나와 이름표·이미지는 그대로예요
2-4💾 파일 백업·가져오기NEW
고른 페르소나(설명·이름·이미지)와 양식·AI 프리셋·덮어쓰기 전 백업·봇 기본 페르소나를 파일 하나로 받고, 다른 기기에서 되살려요.
· 같은 것은 건너뛰고, 내용이 다른 같은 페르소나는 ‘(가져옴)’ 사본으로 더해요

FEATURE 3 · ADDON WORKSHOP
🛠️ 애드온 창작마당 오픈
이제 누구나 Dusk 기능을 만들어 넣고 나눌 수 있어요. Dusk 본체를 업데이트하지 않아도 애드온 파일(.js) 하나로 기능이 늘어요. 애드온 상자도 홈으로 나와 카테고리별로 정리됐어요.
3-1✨ AI와 함께 만들기NEW
애드온 상자 오른쪽 위 만들기에서 만들고 싶은 기능을 적어요.
· 다른 AI에게 줄 요청 복사 — 클로드·GPT 등에 붙여 넣어 코드를 받아요
· 여기서 AI로 만들기 — 리스 보조 모델로 바로 만들어요
· 안내서·빈 틀을 받아 직접 만들 수도 있어요
3-2📥 불러오기·나누기NEW
불러오기로 받은 파일을 넣으면 ‘커스텀 애드온’ 묶음에 모여요. 같은 이름이면 새 버전으로 바꿔요.
· 스위치 옆 ··· — 내보내기(파일), AI로 고치기, 지우기
· 만든 애드온은 자유롭게 공유해요
· 괜찮은 기능은 Dusk 개발자가 제작자에게 공식 기능으로 넣고 싶다고 요청할 수도 있어요
3-3🗂️ 홈 애드온 상자NEW
설정에 있던 애드온 목록이 홈으로 나왔어요. 기억·만들기·관리·꾸미기·실험·커스텀으로 나눠 보여 줘요.
애드온은 Dusk와 같은 권한으로 돌아서 봇·채팅·설정을 바꿀 수 있어요. 남이 만든 파일은 믿을 수 있는 것만 넣어 주세요.

FEATURE 4 · AND MORE
✨ 그 밖에 — 더 편하고, 덜 실패하게
4-1■ AI 생성 중지 버튼NEW
Dusk와 애드온이 AI를 쓰는 동안 오른쪽 아래에 ■ 생성 중지가 떠요. 누르면 지금 도는 AI 작업을 모두 바로 멈춰요.
· 페르소나·봇 만들기, 기억 기록, 번역, 검토 등 전부
· Dusk 창을 닫아 둔 채 뒤에서 도는 작업은 리스 화면 오른쪽 아래에 떠요
4-2🔎 기능 찾기NEW
홈 위 검색창에 낱말(예: 생리, 호감, 테마, API)을 적으면 그 기능이 어디 있는지 보여 주고, 누르면 그 자리로 데려가 잠깐 강조해요.
· 고급 모드에서만 보이는 항목·꺼진 애드온의 기능도 알려 줘요
4-3🧠 장기 기억 기록이 덜 실패해요FIX
2.0.0 이후 자동 기록이 자주 실패하던 문제를 고쳤어요. 기록기에 걸린 서로 다른 형식 지시가 부딪혀, 추론 모델이 수만 토큰을 고민하다 빈 답을 내던 게 원인이었어요.
· 빈 답이면 한 번 더 묻고, 끝내 실패하면 예전 리수폿 방식으로 대신 기록
· 같은 실패가 되풀이되던 것, ‘수치 상태가 비어 있는 인물’ 알림이 매번 뜨던 것 고침
· 약한 모델은 가벼운 지침으로 자동 전환
· 채팅을 지우거나 되감은 뒤 자동 기록이 영영 멈추던 문제 고침
4-4📚 로어북에 있는 인물만 위키에NEW
봇 이름·설명이나 로어북에 이름이 나오는 인물만 새 문서를 만들어요. 지나가는 엑스트라가 위키에 쌓이지 않아요(기본 켜짐).
· 인물 위키 위쪽 ‘로어북에 없는 인물 지우기’로 이미 쌓인 인물도 골라 지워요
