# v1.7.1 검증·측정 안내

> 코드는 단위 시험(순수 로직)과 가짜 환경 브라우저 시험까지 통과했어요. 아래는 **실제 모델·실제 채팅으로 직접 확인해야 하는 것**이에요.

## 0. 준비 — 기억 JSON 뽑기
1. 리스에서 확인할 채팅을 열고, 설정 → 화면 모드를 **고급**으로 바꿔요.
2. 기억 탭 → `기억 편집기`를 열고 **JSON 복사**를 눌러요.
3. 메모장에 붙여 `memory.json`으로 저장해요(개인정보가 들어 있으니 공유할 땐 인물 이름·본문을 지워요).
4. 저장소를 받은 폴더에서 `npm install` 후 아래 명령을 써요(Node 필요).

## 1. 구버전 데이터 검증 (1.7.0에서 쌓인 기억)
1.7.0 때 쌓인 채팅의 JSON으로:
```
node tools/check-migration.mjs memory.json
```
- 모두 ✔면 통과예요. 읽기·주입·새 분석 결과 반영·기존 기록 보존을 확인해요.
- ✘가 있으면 그 줄과 JSON(민감한 부분 제외)을 알려 주세요.
- 화면으로도 확인: 새 버전을 켜고 **새 필드가 없는 옛 기록**이 인물 화면에 그대로 보이고, 편집기에서 열어 고쳐도 되는지 봐요.

## 2. 모델이 새 칸을 제대로 채우는지 (20~30턴 돌린 뒤 편집기에서 눈으로)
| 볼 것 | 좋은 상태 | 나쁜 상태(알려 주세요) |
|---|---|---|
| 사실/추론 구분 | 직접 한 말·장면은 사실, 마음 읽기는 추론 | 추측인데 `사실 · 높음` |
| 확신도 | 높음이 과반을 넘지 않음 | 거의 전부 높음 |
| 속성(`자세히`의 속성 줄) | 같은 성질은 같은 키(예: `매운 음식`) | 같은 성질인데 키가 매번 다름 → 충돌 판정을 놓쳐요 |
| 충돌 이력 | 취향·관계가 바뀌면 `이전 → 현재`가 남음 | 바뀌었는데 둘 다 살아 있음 |
| 상황 관점·기대·자기 해석 | 큰 장면에서만 가끔 | 거의 모든 응답에 붙음(토큰 낭비) |
| 자기 해석의 추정 원인 | 해석확실성이 붙고 단정하지 않음 | 단정형 |
| 감정 게이지 | 큰 사건에만 변함 | 응답마다 출렁임 |

고쳐 보기: 기록의 확신도를 바꾸면 `사용자지정` 뱃지와 🔒가 보이고, 다음 분석에서 그 칸이 안 바뀌어야 해요. `되돌리기`는 직전 1건만 돼요.

## 3. 토큰 증가량 재기
**확정된 값(코드 기준)**: 분석 호출의 시스템 프롬프트 632 → 1060 토큰(**+428/호출**).

실제 채팅 기준으로는:
```
node tools/measure-memory.mjs memory.json --recent "지금 장면 글 한두 줄"
```
- ① 분석 프롬프트 증가, ② 주입 블록의 1.7.0 기준 / 3단계 끔 / 전체 토큰을 한 번에 비교해요.
- 실제 청구량: 같은 봇으로 **1.7.0일 때 20턴, 1.7.1일 때 20턴**을 돌리고, 기억 탭 `사용량`(또는 모델 공급자 화면)의 입력 토큰 합계를 비교해요.
- 기준 제안: 주입 블록 증가 **+150토큰 이내**, 분석 호출 전체 입력 증가 **+40% 이내**. 넘으면 설정의 `인물 관점·내면·기대 불일치 넣기`를 끄고 다시 재요.

## 4. 검색 정확도·이어쓰기 점검
### 4-1. 포착률·배제율(숫자)
1. 뼈대 만들기: `node tools/measure-memory.mjs memory.json --template > cases.json`
2. `cases.json`의 각 장면마다 `need`(이 장면에서 떠올라야 할 기록 id), `avoid`(나오면 안 되는 기록 id)를 채워요. id는 JSON의 `records[].id`예요. 5~10개 장면이면 충분해요.
3. `node tools/measure-memory.mjs memory.json --cases cases.json`
- **필요한 기억 포착률**과 **불필요한 기억 배제율**이 1.7.0 → 1.7.1로 나와요. 놓친 id와 잘못 들어온 id도 줄마다 나와요.
- 기준 제안: 포착률은 1.7.0 이상, 배제율은 1.7.0보다 떨어지지 않기.

### 4-2. 이어쓰기 점검(숫자로 못 재는 부분)
토큰만 줄고 연속성이 나빠지면 실패예요.
1. 같은 채팅의 중간 지점에서, 1.7.0 상태와 1.7.1 상태로 **같은 입력 5개**를 보내요(리롤 말고 각각 새로).
2. 응답에서 **잊은 사실·뒤바뀐 관계·이미 해결된 일을 다시 꺼냄**을 세어요.
3. 1.7.1이 1.7.0보다 많으면 실패 → 편집기 `들어갈 내용 보기`로 빠진 기억이 있는지 확인해요.
