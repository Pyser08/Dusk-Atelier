문제
· 다섯 구역이 한 페이지에 위아래로 쌓여, 비어 있어도 큰 빈 상태 그림 5개가 이어져요.
· 구역 이동 칩이 두 줄로 꺾이고, 내용은 아래로 한참 스크롤해야 해요.
· 상황 카드마다 버튼 2개(새 채팅·새 봇)가 길게 붙어요.
· 위의 ‘인물 위키’ 칸이 맨 위에 빈 채로 보여요.

개편안
· 구역 이름 칩에 개수를 붙여 한 줄로(옆으로 밀어서 이동), 한 번에 한 구역만 보여 줘요.
· 빈 구역은 큰 그림 대신 한 줄 안내(+ 분석 버튼 하나).
· 상황·시간선은 세로 시간선(점) 모양, 현재 상황·‘지금’ 표시.
· 열린 항목: 종류 라벨·해결 버튼, 삭제 등은 ···, 해결된 항목은 접어서.
· 채팅 고르기는 머리의 ‘1. 교실 이야기 ▾’ 하나로.
동작이 바뀌는 점(확인 부탁): 지금은 칩을 누르면 같은 페이지 안에서 그 구역으로 스크롤돼요. 개편안은 구역을 칩으로 바꿔 한 번에 하나만 보여요. 한 번에 다 훑어보기보다 필요한 구역을 골라 보는 쪽이 더 깔끔하다고 판단했는데, 예전 방식이 더 좋으면 알려 주세요.
