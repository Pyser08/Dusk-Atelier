넓은 화면은 왼쪽에 단계 목록(끝낸 단계는 ✓, 눌러서 바로 이동), 가운데에 고를 것, 오른쪽에 미리보기가 나와요(꾸미기 단계). 장기 기억 단계처럼 미리볼 게 없으면 가운데를 넓게 써요.
누구에게 뜨나요: 새로 받은 사람이든 이미 쓰던 사람이든, 이 버전을 처음 열 때 한 번은 모두에게 떠요. 이미 쓰던 사람은 지금 설정이 미리 골라진 채로 시작하고, 바꾸지 않고 넘기면 그대로예요(아무것도 초기화하지 않아요). 한 번 끝내거나 ‘나중에 하기’를 누르면 다시 자동으로 뜨지 않고, 설정 → 도움말의 ‘시작 안내 다시 보기’로 언제든 다시 볼 수 있어요.
