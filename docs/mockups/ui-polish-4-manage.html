· 줄에는 ‘편집’과 ···만(AI로 다듬기·에셋·폴더 이동은 ···).
· ‘지금 채팅’ 라벨로 분명하게.

· 도구 한 줄: 개수·순서 요약 + ‘＋ 새 모듈’ + ···(선택·폴더·정렬).
