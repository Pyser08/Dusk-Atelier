문제
· 제목이 두 번(위 안내 + ‘코코아/코코아전트 스킬 그대로…’).
· ‘사용할 스킬’ 칩과 ‘스킬 세트’ 목록이 같은 세트를 두 번 보여 줘요.
· 세트마다 버튼 4개(열기·ZIP·JSON·삭제)가 좁은 화면에서 두 줄로 깨져요.
· 떠 있는 ‘AI로 스킬 만들기’가 아래 탭과 겹쳐요.
· 고급에선 ‘어느 호출에 붙일까요’가 세트 수×4줄로 길어져요.

개편안
· 제목 하나 + ?.
· 맨 위 카드: 켜기 + ‘3개 중 1개 사용 중’.
· 한 목록으로 합침: 간단은 줄마다 스위치(켜면 정리 노트·기록하기), 고급은 줄 아래 ‘붙는 곳’ 칩 4개.
· ZIP·JSON·삭제는 ··· 메뉴, 줄을 누르면 편집.
· ‘AI로 만들기’는 목록 머리로.
· 고급 묶음(옮겨오기·웹 도구·호출 기록)은 한 줄씩.

문제 · 봇 고르기(드롭다운)·채팅 칩·탭 칩이 세 줄로 쌓이고 가운데가 비어요. · 단계 표시가 ‘1. 1. 인물’처럼 번호가 두 번 나와요(아래 버그). · ‘다음’ 버튼이 왼쪽 아래에 작게 있어 찾기 어려워요. · ‘고급 모드에서 더 보기’가 화면 맨 아래 멀리 떨어져 있어요.
개편안 · 봇·채팅은 한 줄 카드(‘바꾸기’를 누르면 봇→채팅 순서로 고름). · ‘만든 카드 / 새로 만들기’는 둘 중 하나 고르기(segmented). · 만든 카드는 2열 그림 타일 + 마지막에 ‘＋ 새 카드’. · 단계는 동그라미 5개 진행 표시, ‘이전/다음’은 아래에 붙여서 오른쪽. · ‘빠르게 만들기’는 강조 상자로 1단계에 그대로.
함께 고칠 버그: 기억 카드 → 새로 만들기의 단계 목록이 ‘1. 1. 인물 · 2. 2. 범위·등급…’으로 번호가 두 번 보여요(목록 기본 번호 + 글자 번호). 기억 카드 탭(rb-cards2)에서는 단계 목록 CSS가 안 먹는 것으로 보여요. 구현할 때 같이 고칠게요.
