# v1.7.0 UI 리뉴얼 플랜 — "간단하게, 바로 쓰게"

브랜치 `feat/1.7.0`. 기준: 사람들은 글을 안 읽고, 복잡한 기능을 싫어한다. 일반 사용자에게 필요한 것만 첫 화면에 두고, 나머지는 각 탭의 **고급**으로 보낸다. 개발 탭·봇 편집기 내부는 고급 사용자용이라 이번 범위에서 크게 바꾸지 않는다.

## 1. 지금 문제 (코드 검토 결과)

| 화면 | 문제 | 근거 |
|---|---|---|
| 장기기억 | 한 화면에 스위치 4개(저장소 선택·리수폿 기능·장기기억 켜기·봇별 자동 기록)가 위치가 제각각. 설정이 왼쪽(좁을 때 목록 위)·오른쪽 패널·봇 화면 '설정' 폴드 세 군데 | `memory/index.js`·`modebar.js`·`home.js`·`botview.js` |

## 2. 원칙 (모든 화면에 적용)

1. **한 화면 = 스위치 1개 + 주요 동작 최대 3개.** 나머지는 화면 맨 아래 `고급` 접기로.
2. **간단 / 고급 모드.** 설정에 전역 토글 하나(기본: 간단). 간단 모드에서는 `고급` 접기 자체를 숨기고, 고급 모드에서만 보인다. 개발 탭은 지금처럼 개발 모드에서만.
3. **글은 한 줄.** 제목 아래 설명은 최대 1문장·40자. 그 이상은 `ⓘ` 말풍선(이미 있는 `tooltip.js`)으로.
4. **상태 먼저.** 화면 맨 위에는 "지금 이 채팅에서 무엇이 켜져 있고 잘 되는지"를 꺼짐 / 준비 중 / 사용 중 3가지로만.
5. **같은 모양 반복.** 모든 탭이 같은 틀: `머리(제목 + 스위치)` → `상태 카드` → `주요 동작` → `목록` → `고급`.
6. **지금 열린 채팅이 기본.** 봇 목록에서 고르게 하지 않고, 리스에서 열려 있는 채팅을 바로 보여 준다. 다른 봇은 `다른 채팅 보기`로.
7. **내부 용어 금지.** cursor·digest·Writer·Router·Director·People refresh 등은 화면에서 쓰지 않는다(용어표 §6).

## 4. 화면별 간단 / 고급

### 홈
- 간단: 지금 채팅 이름, 카드 2장 [기억: 사용 중 · 마지막 요청 19:18 반영 3건] [인물: 사용 중 · 6명], 빠른 동작 3개.
- 상태가 꺼짐이면 카드 안에 `켜기` 버튼 하나만.
- 고급 없음.

### 기억 (사건 기억)
- 머리: `이 채팅에서 기억 사용` 스위치(봇별 자동 기록 + 주입을 하나로).
- 상태 카드: 꺼짐 / 준비 중 / 사용 중 + "마지막 요청 19:18 · 3건 반영" 또는 "미반영: 이유"(v1.7.0 버그 수정에서 만든 이유 코드 사용).
- 주요 동작: `지난 대화 분석(미처리 N개)` · `카드로 만들기` · `다른 채팅 보기`.
- 목록: 최근 기록(인물·한 줄·등급).
- 고급: 저장소(자동·플러그인·BardWiki·끔) · 자동 기록 시점 · 분석 모델·제한시간 · 주입 토큰·시작 턴 · 상황·시간선·열린 항목·관계(장부) · 제외 이름 · 초기화 · 진단·복구 · 카드 목록.

### 인물 (인물 위키)
- 머리: `이 채팅에서 인물 위키 사용` 스위치(리수폿 기능 + 턴 흐름).
- 상태 카드: 인물 N명 · 마지막 자동 기록 결과(충돌이면 전용 안내).
- 주요 동작: `AI로 빈칸 채우기` · `인물 추가`.
- 목록: 인물 카드(사진·이름·호감도 게이지·한 줄 요약). 누르면 인물 페이지: 지금 상태 · 요약 · 성격 — 편집은 `✎` 하나.
- 고급: 빠르게/정확하게 모드 · AI 모델 · 폴더 · 합치기 · 항목 관리 · AI 도구(다시 정리·직접 지시·수치 제안) · 수동 기록 · 위키 기록·되돌리기 · 추적 인물 · 추적 수준 프리셋·기능 카드.

### 봇
- 줄: 사진 · 이름 · 폴더 · `편집` · `AI로 만들기`(편집기를 AI 탭으로 바로 염).
- 위: 검색 · `가져오기` · `새 봇`.
- 고급(줄 메뉴 ⋯): 에셋 · 업데이트 가져오기 · 패치 만들기/적용 · 내 수정 내보내기 · 삭제.

### 모듈
- 지금 구조 유지. 줄 버튼은 `켜기` 스위치 + `편집`만, 나머지는 ⋯ 메뉴로.

### 꾸미기
- 간단: 색 프리셋 6개 · 밝기(자동/밝게/어둡게) · 글자 크기 · `채팅 테마 만들기`(빌더 3단계).
- 고급: 메뉴 위치·밀도·고대비 · 테마 스튜디오(직접 편집·공유).

### 설정
- 간단: 간단/고급 모드 · 이야기 보조 3개(스위치만) · 백업/복원.
- 고급: 주사위 세부(재해석/존중·리롤 때 확률) · 로어북 이름 경계 · 응답 아래 로어북 버튼 · 채팅 메뉴 장기기억 버튼 · 설정 정리 · 개발 모드.

## 5. 디자인 방향

- 지금 토큰 체계(`theme.js`, 회백 + 코랄)는 유지하고 **밀도만 줄인다**: 카드 안 카드 금지, 카드 사이 여백 확대, 본문 15px·제목 20px, 버튼은 주요 1개만 색 채움.
- 공용 부품 5개를 새로 만들고 모든 탭이 이것만 쓴다(`ui/kit.js`): `pageHead(title, switch)` · `statusCard(state, line, action)` · `actionRow([...])`(최대 3개) · `advFold(tabId, ...children)`(고급 모드에서만, 열림 기억) · `emptyState(icon, text, action)`.
- 상태 색 3개만: 꺼짐(회색) · 준비 중(노랑) · 사용 중(초록). 오류는 빨강 한 줄 + 해결 버튼.
- 아이콘 + 짧은 라벨(2~4글자 우선). 설명 문장은 `ⓘ`로.
- 모바일 우선 한 칸 배치, 넓으면 오른쪽에 상세(인물 페이지·기록 상세)만 붙인다.

## 7. 데이터 쪽 변경 (화면 분리에 필요)

- 지금: `settings.potMode`(리수폿 기능) + `settings.flow.on`(장기기억 켜기)이 인물 위키를 켜고, Dusk 기억은 `backend`·`bots[id].on`·`inject.on`이 나눠 가짐.
- 바꿈: 사용자에게는 **두 스위치만** — `기억 사용`(= 봇별 `bots[id].on` + `inject.on`), `인물 사용`(= `potMode` + `flow.on`). 둘 다 "전체 기본값 + 이 봇 덮어쓰기"로.
- 기억만 켜고 인물을 끄면 Dusk 러너 단독, 인물만 켜면 지금의 `backend:"off"` 경로(위키 정리만), 둘 다 켜면 지금의 합친 흐름. 엔진은 그대로, 스위치를 이 조합으로 옮기는 마이그레이션만 추가(`memorystore` index v3 → v3.1).

## 9. 위험·주의

- e2e 시험이 버튼 문구로 요소를 찾는다 → 단계마다 같이 고친다.
- 기존 사용자 설정이 바뀌면 안 된다 → 마이그레이션은 "지금 켜진 것은 계속 켜짐"을 지킨다.
- 고급 기능을 숨기면 "기능이 사라졌다"는 반응 → 첫 실행 때 한 번 "고급 기능은 설정 → 고급 모드" 안내, 각 탭 맨 아래 작은 `고급 모드에서 더 보기` 링크.
- `pot/`(자동 생성)의 문구는 직접 못 고친다 → 화면에서 감싸 번역하거나 `tools/pot-patches.json`으로.
- 편집기(`editor.js` 2,500줄)·개발 탭은 범위 밖. 진입점만 바꾼다.

## 10. 정할 것

1. 탭 구조(§3) — 기억 카드 탭 흡수, 꾸미기 분리 괜찮은지.
2. 간단/고급 전역 모드 vs 탭마다 접기만 — 플랜은 둘 다(전역 모드가 접기를 보이고 숨김).
3. 목업을 먼저 볼지(권장), 바로 1단계부터 갈지.
