## 1. 원칙 (모든 화면)

1. **한 화면 = 스위치 1개 + 주요 동작 최대 3개.** 나머지는 고급 모드 영역 또는 ⋯ 메뉴.
2. **간단 / 고급 모드**: 설정 → 화면 모드(전역, 기본 간단). 고급 모드에서만 고급 영역이 보인다. 각 화면 맨 아래 작은 `고급 모드에서 더 보기` 링크.
3. **개발자 모드**: 설정 → 개발자(고급 모드에서만 보임). 켜면 캐릭터·모듈 화면에 기존 오른쪽 상세 패널, 행 메뉴에 개발 항목, 메뉴에 개발 탭.
4. **글은 한 줄**(설명 최대 1문장·40자). 긴 설명은 `ⓘ`(tooltip.js).
5. **상태 먼저**: 꺼짐(회색) / 준비 중(노랑) / 사용 중(초록) 3가지. 오류는 빨강 한 줄 + 해결 버튼.
6. **같은 틀**: 머리(제목 + 스위치) → 상태 카드 → 주요 동작 → 목록 → 고급.
7. **지금 열린 채팅이 기본.** 다른 봇은 `다른 채팅 보기`.
8. **내부 용어 금지**(§9 용어표).

## 2. 메뉴 구조

### 2.1 목록
| 묶음 | 항목 | 모바일 | PC |
|---|---|---|---|
| 기본 | 홈 · 기억 · 리수폿 · 인물 | 아래 탭바 4칸 | 사이드바/위쪽 바 위 묶음 |

- **모바일 탭바: 홈 / 기억 / 리수폿 / 인물 / 더보기** (봇 자리를 리수폿으로). 캐릭터·모듈 등은 홈 `바로 하기`와 더보기 칩 줄로 간다.

- 개발 탭: 개발자 모드일 때만 더보기 끝에.
- 기억 카드: 독립 탭 유지(더보기) + 기억 화면 `카드로 만들기`로도 진입.

- 기존 `theme.layout`(home/left/top, `rb-lay-*` 클래스, `app.js` nav/topnav)을 그대로 쓴다.

### 2.3 홈 `바로 하기` (9칸)

### 3.2 기억 = Dusk 장기 기억 (Memory / MemoryAdv / PcMemory)

### 3.7 모듈 연결 (일반 모드)
- 개발자 모드가 아니어도 모듈을 전역·페르소나·캐릭터·지금 채팅에 연결할 수 있어야 한다.
- 진입: 줄의 `🔗 연결 · N` 버튼, ⋯ `연결 설정…`.
- PC: 줄 옆 팝오버(380px). 모바일: 아래에서 올라오는 시트(배경 어둡게, 손잡이, ✕).
- 내용(기존 상세 패널 연결 영역 그대로): 전역(글로벌 활성화) · 페르소나(검색 "페르소나 N개에서 찾기" + 목록 스위치) · 캐릭터(불러오기 → 목록 스위치) · 지금 채팅. 스위치는 기존 "켜짐/꺼짐" 알약 모양.
- 구현: `modules.js` `showDetail`의 `links`·`personaBox`·`charBox`·`chatBox` 생성부를 함수로 떼어 패널·팝오버·시트가 같이 쓴다.

### 3.8 개발자 모드 오른쪽 패널
- **새로 만들지 않는다.** 기존 `rb-detail`(380px, `styles.js`)과 `characters.js detail2` · `modules.js showDetail`을 그대로 쓰고, **개발자 모드일 때만** 캐릭터·모듈 화면에서 보인다. 개발자 모드가 꺼지면 패널 숨김(`rb-has-dev` 클래스 활용).
- 모듈 패널: 이름(이름 색)·namespace·설명 → 2×2 통계(로어북·정규식·트리거·에셋) → 연결(글로벌 활성화, 페르소나, 캐릭터, 지금 채팅) → 버전 타임라인(전체 보기) → 편집·에셋·내보내기 / 삭제.
- 캐릭터 패널: 제작자·버전·이름·설명 → 2×2 통계(로어북·에셋·채팅·연결 모듈) → 연결된 모듈(열기) → 버전 타임라인 → 편집·에셋·삭제 → 업데이트 가져오기 · 개발 목록에 넣기 · 패치 만들기 · 패치 적용.
- 개발자 모드가 꺼져 있을 때 패널에만 있던 동작(내 수정 내보내기·업데이트 가져오기·버전 타임라인)은 ⋯ 메뉴와 기록·되돌리기로 접근.
- 모바일은 지금처럼 아래 시트(`.rb-detail.open`) 유지(개발자 모드일 때만).

### 3.9 기억 카드 (Cards / CardsCompose / PcCards)
- 위: 카드를 만들 봇 선택(드롭다운).
- 분할 버튼: `만든 카드 N` | `새 카드·새 봇 만들기`.
- 카드 줄: 썸네일(52×72) · 이름 · "인물 N · 응답 범위 · 날짜" · `새 봇으로 이어가기`(주요) · `PNG 받기` · ⋯(고치기·이름 바꾸기·지우기).
- 만들기: 1. 인물 고르기(칩) · 2. 범위(전체 | 최근 20응답 | 직접 고르기) · 3. 카드 이름 → `카드만 저장` / `카드 만들기`(→ 새 봇 이어가기). 카드 설정 접기는 고급.
- PC: 왼쪽 목록 + 오른쪽 만들기를 한 화면에.

### 3.10 도구 (Tools / PcTools)
- 타일(모바일 2열, PC 3열): 프리셋(공유 코드) · 페르소나 빌더 · 로어북 로그 · .risum 인스펙터 · 전체 백업·복원 · 기록·되돌리기.
- 아래 **도움 주신 분들** 카드: 봇빌더("AI로 제작 기능을 허락받고 옮겨 왔어요 · 원문 글 보기 ↗") · 리수폿("위키 기억 기능의 바탕 · 원문 글 보기 ↗"). 기존 `thanksCard`·`creditCards` 내용 유지.
- "어떤 도구가 맞을까요?" 안내는 고급 모드에서만.

### 3.11 플러그인 (Plugins / PcPlugins)
- 보기 분할: 목록 | 연동 설정 | 만들기 | 저장소 (기존 `VIEWS`).
- 동작: `업데이트 N개`/`업데이트 확인` · `새로고침` · `내보내기`.
- 카테고리별 묶음(미분류는 마지막): 줄 = 사진 · 이름 + 배지(이 플러그인 / 연동 / 꺼짐 / 중복) · "이름 · 버전 · 크기" · 켜기 스위치 · ⋯(연동 설정 열기 · 카테고리 지정 · …).
- PC는 카테고리 카드 2열.

### 3.12 꾸미기 (Look)
- 미리보기(말풍선 2개) · 강조 색 6개(코랄 #cc4b2e, 청록 #0f766e, 세이지 #4d7a4f, 라일락 #7c4fc2, 모노 #3f4650, 황혼 #4f63e0) · 밝기(자동 | 밝게 | 어둡게) · 글자 크기(작게 | 보통 | 크게) · `내 채팅 테마 만들기`(테마 빌더).
- 고급: 메뉴 위치 · 밀도 · 고대비 · 확대율 · 테마 스튜디오(직접 편집·공유 코드).
- PC는 설정 화면의 "화면" 묶음에서 진입.

### 3.13 설정 (Settings / PcSettings)
- 화면: 화면 모드(간단 | 고급) · 메뉴 위치(PC) · 꾸미기 ›.
- 이야기 도우미: 공정한 전개 · 유저 편향 없애기 · 이야기 시간 자동 삽입 (스위치만, 세부는 고급).
- 개발자(고급 모드에서만): 개발자 모드 스위치 + 설명 "켜면 캐릭터·모듈 화면에 오른쪽 상세 패널과 패치·개발 목록 기능, 메뉴에 개발 탭이 생겨요".
- 백업 만들기·복원 · 처음 둘러보기 · 새로 바뀐 점.
- 고급: 주사위 세부 · 로어북 이름 경계 · 응답 아래 로어북 버튼 · 채팅 메뉴 버튼 · 설정 정리(정렬 순서 초기화·꺼진 모듈 모두 켜기 등) · 업데이트 설정.

## 5. 데이터 변경

- 기억 스위치 = 봇별 `bots[id].on` + `inject.on` (전체 기본 + 이 봇 덮어쓰기).

## 10. 위험·주의

- e2e가 버튼 문구로 요소를 찾는다 → 단계마다 같이 고친다.
- 마이그레이션은 "지금 켜진 것은 계속 켜짐".
- 고급 기능을 숨기면 "기능이 사라졌다"는 반응 → 첫 실행 한 번 안내 + 각 화면 `고급 모드에서 더 보기` 링크.
- `pot/`(자동 생성) 문구는 직접 못 고친다 → 화면에서 감싸거나 `tools/pot-patches.json`.
- 공유 코드 DTB2는 목록 번호 기반 → STYLES·AVATARS·FONTS·WIDTHS 순서 변경 금지(끝에만 추가).
- 편집기(`editor.js`)·개발 탭은 범위 밖.
- 인물 탭 스위치가 가리키는 실제 플래그는 4단계 시작 때 코드로 확인.
