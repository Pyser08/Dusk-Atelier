기능 가이드

모듈 · 봇 관리

모듈과 봇을 정리하고, 고치고, 되돌리는 관리 기능이에요.

탭별로 보기

  • 검색·필터: 이름, 로어북 키, 정규식·트리거 이름으로 찾고 전체·켜짐·꺼짐·전역·LLA·MCP로 걸러요.
  • 켜기/끄기: 끈 모듈은 RisuAI 목록에서 빠져 보관함에 들어가고, 8초 동안 되돌릴 수 있어요. 에셋이 있는 모듈은 끌 수 없어요(끄면 RisuAI의 에셋 정리로 파일이 지워질 수 있어서예요).
  • 폴더: 접기·펴기, 폴더 색, 이름 바꾸기, 순서 바꾸기, 끌어서 넣기. 만들 때 넣을 모듈을 바로 골라요.
  • 이름 색: 어느 밝기에서도 읽히게 진하기를 자동으로 맞춰요.
  • 순서: 줄 왼쪽 손잡이(점 여섯 개)를 잡고 끌어요. 모바일도 돼요. PC는 줄 전체를 끌거나 Alt+↑/↓를 눌러요.
  • 메뉴: 편집, 에셋 관리, .risum 내보내기, JSON 복사, 내 수정만 내보내기, 패치 적용, 이름 바꾸기, 삭제(지우기 전 상태를 백업해서 되살릴 수 있어요).
  • 폴더·순서: RisuAI 사이드바의 캐릭터 폴더·순서를 그대로 써요. 여기서 바꾸면 사이드바에도 바로 반영돼요.
  • 봇 편집: 모듈 에디터와 같은 화면에서 정보(이름·설명·첫 메시지·추가 인사말·성격·시나리오·시스템 프롬프트·제작자 노트·기본 변수·배경 HTML 등), 로어북, 정규식, 트리거, JSON을 고쳐요.
  • 첫 메시지·추가 인사말은 일반 / 코드 입력 모드가 있고, <img=…>, {{CBS}}, HTML 태그에 색을 입혀요.
  • 저장 전에 변경 요약을 보여 주고 백업해요. 채팅과 메모는 건드리지 않아요.
  • 에셋: 에셋 관리자로 봇의 추가 에셋을 관리해요.

모듈 켜짐·순서·글로벌 상태를 묶어 저장하고 전환해요.

  • 만들기, 이름 바꾸기, 덮어쓰기, 삭제, 내보내기, 가져오기
  • 디바이스 페어: 기기가 바뀌면 모바일용·데스크탑용 프리셋으로 자동 전환해요.
  • 목록: 설치한 플러그인을 카테고리로 묶어 보고, 업데이트 주소가 있는 플러그인의 새 버전을 확인해요. 목록은 JSON으로 내보내요.
  • 저장소: 모든 플러그인이 함께 쓰는 pluginStorage의 키를 플러그인별로 묶어 보고, 값을 보거나 내려받거나 지워요.
  • 연동 설정: DA Interop 코드를 넣은 플러그인은 설정 화면이 자동으로 생겨요.
  • 코드 수정: RisuBard에 Dusk Cellar가 설치돼 있으면 플러그인 ··· 메뉴에서 코드를 고쳐요(아래 '플러그인 코드 수정').

연결

글로벌 활성화, 페르소나별 자동 활성화(그 페르소나를 쓰는 동안 지금 캐릭터에 자동으로 넣어요), 캐릭터별 연결, 지금 채팅에서 해제를 할 수 있어요. 줄의 '🔗 연결'에서 바로 고쳐요.

에디터

정보·로어북·정규식·트리거·JSON 탭이 있어요. 로어북 폴더는 RisuAI 로어북 창과 같은 저장 형식이라 양쪽에서 그대로 보여요. 넓은 화면에서는 창이 커지고 로어북 내용 칸이 크게 나와요. 항목은 추가·복제·삭제·순서 바꾸기를 해요.

단축키동작
Ctrl+F찾기
Ctrl+S저장

위쪽 '경고 N'을 누르면 경고마다 왜 뜨는지, 어떻게 고치는지 볼 수 있어요. 정규식 문법 오류, 키가 없는 로어북, 없는 폴더를 가리키는 항목을 검사해요. 적용하기 전에 바뀐 내용을 요약해서 보여 주고 저장 전 상태를 백업해요.

로어북 더스크화

AI가 로어북을 Dusk 규칙에 맞게 정리해요. 정규식으로 길게 쓴 키를 이름 키로 바꾸고, 다음 단계에서 항목마다 조건·확률·유지·그룹·연쇄 같은 규칙을 설계해요. 내용·키·폴더는 바꾸지 않고, 미리보기에서 이유와 함께 항목별로 골라 적용해요. '키만 정리' 버튼으로 AI 없이도 할 수 있어요.

에셋 관리자

  • 빠른 불러오기: 화면에 보이는 것만, 동시에 8장씩, 화면에 가까운 것부터 읽고 썸네일로 줄여 그려요. 한 번 읽은 것은 기억해요.
  • 폴더·선택: 하위 폴더를 만들고, Ctrl·Shift로 여러 개를 골라요. Ctrl+A로 모두 고르고 Delete로 지워요. 고른 것을 폴더 칩으로 끌어 옮겨요.
  • 편집: 추가(끌어 놓기도 돼요), 교체, 일괄 교체(이름 또는 순서로 맞춰요), 이름 바꾸기, 삭제(되돌릴 수 있어요).
  • 보기·내려받기: 크게 보기(←/→로 넘겨요), ZIP 내려받기(폴더 구조 그대로).
  • 최적화: WebP로 바꾸고(브라우저가 지원하면 AVIF도), 미리 계산해 본 뒤 더 작아지는 것만 바꿔요.
  • 메타데이터: PNG 텍스트·EXIF·XMP·WebP를 보고, 그림은 그대로 둔 채 지울 수 있어요.

가져오기와 업데이트

  • 형식: .risum, .charx, .module.charx, PNG·JPEG 카드, 비밀번호가 걸린 카드, .json. 여러 파일을 한 번에 넣으면 차례로 처리해요.
  • 기존 항목 찾기: 버전 표기가 달라도 같은 모듈·캐릭터로 찾아요. 꺼 둔 모듈도 찾고, 업데이트한 뒤에도 꺼진 상태를 유지해요.
  • 연결 기억: 한 번 고른 파일과 대상의 짝을 기억해서 다음 버전부터 바로 그 대상을 골라요.
  • 에셋: 바뀐 에셋만 올려요.
  • 3방향 병합: 내가 고친 내용은 지키고, 제작자와 내가 둘 다 고친 곳(충돌)은 고르게 해요.
  • 되돌리기: 업데이트 직후 "바로 되돌리기"를 누를 수 있어요. 응답을 생성하는 중에는 적용을 막아요.

기록과 되돌리기

업데이트·편집·삭제 전 상태를 대상별로 시간순으로 보여 줘요. 지금과 비교하거나 그 시점으로 되돌려도 채팅은 그대로예요. 보관 개수는 항목마다 3/5/10/20개 중에서 골라요. 보관 개수를 넘은 백업은 요약만 남아요.

백업

도구 탭에서 전체 백업/복원(zip)을 해요. 빠른 백업은 모듈과 설정만 담아 몇 초면 끝나고, 에셋까지는 에셋 파일도 모두 담아서 다른 서버로 옮길 때 써요. 백업 내용과 원본 기록은 서버에 파일(에셋)로 저장돼서, RisuAI의 '사용하지 않는 에셋 정리'를 하면 지워질 수 있어요.

패치 받기

제작자가 보낸 .rbupatch 파일은 창 어디에나 끌어다 놓으면 대상을 찾아 미리 보기 → 백업 → 적용 순서로 적용돼요. 내가 직접 고친 부분은 지켜져요. 패치를 만드는 쪽은 개발자 가이드를 보세요.

도구 탭

  • .risum 인스펙터: 필드별 크기, 에셋 목록, ZIP으로 풀기
  • 설정 정리: 이 플러그인이 저장한 순서·꺼진 모듈·에셋 폴더·프리셋·페르소나·캐릭터 연결·폴더·이름 색 중에서 골라서 지워요.

Dusk Cellar (선택 서버)

리스를 직접 돌리는 서버(RisuBard 등)에 함께 설치하는 선택 서버예요. 없어도 모든 기능이 그대로 돼요. 리스 폴더에서 git clone https://github.com/Pyser08/Dusk-Cellar 후 cd Dusk-Cellar, node setup.cjs를 실행하면 리스 찾기 → 빌드 → pm2 정리 → 함께 실행 → 부팅 시 자동 실행까지 해 줘요.

설치하면 플러그인이 알아서 찾아요. 리스 서버를 거쳐 연결하므로 주소·토큰을 넣을 필요가 없고, 리스 암호로 보호돼요. 설정 → 서버 → Dusk Cellar에서 '연결됨'인지 확인하고 다시 확인할 수 있어요(고급 모드에서는 주소도 바꿀 수 있어요).

장기기억 서버 저장

Cellar가 연결되면 채팅별 장기기억을 처음 한 번 서버로 옮기고, 그다음부터는 서버에만 저장해요. 기억 설정·목록은 지금처럼 플러그인에 남아요.

  • 연결이 잠깐 끊기면 바뀐 기억만 이 기기에 모아 두었다가, 다시 연결되면 알아서 올리고 지워요.
  • 다른 기기에서 같은 채팅 기억을 동시에 바꿨으면 기록을 합쳐서 잃지 않아요.
  • 서버로 옮기기 전 기억은 플러그인에 그대로 남아 있어요(끊겼을 때 읽기용).
  • 기억을 이 기기로 되돌리기를 누르면 서버의 기억을 모두 받아 오고 예전 방식으로 돌아가요. 서버 기억은 지우지 않아요.

Cellar 업데이트

설정 → 서버 → Dusk Cellar → 업데이트 확인에서 새 버전이 있는지 보고 바로 업데이트해요. Cellar만 잠깐 다시 켜지고 리스는 그대로 돌아요. 새 버전이 안 불러지면 자동으로 이전 버전으로 돌아가요. Cellar를 git clone으로 설치한 서버에서만 쓸 수 있어요. 실행기가 바뀐 업데이트는 서버에서 한 번 더 재시작(pm2 restart)하라고 알려 줘요.

세이브 백업

설정 → 서버 → Dusk Cellar → 세이브 백업에서 리스 세이브 폴더 전체(캐릭터·채팅·에셋·설정)와 서버 기억을 서버에 백업해요. 최근 5개를 보관해요.

  • 압축하지 않고 바뀐 파일만 복사해요. 바뀌지 않은 파일은 이전 백업과 공유해서 두 번째부터는 몇 초면 끝나고 디스크도 거의 안 늘어요.
  • 리스를 쓰는 중에도 백업할 수 있어요.
  • 복원하면 리스가 잠깐 꺼졌다 켜지고, 직전 상태는 '복원 전 자동' 백업으로 남아요.
⚠️
복원한 뒤에는 리스를 열어 둔 화면(다른 기기 포함)을 모두 새로고침하세요. 새로고침 전 화면이 옛 데이터를 다시 저장할 수 있어요.

플러그인 관리 (서버 연결 시)

Dusk Cellar가 연결돼 있고 RisuBard 서버일 때, 플러그인 탭에서 플러그인 매니저처럼 목록을 직접 관리할 수 있어요. 리스가 플러그인의 목록 수정을 막아서, 실제 수정은 서버(Cellar)가 대신 하고 리스를 새로고침해야 적용돼요.

  • 줄: 스위치로 켜기/끄기, ··· 메뉴에서 별칭·위로·아래로·삭제.
  • 파일에서 등록: JS 코드를 붙여넣거나 파일로 가져오면 머리말(//@name, //@arg 등)을 읽어 등록해요. 같은 이름이면 덮어쓰기(기존 인자값·켜짐·별칭 유지 선택). API 2.0은 2.1로 바꾸는 버튼이 있어요. TypeScript 변환은 아직 없어요.
  • 중복 정리: 같은 이름 사본 중 켜진 첫 번째만 남겨요.
  • 전체 백업 / 백업 복원: 코드·인자값·카테고리·프리셋을 JSON으로 받고, 범위(전체/플러그인만/카테고리·프리셋만)와 방식(전체 교체/병합)을 골라 복원해요. 플러그인 스토리지는 들어가지 않아요.
  • 글로벌 프리셋: 켜짐/꺼짐·순서·카테고리를 저장해 한 번에 바꿔요. 내보내기·가져오기, 카테고리 JSON, 디바이스 페어 이름 저장이 있어요(화면 너비에 따른 자동 전환은 아직 없어요).
  • 메타데이터 정리: 설치되지 않은 플러그인에 남은 카테고리·프리셋 항목을 지워요.
  • 저장소 탭: 값 수정(문자열/JSON 형식, 저장 직전에 바뀜 확인), 새 키, 내보내기·가져오기(이미 있는 키는 덮어쓰기 표시).

플러그인 코드 수정 (RisuBard)

리스는 플러그인이 다른 플러그인을 고치지 못하게 막아서, Cellar가 대신 고쳐요. Cellar가 RisuBard에 설치돼 있으면 관리 → 플러그인 → 목록에서 플러그인의 ··· 메뉴에 코드 수정이 생겨요. PocketRisu와 원본 RisuAI는 아직 지원하지 않아요.

  • 코드를 고치고 변경 확인을 누르면 바뀐 줄을 미리 보여 줘요. 맨 위 머리말의 //@name은 바꿀 수 없어요(바꾸면 플러그인 저장소·업데이트가 끊겨요).
  • 고치기 전에 세이브 전체 백업(선택, 기본 꺼짐 — 파일이 많으면 오래 걸려요)과 설정 파일 복사본(항상, 최근 20개)을 만들어 둬요. 세이브 백업은 최근 5개만 보관하니 오래된 백업이 밀려날 수 있어요.
  • 리스 설정 파일에서 그 플러그인의 코드만 바뀌고, 리스가 바뀐 파일을 받아들여요. 다른 플러그인과 설정은 그대로예요. 리스 암호는 다시 묻지 않고, 이 창의 확인이 대신해요.
  • 고친 뒤 리스를 새로고침해야 새 코드로 돌아요(다른 기기의 화면도 모두). 결과 화면의 되돌리기로 방금 고친 코드를 처음 코드로 돌릴 수 있어요.
  • 리스에 검토 대기 중인 외부 변경이 있거나 그새 코드가 바뀌었으면 고치지 않고 알려 줘요.
⚠️
