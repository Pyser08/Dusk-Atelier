기능 가이드

프로바이더

리스의 모델 목록에 Dusk 자동과 Dusk · 프로필이름을 더해요. 키·모델·생각·캐시·번역·도구를 한곳에서 정하고, 리스에서는 모델만 고르면 돼요.

⚠️
모델 목록에 직접 더하는 기능(addProvider)이 RisuAI·RisuBard·PocketRisu에서 모두 되는지는 아직 기기에서 확인하지 못했어요. 목록에 안 보이면 이 화면 위쪽 상태 카드에 안내가 떠요.

처음 쓰기

  1. 작업실 → 프로바이더를 열고 연결 추가에서 공급자(OpenAI·Anthropic·Gemini·OpenRouter·DeepSeek·Vertex·Copilot·직접 입력 등)를 골라요.
  2. API 키를 붙여 넣고 키 추가. 키는 이 기기의 로컬 저장소에만 저장돼요(동기화·내보내기 없음, 목록엔 끝 4자리만 보여요).
  3. 모델 불러오기를 누르고 모델을 누르면 프로필이 만들어져요.
  4. 위쪽 사용 스위치를 켜면 리스 모델 목록에 나타나요. 연결 시험으로 먼저 확인해 보세요.

프로필

프로필은 모델 하나에 대한 설정 묶음이에요. 온도·최대 토큰·Top P/K, 생각(추론) 강도(기본·끔·약하게·중간·강하게·최고 = none·low·medium·high·xhigh, 모델에 맞게 바꿔 보내요), 답 속 생각 보이기(<Thoughts>), 받는 방식(스트림/한번에), 모델 내장 웹 검색, 캐시(Claude 5분·1시간 / OpenAI / Gemini 관찰·자동·수동), 반복 감지, 프리필을 정해요. 고급 모드에서는 단가·재시도·서비스 등급·안전 필터·추가 요청 값(JSON)도 보여요.

빠른 설정: 프로필 안의 칩을 눌러 켜고 꺼요. 플렉스·우선 처리, OpenRouter 공급자 폴백·싼/빠른 공급자 우선, Claude 100만 문맥·인터리브드 생각 베타, Vertex 플렉스·우선, DeepSeek 생각 끄기가 있어요(연결 종류에 맞는 것만 보여요). OpenRouter 프로필에는 공급자 순서(한 줄에 하나)와 폴백 켬/끔이 따로 있어요. 모델 목록은 검색칸에 단어를 적어 걸러요.

용도별 지정

메인 대화·번역·감정·메모리(요약)·보조·Dusk 자체 AI마다 다른 프로필을 쓸 수 있어요. 비워 두면 메인을 따라요. 용도마다 온도·최대 토큰·생각을 덮어쓸 수 있어요.

  • Dusk 자체 AI: 지난 대화 분석처럼 Dusk가 직접 AI를 부르는 일이 이 프로필로 돌아요. Cellar 서버 분석에도 그대로 쓰여요(Vertex·Responses 연결은 서버가 직접 못 불러서 플러그인이 중계해요). 내 API 모델을 따로 고른 작업은 그대로예요.
  • 실패하면 다음 프로필로: 차단·한도·서버 오류일 때 정한 순서대로 시도해요. 글이 나오기 시작한 뒤에는 넘기지 않아요.
  • 봇마다 다른 프로필: 지금 연 봇에 프로필을 지정해요.
  • 예산: 하루·한 달 한도를 넘으면 알려 주기 / 싼 프로필로 바꾸기 / 막기 중에서 골라요.

규칙·사용량·비교

  • 규칙: 모든 요청(또는 고른 용도·모델·봇)에 글을 앞/뒤/마지막 앞에 끼워 넣어요.
  • 사용량: 오늘·이번 달 비용, 용도·프로필·모델별 토큰, 캐시로 아낀 돈. 비용은 프로필에 단가를 적었을 때만 계산돼요.
  • 비교: 같은 말을 두 프로필에 보내 나란히 봐요.
💡
키가 여러 개면 무작위·돌아가며·봇마다 고정 중에서 고르고, 한 키가 막히면 잠시 쉬고 다른 키로 넘어가요. 오류 글에는 키 값이 ***로 가려져요.

아직 안 되는 것

도구(웹 검색·리스 정보 읽기/고치기)와 번역 다듬기 화면, Bedrock·NovelAI 연결, 배치(Anthropic·OpenRouter), 참고자료 PDF 변환, Cellar를 거쳐 대화를 보내는 방식은 이번 버전에 없어요. 웹 검색 키는 설정에 저장돼서 기기 간 동기화될 수 있어요.
