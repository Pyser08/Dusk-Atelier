기능 가이드

위젯 홈

음악·사진·시계·최근 대화·최근 추가한 봇·메모를 한 화면에 모은 홈이에요. 리스 메뉴의 ‘위젯 홈’ 버튼이나 작업실 → 도구에서 열어요. 2.0.0부터 위젯 애드온을 받아야 써요(설정 → 애드온).

켜기

  1. 설정 맨 위쪽의 위젯 홈 카드에서 스위치를 켜요(처음엔 꺼져 있어요).
  2. 리스 메뉴(햄버거)에 위젯 홈 버튼이 생겨요. 작업실 → 도구에도 같은 행이 생겨요.
  3. 끄면 화면과 메뉴 버튼이 정리돼요. 메뉴 버튼은 리스를 다시 열어야 사라질 수도 있어요.

자동으로 열기

리스를 켜거나 홈으로 돌아오면 사이드바 옆 홈 자리에 자동으로 떠요. 사이드바 폭이 바뀌면 위젯 홈 크기도 따라가요. 캐릭터를 고르거나 설정 화면을 열면 닫히고, 홈으로 돌아오면 다시 떠요. 위젯 홈 안 ‘설정’에서 자동 열기를 끌 수 있어요.

💡
설정 카드에 ‘홈 자리를 찾는 중이에요’가 계속 보이면 위젯 애드온을 최신으로 업데이트하고 리스를 새로고침해 주세요. 더스크 스텔스를 함께 쓸 때는 ‘홈 화면도 바꾸기’를 꺼 두세요.

ProtLink+ 위젯

위젯 배치 편집에서 ProtLink+ 위젯을 켜면 연결해 둔 링크를 최대 5개 보여 줘요. 새 파일이 올라온 링크는 먼저 나오고 새 파일 배지가 붙어요. 누르면 관리 → ProtLink+ 화면이 열려요. 자세한 사용법은 관리 안내를 보세요.

원래 ‘위젯 홈’ 플러그인이 있다면

저장 위치가 같아서 쓰던 배치·색·메모·사진이 그대로 이어져요. 둘이 같이 켜져 있으면 Dusk 쪽이 우선이에요. 메뉴에 버튼이 두 개 보일 수 있으니 원래 플러그인은 끄는 걸 권해요(카드에 안내가 떠요).

알아둘 점

  • 위젯 홈은 Dusk 화면과 따로 그려서 색·글꼴이 섞이지 않아요.
  • Dusk 창을 열면 위젯 홈은 먼저 닫혀요. 같은 플러그인 화면을 번갈아 쓰기 때문이에요.
  • 음악 파일을 저장하는 기능은 호스트가 지원해야 해요. 지원하지 않으면 위젯 홈이 안내를 보여 줘요.
