기능 가이드

화면 · 꾸미기

테마, 강조 색, 글꼴까지 플러그인 화면을 내 취향으로 꾸며요.

시작 안내

처음 열면 화면 모드·글자 크기 → 꾸미기 → 장기 기억 → 이야기 도우미 → 이미 쓰던 것(HypaPlus·코코아전트·RisuPot) → 요약 순서로 안내해요. 고르는 즉시 적용되고 아무것도 초기화하지 않아요. 설정 → 도움말 → '시작 안내 다시 보기'로 다시 볼 수 있어요.

꾸미기

작업실 → 도구 → 플러그인 꾸미기에서 열어요(위쪽 팔레트 버튼과 설정의 링크로도 열려요).

  • 테마 묶음 12개(+🎲 아무거나), 강조 색 18개, 그라데이션 8개(가로·대각선·세로)
  • 밝기: RisuAI 따라가기 / 다크 / 라이트 / 시간 따라, 글자 크기 '아주 크게'까지

모양·글꼴 더 고르기에서 모서리·그림자·테두리·글꼴(기기에 있는 글꼴)·글자 굵기·줄 높이·아이콘 굵기·바탕 무늬·카드 유리 효과·움직임 줄이기를 골라요.

체험 · 이 사이트에 먼저 입혀 보기

강조 색과 모서리 둥글기를 이 안내서 화면에 미리 입혀 볼 수 있어요. 앱의 꾸미기도 비슷하게 골라요(앱의 실제 색 이름과는 달라요).

미리보기 카드
버튼과 제목, 위쪽 막대에 고른 색이 반영돼요.

내 테마

지금 모양을 내 테마로 여러 개 저장하고, 밝을 때/어두울 때 따로 쓸 수 있어요. 테마 코드(DA1:…)로 주고받아요. PC에서는 오른쪽에 미리보기(밝게/어둡게)가 고정돼요.

💡
고급 모드에서는 바탕·카드·글자·사이드바 색을 직접 골라요. 읽기 어려운 조합은 대비를 자동으로 맞춰요.

간단 모드와 고급 모드

설정 → 화면 모드에서 바꿔요. 간단 모드는 꼭 필요한 것만, 고급 모드는 세부 설정까지 보여요. 두 모드는 같은 데이터를 써요.
