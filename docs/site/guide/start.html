처음 사용자 가이드

설치하고, 열고, 처음 안내를 따라가는 데까지 걸리는 길이에요.

Dusk Atelier는

RisuAI 용 모듈·캐릭터 관리·업데이트 플러그인이에요. 모듈 켜기·끄기, 폴더, 순서, 연결, 프리셋, 편집, 에셋 관리와 봇·모듈의 빠른 업데이트를 해요. 장기 기억, 이야기 도우미 같은 기능도 함께 있어요.

🛡️
다른 관리 플러그인과 저장 칸을 나눠 쓰지 않아요. 함께 설치해도 서로의 설정·꺼진 모듈·순서를 건드리지 않아요.

설치

체크리스트 · 설치하고 열기

누르면 체크돼요. 이 기기의 브라우저에 진행이 저장돼요.

  • dusk_atelier.js 내려받기 (최신 릴리스)
  • RisuAI 설정 → 플러그인에서 dusk_atelier.js를 추가해요. API 3.0을 써요.
  • 예전 이름(Dusk Manager)으로 설치했다면 그 플러그인은 지워요. 설정·폴더·백업 기록은 같은 저장소를 쓰므로 그대로 이어져요.
  • 왼쪽 사이드바(햄버거 메뉴)의 Dusk Atelier를 눌러 열어요.

여는 방법

  • 왼쪽 사이드바(햄버거 메뉴)의 Dusk Atelier를 눌러요.
  • 또는 설정 메뉴에서 열어요.
  • 창 안 어디에 파일을 끌어다 놓아도 바로 가져와요.

애드온

2.0.0부터 기능은 애드온으로 받아 써요(홈 → 애드온, 또는 시작 안내 첫 단계). 장기기억·관계도, 기억카드, Erosync, 더스크 스텔스, 위젯, 프로바이더(실험), 캐릭터·모듈·플러그인 관리, ProtLink+, AI로 봇·페르소나 만들기, 채팅 테마 만들기가 있어요. 애드온은 새로고침 없이 따로 업데이트되고, 꺼도 데이터는 남아요. 새 애드온이 나오면 리스 화면 오른쪽 위에 알려 줘요. 자세한 건 애드온 안내를 보세요. 애드온이 하나도 없어도 홈·가져오기·코코아·꾸미기·도구·설정은 돼요.

기능 맛보기

처음엔 장기 기억만 켜 두고 쓰면 돼요. 기록이 쌓이고 자주 열수록 홈에 다음에 맛볼 기능 카드가 하나씩 떠요. ‘해 보기’를 누르면 그 화면으로 가서 하나씩 짚어 드리고, 필요한 애드온은 받아서 열어요. ‘나중에’는 하루 쉬고, ‘그만 보기’를 눌렀다면 설정 → ‘기능 맛보기 다시 켜기’로 되돌려요.

시작 안내 따라가기

처음 열면 플러그인 창을 꽉 채운 시작 안내가 떠요. 루네가 손을 흔들며 인사해요. 고르는 즉시 적용되고, 이미 쓰던 분은 지금 설정이 골라진 채로 시작해요(아무것도 초기화하지 않아요). 단계를 눌러 보세요.

기능 (애드온)
장기기억·관계도, 기억카드, Erosync, 위젯 같은 기능을 골라요. 켜면 바로 받아서 켜고(필요한 기능도 같이), 끄면 꺼 두기만 해요. 2.0.0으로 올라오면 안내가 한 번 더 떠요.
화면 모드 · 글자 크기
간단 모드(필요한 것만)와 고급 모드(세부 설정까지) 중에서 골라요. 나중에 설정 → 화면 모드에서 바꿀 수 있어요.
꾸미기
꾸미기 화면과 같은 선택지예요. 테마와 강조 색을 골라요.
장기 기억
기록할 AI, 기억 수준, 임베딩을 정해요. 임베딩 기본 주소와 모델은 미리 채워져 있어요.
이야기 도우미
공정한 전개, 유저 편향 없애기, 이야기 시간, 이미지 태그 교정을 켜고 꺼요.
이미 쓰던 것
HypaPlus·코코아전트·RisuPot을 쓰던 기록이 있으면 찾은 것만 보여 줘요.
요약
고른 내용을 한눈에 보여 줘요. 끝내거나 '나중에 하기'를 누르면 화면마다 따로 뜨던 안내는 자동으로 띄우지 않아요.
💡
설정 → 도움말 → '시작 안내 다시 보기'로 언제든 다시 볼 수 있어요. 화면 위쪽 ? 버튼은 지금 화면의 각 부분을 하나씩 강조하며 안내해요.

AI 생성 중지

Dusk와 애드온이 AI를 쓰는 동안(페르소나·봇 만들기, 기억 기록, 번역, 검토 등 모든 작업) 화면 오른쪽 아래에 ■ 생성 중지 버튼이 떠요. 누르면 지금 돌고 있는 AI 작업을 모두 바로 멈추고, 받은 결과는 버려요. Dusk 창이 닫혀 있을 때(뒤에서 도는 기억 기록 등)는 리스 화면 오른쪽 아래에 떠요(리스 화면 권한이 필요해요). 아주 짧게 끝나는 호출에서는 뜨지 않아요. 리스 본체의 채팅 응답 생성은 리스의 중지 버튼을 쓰세요.

기능 찾기

홈 화면 위 검색창에 낱말을 적으면(예: 생리, 호감, 테마, API) 그 기능이 있는 자리를 목록으로 보여 줘요. 누르면 그 화면으로 가서 해당 항목을 잠깐 강조해 주고, 고급 모드에서만 보이는 항목이면 알려 줘요. 애드온이 꺼져 있어 쓸 수 없는 기능은 ‘애드온 꺼짐’으로 표시돼요.

간단 모드와 고급 모드

기본이에요. 꼭 필요한 것만 보이고, 가끔 쓰는 버튼은 ··· 메뉴에 모여 있어요.
세부 설정이 모두 보여요. 개발자 모드는 고급 모드에서만 켤 수 있어요. 각 화면 맨 아래 '고급 모드에서 더 보기'로도 바꿔요. 두 모드는 같은 데이터를 써요.

호환

기준 환경이에요. 모델 호출 표시는 동작하지 않아요.
모든 기능이 동작해요. 처음 쓸 때 데이터베이스 접근 권한을 물으면 허용해 주세요.
모듈 기능은 모두 동작해요. 대화가 긴 봇의 편집·에셋·업데이트·패치 적용은 RisuVault가 채팅 보호로 막아요. 이때는 안내만 보여 주고 아무것도 바꾸지 않아요.
