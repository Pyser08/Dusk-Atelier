설치하고, 열고, 처음 안내를 따라가는 데까지 걸리는 길이에요.

Dusk Atelier는

RisuAI 용 모듈·캐릭터 관리·업데이트 플러그인이에요. 모듈 켜기·끄기, 폴더, 순서, 연결, 프리셋, 편집, 에셋 관리와 봇·모듈의 빠른 업데이트를 해요. 장기 기억, 이야기 도우미 같은 기능도 함께 있어요.

🛡️
다른 관리 플러그인과 저장 칸을 나눠 쓰지 않아요. 함께 설치해도 서로의 설정·꺼진 모듈·순서를 건드리지 않아요.

설치

  1. 파일 받기dusk_atelier.js 내려받기 (최신 릴리스)
  2. 플러그인 추가RisuAI 설정 → 플러그인에서 dusk_atelier.js를 추가해요. API 3.0을 써요.
  3. 예전 이름이라면예전 이름(Dusk Manager)으로 설치했다면 그 플러그인은 지우고 dusk_atelier.js를 새로 추가하세요. 설정·폴더·백업 기록은 같은 저장소를 쓰므로 그대로 이어져요.

열기

  • 왼쪽 사이드바(햄버거 메뉴)의 Dusk Atelier를 눌러요.
  • 또는 설정 메뉴에서 열어요.
  • 창 안 어디에 파일을 끌어다 놓아도 바로 가져와요.

시작 안내 따라가기

처음 열면 플러그인 창을 꽉 채운 시작 안내가 떠요. 루네가 인사하고, 아래 순서로 안내해요.

  1. 화면 모드 · 글자 크기
  2. 꾸미기 (꾸미기 화면과 같은 선택지)
  3. 장기 기억 (기록할 AI · 기억 수준 · 임베딩)
💡
장기 기억의 임베딩은 이 시작 안내 3단계에서 설정해요. 나중에 바꾸고 싶으면 장기 기억 화면에서 다시 바꿀 수 있어요.

간단 모드와 고급 모드

기본은 필요한 것만 보이는 간단 모드예요. 자세한 설정이 필요하면 고급 모드로 바꿔 쓰면 돼요. 두 모드는 같은 데이터를 써요.
