묘사 지침

심리학·해부학으로 감정과 몸 묘사를 현실에 붙잡아요.

처음 시작 (단계별) 인물 위키 탭 고치기 · 지우기 · 되돌리기 세계 · 캘린더 · 날씨 성인 탭 묘사 지침 장기 기억 (전체 설명)

무엇인가요

AI는 감정·몸 묘사를 과장하거나 비현실적으로 쓰곤 해요(통속 심리학, 너무 빠른 회복). 묘사 지침은 심리 73개 · 몸 68개, 141개 조각에서 지금 장면과 인물 상태에 맞는 것만 골라 한 번에 2개까지 요청에 붙여요.

  • 교과서 수준으로 합의된 내용만. 속설은 ‘피할 것’으로 적었어요.
  • 주제당 하나, 같은 조각은 3턴 쉬고, 리롤해도 같은 결과.
  • AI 호출은 늘지 않아요.

설정

  1. 장기 기억 → 설정 → 기억 옵션 → 묘사 지침 스위치로 켜고 꺼요(기본 켜짐).
  2. 조각 보기·고치기로 141개를 찾아보고, 체크를 끄면 그 조각은 넣지 않아요.
  3. + 조각으로 직접 써요 — 분야·주제·‘글에 이 말이 나오면’(| 로 나눔)·지침. 직접 쓴 조각이 먼저 골라져요.
