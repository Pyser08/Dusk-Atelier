Dusk Cellar

리스를 내 컴퓨터나 서버에서 직접 돌린다면, 옆에 같이 켜 두는 선택 서버예요. 세이브 백업·복원이 빠르고, 장기 기억과 플러그인 수정도 서버가 맡아 줘요. 없어도 Dusk Atelier의 모든 기능은 그대로 돼요.

🗄️
RisuBard·PocketRisu·순정 RisuAI 서버에서 쓸 수 있어요. 웹이나 앱으로만 쓰는 RisuAI에는 해당하지 않아요.

Cellar가 해 주는 일

  • 압축 안 하고 바뀐 파일만 복사해요. 파일 2만 개·약 1GB 시험에서 처음 백업 4.8초(tar.gz 34.6초), 복원 1.0초(풀기 7.2초)로 압축 방식의 약 1/7이었어요. 몇 개만 바뀐 뒤 백업은 3.0초예요.
  • 어디서: 설정 → 서버 → Dusk Cellar → '세이브 백업'. 캐릭터·채팅·에셋·설정 전체와 서버 기억을 한 번에 담아요. 리스가 도는 중에도 백업할 수 있고 기본 5개를 보관해요.
  • 복원이 망가지지 않게: 복원 전에 백업이 온전한지 먼저 확인하고, 지금 상태를 '복원 전 자동' 백업으로 남겨요. 복원이 실패하면 그 백업으로 자동으로 되돌리고 화면에 이유를 보여 줘요. 세이브가 비었거나 디스크가 부족하면 백업하지 않고, 백업하는 동안 세이브가 계속 바뀌었다면 목록에 경고가 떠요.
⚠️
복원하면 리스가 잠깐 꺼졌다 켜져요. 끝난 뒤에는 리스를 열어 둔 화면(다른 기기 포함)을 모두 새로고침해 주세요. 새로고침 전 화면이 옛 상태로 다시 저장할 수 있어요.
  • Cellar가 있으면 채팅별 장기 기억을 처음 한 번 서버로 옮기고, 그다음부터는 서버에만 저장해요. 플러그인 저장소가 가벼워져요.
  • 서버와 잠깐 끊기면 바뀐 기억을 이 기기에 모아 뒀다가 다시 연결되면 알아서 올려요.
  • 다른 기기에서 같은 기억을 동시에 바꿔도 기록을 합쳐서 잃지 않아요.
  • 설정 → 서버 → Dusk Cellar에서 저장 위치를 보고, '기억을 이 기기로 되돌리기'로 언제든 예전 방식으로 돌아갈 수 있어요.
  • 플러그인 탭에서 코드 수정, 켜기/끄기, 순서, 추가/삭제를 할 수 있어요. RisuBard·PocketRisu·순정 리스AI 모두 돼요. 기본으로 켜진 베타 기능이에요.
  • 리스가 플러그인 목록을 막아 두기 때문에 Cellar가 서버에서 대신 고쳐 줘요. 고친 뒤에는 리스 화면을 새로고침(F5)해야 반영돼요. 걸리는 시간은 서버에 따라 달라요.
  • 열려 있던 리스 화면이 옛 목록으로 다시 저장해 버리면 알려 드려요. 그땐 새로고침하고 다시 해 주세요.
⚠️
다른 플러그인 코드도 고칠 수 있는 기능이에요. 믿을 수 있는 플러그인만 설치하세요.
  • Cellar에 새 버전이 나오면 Dusk Atelier가 화면에 알려 줘요(같은 버전은 한 번만). 설정 → 서버의 Dusk Cellar 줄에도 '새 버전 vX'가 보여요.
  • 설정 → 서버 → Dusk Cellar → '업데이트 확인'을 누르면 Cellar만 잠깐 다시 켜지고 리스는 그대로 돌아요. 새 버전이 안 불러지면 자동으로 이전 버전으로 돌아가요.
  • 이 버튼은 git으로 설치한 서버에서만 돼요. git 없이 설치했다면 설치 파일을 다시 실행하면 최신으로 바뀌어요(백업·기억은 그대로).

설치하기

git이나 Node.js를 따로 설치하지 않아도 돼요. 리스 폴더 안에 들어 있는 Node(bin 폴더)를 써요. 아래 설치 파일은 항상 최신 릴리스에서 바로 받아져요.

  1. install.bat 받기
  2. 받은 파일을 리스 폴더(bin 폴더가 있는 곳)에 넣고 더블클릭해요.
  3. 끝나면 폴더에 원래이름_cellar.exe가 생겨요. 앞으로는 이 파일을 눌러서 켜면 리스와 Cellar가 같이 켜져요.
  1. install.command 받기
  2. 받은 파일을 리스 폴더에 넣고 더블클릭해요(처음 한 번은 우클릭 → 열기).
  3. 끝나면 폴더에 원래이름_cellar.app이 생겨요(원래 앱의 아이콘 그대로). 앞으로는 이 앱을 눌러서 켜면 리스와 Cellar가 같이 켜져요.
  1. 리스 폴더에서 터미널에 아래 한 줄을 붙여 넣어요. (install.sh를 받아 bash install.sh로 실행해도 돼요)
    curl -fsSL https://raw.githubusercontent.com/Pyser08/Dusk-Cellar/main/install.sh | bash
  2. 묻는 대로 답하면 pm2에 등록돼서 리스와 함께 켜져요. 부팅 시 자동 실행도 고를 수 있어요.
  3. 휴대용 리스(bin/node가 있는 배포본)라면 start_cellar.sh가 생겨요.
✅
끝나면 리스에서 Dusk Atelier 설정 → 서버 → Dusk Cellar가 '연결됨 v…'으로 보여요. 주소나 토큰을 넣을 필요는 없어요(리스 암호로 보호돼요).
🖥️
이미 git으로 설치해 둔 서버라면 git pull 후 pm2 restart risu를 하거나, 위 '업데이트 확인' 버튼을 쓰세요.

자주 묻는 질문

'없음'이라고 떠요
Cellar가 안 켜져 있거나 못 찾는 거예요. 윈도우·맥은 _cellar 실행 파일로 켰는지, 리눅스는 pm2 list에서 리스가 켜져 있는지 확인해 보세요. 그래도 안 되면 설정 → 서버 → Dusk Cellar에서 '다시 확인'을 눌러 보세요.
원래 쓰던 실행 파일로 켜면 어떻게 돼요?
리스만 켜지고 Cellar는 안 켜져요. 그때는 Dusk Atelier가 '없음'으로 보이고 모든 기능은 예전처럼 플러그인 안에서 동작해요. Cellar와 같이 쓰려면 _cellar 파일로 켜세요.
Cellar를 지우고 싶어요
설정 → 서버 → Dusk Cellar에서 '기억을 이 기기로 되돌리기'를 먼저 누르면 서버의 장기 기억이 플러그인으로 돌아와요. 그다음 Dusk-Cellar 폴더와 _cellar 실행 파일을 지우면 돼요.
백업 파일은 어디에 있어요?
리스 폴더의 Dusk-Cellar/dusk-data/backups에 있어요. 바뀌지 않은 파일은 이전 백업과 공유해서 용량이 크게 늘지 않아요. 디스크가 부족하면 오래된 백업부터 정리하세요.
