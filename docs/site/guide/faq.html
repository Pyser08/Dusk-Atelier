질문과 답

Dusk Cellar가 뭐예요? 꼭 필요한가요?
리스를 직접 돌릴 때 옆에 같이 켜는 선택 서버예요. 없어도 모든 기능이 그대로 돼요. 있으면 백업·복원이 압축 방식의 약 1/7로 빨라지고 장기 기억을 서버에 저장해요. 설치는 Dusk Cellar 안내를 보세요.
모듈이 안 꺼져요
에셋이 있는 모듈은 끌 수 없어요. 끄면 RisuAI의 '사용하지 않는 에셋 정리'로 파일이 지워질 수 있기 때문이에요.
끈 모듈을 다시 켜고 싶어요
끈 뒤 8초 동안은 바로 되돌릴 수 있고, 그 뒤에는 보관함에서 켜요. 업데이트를 해도 꺼진 상태는 유지돼요.
삭제한 모듈이나 봇을 되살릴 수 있나요
삭제 전 상태를 백업해 두기 때문에 도구의 기록(되돌리기)에서 되살릴 수 있어요. 되돌려도 채팅은 그대로예요.
업데이트가 마음에 안 들어요
업데이트 직후 '바로 되돌리기'를 누를 수 있어요. 응답을 생성하는 중에는 적용이 막혀요.
RisuVault에서 편집·업데이트가 막혀요
대화가 긴 봇에서는 RisuVault가 채팅 보호로 막아요. 이때는 안내만 보여 주고 아무것도 바꾸지 않아요. 대화가 짧은 봇은 그대로 돼요.
처음 쓸 때 데이터베이스 접근 권한을 물어요
원본 RisuAI에서는 허용해 주세요. 그래야 모든 기능이 동작해요.
예전 Dusk Manager 설정이 이어지나요
같은 저장소를 쓰기 때문에 설정·폴더·백업 기록이 그대로 이어져요. 예전 플러그인은 지우고 dusk_atelier.js를 새로 추가하세요.
다른 플러그인을 켜고 끄거나 순서를 바꿀 수 있나요
RisuAI(PR #1572 이후)와 이를 따르는 포크는 플러그인이 다른 플러그인을 켜고 끄거나 순서·코드를 바꾸는 것을 막아요. 그래서 그런 기능은 없어요.
모델 호출 표시가 안 나와요
기본은 꺼짐이에요. 홈 빠른 설정에서 켜 주세요. RisuBard에서는 동작하지 않아요.
리롤하면 주사위가 또 바뀌나요
같은 턴을 다시 생성하면 같은 주사위 값을 써요. 새 입력을 보내면 새로 굴려요.
유저 편향 없애기를 켰더니 공정한 전개도 켜졌어요
유저 편향 없애기는 공정한 전개 위에서만 작동해서 함께 켜져요.
임베딩이 실패하면 어떻게 되나요
실패하거나 느리면 기존 방식(단어 기반)으로 이어가요. 키는 이 기기에만 저장되고 내보내기·백업에 들어가지 않아요.
HypaPlus와 같이 써도 되나요
HypaPlus와 Dusk 기억은 동시에 쓸 수 없어요. 한쪽만 켜 주세요. 기억은 'HypaPlus에서 가져오기'로 옮길 수 있고 원본은 그대로 남아요.
이미지 태그가 안 고쳐져요
그룹 채팅에서는 건드리지 않아요. 기본 표정이 없는 봇에서는 고칠 수 없는 태그를 그대로 둬요. 이미 나온 응답은 도구 → 에셋 태그 고치기로 손볼 수 있어요.
백업은 어디에 저장되나요
백업 내용과 원본 기록은 서버에 파일(에셋)로 저장돼요. 그래서 RisuAI의 '사용하지 않는 에셋 정리'를 하면 지워질 수 있어요.
시작 안내를 다시 보고 싶어요
설정 → 도움말 → '시작 안내 다시 보기'에서 언제든 다시 볼 수 있어요. 각 화면 위쪽 ? 버튼은 그 화면의 둘러보기를 보여 줘요.
간단 모드와 고급 모드는 데이터가 달라요?
아니에요. 같은 데이터를 써요. 설정 → 화면 모드에서 바꾸거나, 각 화면 맨 아래 '고급 모드에서 더 보기'로도 바꿔요.
저장한 설정을 지우고 싶어요
도구 탭의 '설정 정리'에서 순서·꺼진 모듈·에셋 폴더·프리셋·연결·폴더·이름 색 중 골라서 지워요.
