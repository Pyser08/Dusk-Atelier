어디서나 같은 편집 줄

  • 줄 오른쪽 ✎ — 여러 칸을 한 창에서 고쳐요.
  • ✕ — 지워요.
  • 목록 아래 + 추가 — 직접 적어요. 날짜는 ‘3월 14일’처럼 써도 3/14로 맞춰요.
  • ↶ 되돌리기 — 마지막으로 고치거나 지운 것을 원래대로.

지운 건 다시 안 적어요

지우면 무시 목록에 들어가서 기록기가 같은 내용을 보내도 걸러요. 몸 흔적·상태이상은 며칠만, 소문·목표·추억·갈등·오해·캘린더·장소는 계속 막아요. 같은 걸 다시 직접 추가하면 막은 것도 풀려요.

고친 값은 잠그지 않아요

고친 값이 출발점이 되고, 이야기가 이어지면 거기서부터 바뀌어요. 바뀌지 않게 하고 싶은 위키 글·수치는 📌 고정을 써요.

마음 흐름·짝사랑·기억에 남은 순간·장면 계획은 다른 값으로 계산되는 칸이에요. 감정·수치·기록을 고치면 따라 바뀌어요.
