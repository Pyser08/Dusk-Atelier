성인 탭 세부

칸내용
상태성욕 게이지·피로·경험·마지막 관계 뒤, 월경·임신·피임(체내 정액량·강제 피임), 인물 비교
취향성인 프로필(성적 수치·8가지 성향·체위·장소), 잠자리 항목, 성적 욕망·이상성향, 선호·금기 태그
신체성감대 인체 모형(종족별 모형·약점 정확한 자리·불감), 몸 흔적
궁합상대와 취향이 얼마나 맞는지(AI 호출 없음)
장면장면 판단·장면 계획

남성 캐릭터 · 나(유저)

  • 남성 성감대 — 음경·귀두·고환·전립선. 남성 모형에만 보이고 무작위 성감대도 성별에 맞게.
  • 성별 고르기(여·남·자동) — 성감대 옆에서. 직접 고르면 잠기고, 자동이면 이야기를 따라가요.
  • 성별 변화 — 변신·마법·성전환이 나오면 그 응답에서 바로. 예전 성감대는 숨겨 두었다가 돌아오면 다시 보여요.
  • 유저(나)의 성인 칸 — 성인 프로필(페르소나 설명으로)·성감대·몸 상태를 따로 저장. 내 상태는 요청·장면 계획에 넣지 않아요(나를 대신 움직이지 않게).

엔진이 계산하는 것

성욕·피로·월경 주기·임신 확률·몸 흔적이 사라지는 날 — 전부 엔진이 계산해요(추가 호출 없음). 달아오르는 속도는 인물마다 다르고, 전체 속도는 설정 → 게이지 배수 → 성욕.
