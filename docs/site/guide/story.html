기능 가이드

이야기 도우미

공정한 주사위로 이야기가 내 뜻대로만 흐르지 않게 하고, 프롬프트 캐시를 확인해요.

체크리스트 · 이야기 도우미 켜기

누르면 체크돼요. 이 기기의 브라우저에 진행이 저장돼요.

  • 홈 → 빠른 설정에서 공정한 전개를 켜요
  • 유저 편향 없애기 박스를 눌러 강도(약하게·보통·강하게)를 골라요
  • 주사위 결과 표시를 켜고 응답 아래에서 굴림을 확인해요
  • 모델 호출 표시를 켜서 캐시 적중이 얼마나 되는지 봐요

공정한 전개

이야기가 내 뜻대로만 흐르지 않게 해요. 홈 빠른 설정이나 채팅 입력창 옆 메뉴에서 바로 켜고 끌 수 있어요.

유저 편향 없애기

요청을 보낼 때마다 프로그램이 1~100 주사위를 굴려 AI에게 함께 줘요. AI는 성공할지 불확실한 행동만 이 값으로 가려요. 행동마다 쉬움·보통·어려움·극악 중 난이도 수치가 정해지고, 굴림이 그 수치 이상이면 성공이에요. 공정한 전개가 켜져 있을 때만 작동해요.

강도효과
약하게성공하기 쉬워요.
보통기본값이에요.
강하게난이도 수치가 높아 실패가 늘어요.

홈 빠른 설정의 '유저 편향 없애기' 박스를 누르면 상세 창이 열려요. 고급 모드에서는 난이도 수치와 주사위 개수를 직접 넣을 수 있어요.

내가 결과까지 적었을 때

상세 창의 강도 위에서 고르는 설정이에요. 재해석(기본)은 내가 적은 결과도 시도로 보고 주사위로 가리고, 존중은 내가 적은 대로 따라요.

체험 · 주사위 굴려 보기

기본 주사위 3개를 굴려 선택한 강도·난이도의 목표치와 견줘요. 이 화면은 연습용이에요.


리롤해도 같은 주사위

같은 턴을 다시 생성(리롤)하면 같은 주사위 값을 써요. 마음에 드는 판정이 나올 때까지 돌리는 걸 막고, 프롬프트도 그대로라 캐시도 덜 깨져요. 새 입력을 보내면 새로 굴려요.

판정 결과 이어 주기

AI가 응답 끝에 판정한 행동마다 숨은 표식(화면엔 안 보여요)을 남기고, 다음 턴에 그 결과(예: 경비병 설득 → 실패)를 다시 알려 줘요. 실패한 일을 없던 일처럼 넘기지 않아요.

주사위 결과 표시 기본 꺼짐

켜면 응답 아래에 굴린 주사위 값이 굴러가는 모양으로 나오고, 난이도 목표치와 견줘 '대실패 · 실패 · 애매 · 성공 · 대성공'으로 보여 줘요. 채팅에 저장된 글은 바뀌지 않아요. 상세 창의 '최근 판정 기록'에서 굴린 값과 평균도 볼 수 있어요.

이야기 시간

'이야기 시간 자동 삽입'을 켜면 이야기 속 시각을 AI에게 알려 줘요.

캐시 확인하기

모델 호출 표시 기본 꺼짐

요청을 보내면 화면 구석에 메인/보조 구분, 모델 이름, '추론 중/출력 중'과 흐른 시간이 떠요. 끝나면 걸린 시간과 입력·출력 토큰(글자 수로 어림)을 보여 주고, 눌러서 펼치면 그때 들어간 로어북 목록과 입력 내역이 나와요. 입력 내역은 메인 요청을 시스템·봇 설정·로어북, 채팅 기록, 장기 기억, 인물 위키, 정리 노트, 모듈 호환 안내처럼 나눠 각각 몇 토큰인지(어림) 큰 것부터 보여 줘요. 입력이 갑자기 늘었을 때 무엇이 키웠는지 바로 알 수 있어요. 보조 호출 줄에는 그 요청부터 다음 요청 전까지 플러그인·애드온이 부른 보조 모델 호출이 작업별(장기기억 · 기억 기록, 정리 노트, Erosync·애드온 등)로 몇 번, 입력·출력 몇 토큰인지 나와요. 내 API 모델은 공급자가 알려 준 실제 토큰이고, 리스 보조 모델은 글자 수로 어림해요. 기억 기록처럼 응답 뒤에 끝나는 호출은 화면이 다시 그려질 때 더해져요.

캐시 적중 표시

이번 요청이 직전 요청과 앞부분이 얼마나 같은지(프롬프트 캐시를 다시 쓸 수 있는 정도)를 어림해서 보여 줘요. 달라지기 시작한 위치와, Dusk가 넣은 내용(이야기 시간·장기 기억 등) 때문이면 그 이름도 알려 줘요.

캐시 깨짐 알림 기본 켜짐

앞부분이 절반도 안 같아 캐시가 깨지면 모델 호출 표시를 꺼 둬도 화면 구석에 이유를 잠깐 알려 줘요. 고급 설정 → 이야기 도우미에서 끌 수 있어요.
