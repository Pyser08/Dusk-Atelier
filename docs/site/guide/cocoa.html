기능 가이드

코코아 · 스킬

코코아전트의 스킬 세트를 그대로 가져와 단계별 지침으로 쓰는 기능이에요.

체크리스트 · 스킬 쓰기

누르면 체크돼요. 이 기기의 브라우저에 진행이 저장돼요.

  • 코코아 탭에서 스킬 세트(ZIP·JSON)를 가져와요 — 코코아전트를 썼다면 '옮겨오기'
  • 사용할 스킬을 골라요
  • 스킬 주입(코코아 기능)을 켜요 — 기본은 꺼짐
  • 호출 기록(고급 모드)에서 스킬 글이 붙었는지 확인해요

스킬이란

스킬 세트(ZIP·JSON)를 가져오면 고른 단계(관련 인물 고르기·정리 노트·기록하기·기억 분석)의 프롬프트 뒤에 스킬 지침이 붙어요. 별도 AI 호출은 없고, 기본은 꺼짐이에요. 장기 기억과 따로 켜고 꺼요.

체험 · 스킬을 붙일 단계 고르기

스킬은 고른 단계의 프롬프트 뒤에 붙어요. 단계를 눌러 켜고 꺼 보세요.

코코아 탭

사이드바 '기억' 섹션의 코코아 탭이에요. 열린 채팅이 없어도 열려요.

  • 켜기 카드에 'N개 중 M개 사용 중'이 보여요.
  • 간단 모드: 코코아 기능 켜기, 스킬 목록(가져오기·새로 만들기·수정), 사용할 스킬 고르기.
  • 고급 모드: 단계별 붙이기, 코코아전트 옮기기, 웹 도구, 호출 기록.

코코아전트에서 옮겨오기

같은 기기에 코코아전트를 쓴 기록이 있으면 스킬 세트와 에이전트별 스킬 연결을 찾아 단계에 이어 줘요. 원하면 에이전트 프롬프트도 스킬로 바꿔요. 코코아전트 데이터는 바꾸지 않아요.

AI로 스킬 만들기

코코아 탭 오른쪽 아래 버튼이에요. AI와 대화하며 스킬 초안을 실시간으로 만들고, 점검 뒤 라이브러리에 넣거나 ZIP·JSON으로 내보내요. 메시지를 보낼 때마다 AI 호출이 한 번 생겨요. 각 스킬 세트는 목록에서 바로 ZIP·JSON으로 내보낼 수 있어요.

웹 도구 기본 꺼짐

스킬 화면의 '웹 도구'를 켜면, 고른 단계(기본: 정리 노트)에서 모델이 필요하다고 판단할 때만 검색이나 페이지 읽기를 요청해요. 요청이 있으면 그 단계의 AI 호출이 1~2번 늘어요.

  • 검색: Wikipedia·DuckDuckGo(키 없이), Brave·Tavily·Serper·Exa(API 키), SearXNG(서버 주소)
  • 키는 이 기기에만 저장되고 내보내기·백업에 들어가지 않아요.
  • 페이지 읽기는 공개 http/https 주소만 가능해요. '시험 검색'으로 설정을 확인해요.
