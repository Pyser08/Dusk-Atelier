# Dusk Atelier 기능 총정리 (v1.6.0 기준)

RisuAI 플러그인. 모듈·봇을 관리하고 업데이트한다. 원본 RisuAI, PocketRisu, RisuBard에서 동작.
- 저장소: https://github.com/Pyser08/Dusk-Atelier (소스 `src/`, 빌드 결과 `dusk_atelier.js`, 변경 기록 `CHANGELOG.md`)
- 설치: `dusk_atelier.js`를 받아 RisuAI 설정 → 플러그인에 추가. 이후 업데이트는 같은 화면의 초록 + 버튼(//@update-url)
- 여는 곳: 왼쪽 사이드바(햄버거 메뉴)의 Dusk Atelier, 설정 메뉴, 리스 + 메뉴 버튼

---

## 1. 화면 구성 (탭)
| 탭 | 내용 |
|---|---|
| 모듈 | 모듈 켜기·끄기·정리·편집 |
| 플러그인 | 설치된 플러그인 관리, DA Interop 연동 설정 |
| 캐릭터 | 봇 관리·편집·업데이트 |
| 도구 | 기록·프리셋·로어북 로그·백업 등 |
| 설정 | 로어북 규칙·테마·색·업데이트 설정·설정 정리·개발자 모드 |
| 개발 | 개발자 모드를 켜면 생김. 패치 제작 |

- 모바일: 탭은 아래로, 상세는 아래에서 올라오는 시트, 손잡이 끌어 순서 변경
- 패치노트 창: 업데이트 후 처음 열 때 "이전 → 지금" 변경점을 한 번 보여 줌(건너뛴 버전 포함). 사이드바 아래 버전 글자로 다시 보기
- 새 버전 알림: 열 때 새 버전 확인

## 2. 모듈 탭
- 켜기·끄기(8초 안에 되돌리기). 꺼 둔 모듈은 Dusk 보관함에 보관
- 폴더(색 지정), 이름 색, 검색·필터, 정렬(이름순·크기순·원래대로), 끌어서 순서 변경(행 전체 드래그)
- 연결: 글로벌 · 페르소나별 · 캐릭터별
- ⋯ 메뉴: 편집, 에셋, 내보내기, 패치 적용, 삭제

## 3. 캐릭터 탭
- 리스 사이드바와 같은 폴더·순서 사용(여기서 바꾸면 사이드바도 즉시 반영)
- 봇 편집, 에셋 정리, 업데이트·패치 적용, 다른 봇에서 가져오기·합치기, ⋯ 메뉴
- 봇 저장: 한 번 읽고 바로 저장, 편집 전 백업은 뒤에서

## 4. 업데이트 (핵심 기능)
### 업데이트하는 세 가지 방법
1. **리스에서 그냥 가져오기/끌어 놓기**: 기존 봇·모듈의 새 버전이면 이어 붙일지 물음. 새 봇이면 우측 상단 토스트로 합칠 봇 검색 제안. 감지는 플러그인 켜지자마자 시작
2. **Dusk 가져오기**: .charx · .risum · PNG 카드 · .json. 기존 것을 찾아 업데이트, 여러 파일 순차 처리
3. **패치 파일**: `.rbupatch`를 모듈 ⋯ 메뉴/봇 메뉴의 [패치 적용]으로

### 업데이트 엔진 (RisuTide 이식)
- 세 방향 비교(지난번 받은 파일 · 지금 · 새 버전): 제작자 변경은 반영, 내가 고친 부분은 보존, 같은 곳을 둘 다 고치면 충돌 → 항목마다 선택
- 인사말 보호
- 검토 화면: 아이콘 카드, 단어 단위 비교, 검색·필터, 충돌로 이동
- 업데이트 영향 미리보기: 모듈은 켜짐·글로벌·쓰는 봇·채팅별 연결·페르소나, 캐릭터는 채팅 수·연결 모듈·그룹 채팅 (가져오기 업데이트·패치 적용 확인 모두)
- 바꾸기 전 상태 자동 백업(내용 주소 방식, 채팅 포함 선택), 지운 봇 되살리기
- 봇이 답변 생성 중이면 업데이트·저장을 막음

### 빠른 가져오기 (v1.5.3~)
- PC 메인 화면 오른쪽 아래 작은 상자 → 누르면 Dusk 가져오기 화면. 에셋을 여러 개씩 동시에 올려 리스 기본 가져오기보다 빠름
- 리스는 상자 위에 떨어뜨린 파일을 플러그인에 주지 않으므로, 상자를 눌러 열린 화면에 놓아야 함
- 접으면 ⚡ 아이콘, 끌어서 위치 이동(기억), 모바일에선 숨김, 채팅 화면이 떠 있는 동안 숨김(v1.5.5), 설정에서 끄기 가능

### 합치기
- 인물만 / 인물+세계관 / 전체, 겹치는 이름 자동 변경
- 출처별 부분 업데이트·떼어내기
- AI 다듬기 스위치(기본 꺼짐)

## 5. 편집기 (모듈·봇 공용)
- 탭: 정보 · 로어북 · 정규식 · 트리거 · JSON
- Ctrl+F 찾기, Ctrl+S 저장, 정규식 오류·키 없는 로어북 등 미리 경고, 저장 전 변경 요약
- 항목별 스크롤·커서 위치 기억, 첫 메시지 일반/코드 모드, 긴 줄 자동 줄바꿈
- 코드 편집기: regex·replace·lua·CBS·HTML 하이라이트, 괄호 짝, 줄 번호, 되돌리기·다시 하기(Ctrl+Z / Ctrl+Shift+Z·Ctrl+Y, 단어 단위, 한글 조합 묶음)
- CBS 사전 버튼

### 로어북 목록 (v1.6.0)
- 탭: **전체**(폴더 트리) / **캐릭터**(폴더·장소 빼고 인물만, 소속 배지) / **소속**
- **Dusk 폴더**: 폴더 안에 폴더(제한 없음), 폴더 색 자동 배정(폴더 화면에서 변경), 끌어 놓기(폴더 줄 가운데=안으로, 위·아래 가장자리=앞뒤로), 접기·펼치기
- **만들기 메뉴**: 폴더 / 소속 폴더 / 장소(지금 폴더 안) / 장소(독립). 폴더 만들 때 넣을 항목 바로 선택
- **선택 모드**: 여러 개 골라 Dusk 규칙 켜기·끄기, 폴더로 옮기기, 삭제. 고른 것 하나를 끌면 모두 같이 이동
- **리스 순정 폴더**: 로어북을 열면 Dusk 폴더로 바꿀지 물음. 안 바꾸면 한 단계 폴더로 계속 사용
- 데이터: 폴더 `extentions.da_folder = { id, color?, aff? }`, 부모 `extentions.da_parent`. 폴더 항목은 키·내용이 비어 리스가 건너뜀. Dusk 없는 리스에선 구조가 안 보이지만 로어북은 그대로 동작

## 6. 로어북 규칙 (Dusk 규칙, v1.5.0~)
항목마다 켜면 리스 활성화 키 대신 Dusk가 켤지 정함. 캐릭터·모듈 로어북 모두.
- **동작 원리**: 내용을 `@@activate` + `{{#if {{getvar::da_xxxx}}}} … {{/if}}`로 감싸고, 입력 시(프롬프트 조립 전) Dusk가 변수를 1/0으로 씀. CBS·배치·토큰 계산은 리스가 처리. Dusk 없으면 꺼진 항목으로 보임
- **저장 위치**: 항목의 `extentions.da_rid`, `extentions.da_rule` → .charx·PNG·.risum에 그대로 따라감
- **조건**(모두 만족/하나라도): 키, 특정 단어 있음·없음, 채팅 변수 비교, 턴 범위, 단어 누적 N번 이상, 항목이 N번 이상 켜짐, 다른 항목 켜짐·안 켜짐
- **빈도**: 확률, 반복(제한 없음·채팅에서 한 번·N턴 쉬기), 유지(N턴 계속 켜 둠), 중복 금지 그룹(한 턴에 하나만)
- **연쇄**: A가 켜지면 B도 N%
- **켜질 때 변수**: =, +, −, ×, ÷, 수식(`clamp(love*1.5,0,100)`, min·max·abs·floor·ceil·round·clamp·rand, turn)
- **배치**: 로어북 자리 / 대화 사이(깊이) / 대화 맨 끝, 역할 system·user·assistant
- **이름 경계**: '김민'이 '김민수'엔 안 걸리고 '김민이·김민에게'엔 걸림
- **찾는 범위**: 최근 N개 메시지(기본 4, AI 출력 포함)
- **리롤**: 응답 후 같은 턴을 미리 다시 계산 → 리롤 때 확률 새로 굴림(설정에서 "이전 결과 유지" 가능). 리롤·빈 입력은 다음 턴으로 세지 않음(v1.6.0)
- **검증**: 없는 대상, 자기 참조, 정규식 오류, 키 중복, 수식 오류 등
- **규칙 시험 창**: 편집 화면 우측 하단. 가상 대화를 한 턴씩 보내며 켜짐/안 켜짐 이유, 변수 변화 확인. 턴·변수·이전 대화·켜진 기록·확률 고정 설정, 마지막 턴 취소. 저장 전 내용 그대로 계산, 실제 채팅 영향 없음
- **F12 콘솔**: `[Dusk 규칙] 턴 N: 항목(이유)…`, `턴 N 빠짐: 항목(확률/최대 인원 이유)`

### 소속 · 장소 (v1.6.0)
- **소속 폴더**: 폴더에서 [소속으로 쓰기]를 켬. 이름에 `[소속] ` 자동. 안의 항목(하위 폴더 포함)이 모두 구성원 → 게헨나 ⊃ 선도부 ⊃ 히나면 히나는 둘 다 소속
  - 켜지는 조건: 소속 키 · 그 소속의 장소가 켜짐 · 구성원이 자기 키로 켜짐 (다른 소속 때문에 켜진 사람은 세지 않음 → 줄줄이 켜짐 방지)
  - 구성원: 기본 확률 + 구성원별 확률(100=항상), 최대 인원 N명(확률 통과자 중 무작위). 자기 키로 켜진 구성원은 제한 무관
  - 데이터: `da_folder.aff = { def, max, prob: { rid: % } }`
- **장소**: 이름에 `[장소] ` 자동, 장소 키가 나오면 장소 설명이 들어감
  - 종속: 소속 폴더 안 → 그 소속도 켜짐
  - 독립: 폴더 밖 → 장소만 켜짐, 같이 켤 소속을 골라 연결 가능 (`extentions.da_place.links`)
- **같은 인물을 여러 소속에**: 복제해서 다른 폴더에 둠. 이름·내용이 같은 항목은 한 턴에 한 번만 주입. 내용이 어긋나면 경고 + [다른 쪽도 이 내용으로 맞추기]
- 소속 안 항목·장소·소속 폴더는 저장 시 Dusk 규칙이 자동으로 켜짐

## 7. 로어북 로그 (v1.5.1~)
- 응답마다 들어간 로어북 항목 기록(Dusk 규칙 없는 봇도). 보낸 프롬프트로 확인, 못 보면 키·규칙으로 추정
- 도구 → [로어북 로그]: 지금 채팅·전체, 이름·입력 검색, 출처(캐릭터·채팅·모듈), 이유(키 일치·항상 켜짐·Dusk 규칙)
- 응답 아래 [📖 로어북] 접는 버튼(화면에만 붙음)
- 설정 → 로어북에서 로그 끄기·버튼 숨기기

## 8. 도구 탭
- **기록·되돌리기**: 업데이트·편집·삭제·불러오기 전 상태 보관, 지금과 비교, 되돌리기(채팅 유지)
- **프리셋**: 모듈 켜기·끄기 조합과 순서 저장, 버튼 하나로 전환, 모바일용·PC용 자동 전환, 파일 내보내기·가져오기, 공유 코드 `DA-PRESET:`, 같은 이름 충돌 처리(덮어쓰기/이름 바꿔 추가/건너뛰기), 모듈 id가 달라도 이름으로 연결
- 로어북 로그, 업데이트 가져오기, 다른 봇에서 가져오기·합치기
- **전체 백업·복원**: 모든 모듈(꺼진 것 포함)·프리셋·폴더·색 설정을 zip으로. 빠른 백업(에셋 제외) / 에셋까지. 복원은 합치기 / 없는 것만 추가 / 통째로 바꾸기
- **.risum 인스펙터**

## 9. 설정 탭
- 로어북 규칙 설정(리롤 때 새로 굴리기/이전 결과 유지), 로어북 로그
- **테마 스튜디오**: 채팅 테마(커스텀 HTML·CSS) 제작·적용. 일반 리스/포켓 계열 따로 저장(원본 RisuAI가 아니면 포켓 계열). 실제 구조 미리보기(PC·모바일), CSS 변수 편집, 셀렉터 찾기
- **테마 빌더**: 스타일 5종(편지·메신저·미니멀 카드·밤의 일기·비주얼 노벨), 대표색 팔레트·대비 자동, 사진에서 색 뽑기, 다이얼(차분↔화려·각지게↔둥글게·촘촘↔여유), 본문 너비, 장식, 프로필 모양, 글꼴 짝, AI로 새 스타일·부분 고치기·되돌리기, 공유 코드 `DTB1:`
- 색 바꾸기, 업데이트 설정(자동 감지·사본 정리·채팅 백업·빠른 가져오기 상자), 설정 정리(꺼진 모듈 모두 켜기 등), 개발자 모드

## 10. 에셋 관리자
- 폴더, 여러 개 선택, 일괄 교체, ZIP 받기, WebP 최적화, 메타데이터 지우기
- 캐릭터·의상별 묶음, 이름·확장자 도구
- 중복 찾기: 내용 해시로 묶고 체크한 것만 빼기(묶음마다 하나는 남김), 10초 되돌리기

## 11. 플러그인 탭
- 목록: 분류, 업데이트 확인, 내보내기, 중복 표시
- 연동 설정: DA Interop 플러그인 설정을 자동 폼으로, 프리셋 적용
- 만들기: 템플릿으로 플러그인 생성·설치
- 저장소 보기: pluginStorage 키별 지연 로딩
- **DA Interop v1**: 다른 플러그인이 스니펫 + `registerInterop`으로 설정값·프리셋을 등록하면 Dusk가 조절 UI를 만들어 줌. 필드 list·multiselect·json·readonly 등. 공식 API만 사용, 차단 환경에선 자동 비활성

## 12. 개발 탭 (개발자 모드)
- 바뀐 부분만 담은 **패치(.rbupatch)** 제작·배포. 배포 기준 표시가 중요(배포 직후 [지금 상태를 기준으로 표시], 또는 [파일에서 기준 불러오기]/기록 선택). [만든 뒤 새 버전을 다음 기준으로]
- **파일 두 개로 패치**: 배포본 + 새 버전 파일만으로(.charx·.png·.jpg / .risum·.json)
- **조립한 파일과 비교**: 밖에서 조립한 파일을 개발 모드 안에서만 불러와 기준과 비교(리스 목록엔 안 들어감). 이름·제작자·네임스페이스가 다르면 확인
- **불러오기**: 로어북·정규식·트리거 .json(리스 내보내기·모듈·카드·배열 형식), 합치기/전체 덮어쓰기, 불러오기 전 자동 백업
- **내보내기**: 로어북·정규식·트리거 .json, 모듈 .json/.risum, 봇 .charx

## 13. 알아 둘 것
