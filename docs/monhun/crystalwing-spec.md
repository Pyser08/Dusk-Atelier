# 유리날개룡: 몬스터 원안 · 소재 도감 · 대검 설계

> 기준: `design-bible.md`. 표시 규칙은 **[확정]**(대화에서 정한 것)과 **[제안]**(이 문서에서 새로 제안, 미확정)이에요.

## A. 몬스터 원안

| 항목 | 내용 |
|---|---|
| 이름 | [확정] 투익룡(透翼龍) |
| 분류 | [확정] 비룡종. 날개팔을 짚고 네발로 걷는 체형(공용 비룡형 뼈대) |
| 외형 | [확정] 날개팔을 짚고 네발로 걷는 체형, 스테인드글라스 같은 결정판 날개(어두운 납선), 부채꼴 결정 볏, 등~꼬리 결정 가시, 꼬리 끝 프리즘, 뒷날개 한 쌍 |
| 몸 색의 정체 | [확정] 검은 몸은 가죽색이 아니다. 빛을 잃고 나이 든 반투명 비늘이 여러 겹 겹쳐 흑요석처럼 검게 보이는 것 |
| 서식 | [확정] 용맥이 지나는 땅(원작 세계관의 용맥 개념을 빌림) |
| 에너지 | [확정] 빛을 에너지로 바꿔 산다 |
| 주 공격 | [확정] 비늘 달린 날개를 앞으로 모아 빛을 응축시켜 빔으로 쏜다 |
| 주 공격 2 | [확정] 날카로운 날개를 모아 뾰족한 창 모양으로 만든 뒤 몸째 들이박는 돌진 |
| 예비 동작 | [확정] 빔과 돌진은 같은 "날개 모으기" 자세에서 시작하고, 이 자세를 길게 둔다 |
| 비늘 사격·열상 | [확정] 부공격. 비늘을 쏘고, 맞으면 비늘이 깨지며 열상 |
| 필살기 | [확정] 빔 |
| 부위 파괴 | [확정] 가슴, 날개(좌우), 꼬리 절단 |
| 파괴와 빔 | [확정] 가슴 또는 날개를 부수면 빔 위력 약화, 둘 다 부수면 빔을 못 쏨 |
| 속성 | [검토] 무속성 또는 용속성 |
| 빔 후 틈 | [확정] 빔을 쏜 뒤 날개 결정이 흐려져 잠시 무력해짐 |

### 확정 설정에서 나온 제안 [제안]
- **비늘의 일생**: 새 비늘은 맑고 빛을 머금는다 → 빛을 다 쓰면 흐려지고 검어진다 → 바깥층으로 밀려나 겹겹이 쌓인다. 나이 든 개체일수록 더 검고 육중하다
- **용맥과의 관계**: 용맥에서 새어 나오는 빛(용맥 에너지)을 비늘이 흡수한다. 용맥이 강한 곳에서만 새 비늘이 자란다
- **날개 모으기 [제안]**: 빔과 돌진은 같은 "날개 모으기" 자세에서 갈라진다. 날개 끝을 앞으로 모아 결정판이 렌즈처럼 겹치면 빔, 모은 날개를 뒤로 눕혀 창끝을 만들면 돌진. 같은 예비 동작이라 사냥꾼이 판판이 읽어야 함
- **비늘 사격의 원리**: 등·날개의 늙은 검은 비늘을 근육으로 튕겨 낸다(탄약 소모 = 묵은 비늘 털어내기). 깨지는 면이 날카로운 흑요석처럼 갈라져 열상을 낸다
- **분노·충전 상태**: 용맥 에너지를 받으면 안쪽 새 비늘이 비쳐 몸에 빛줄기가 돈다. 이때 쏘는 비늘은 맑고 빠르다
- **약점 흐름**: 비늘을 많이 쏠수록 겉층이 얇아져 맑은 속비늘이 드러난다 → 부위가 무르게 된다
### 특수 기관 [제안]
- **광낭(光囊)**: 가슴 안쪽의 반투명 주머니. 결정판이 모은 빛을 저장한다. 꼬리 프리즘과 신경처럼 이어져 있음
- **꼬리 프리즘**: 저장한 빛을 한 방향으로 모아 내보내는 렌즈 덩어리

## B. 소재 도감

### 소재 컨셉 [확정]
- 무기의 핵심부(칼날 등 날이 서는 부분)는 **반짝이는 맑은 비늘**
- 그 외 부분(몸체·칼등·가드·손잡이 등)은 **빛을 잃은 검은 비늘**이 주 소재
- 근거: 맑은 비늘 = 빛을 머금은 새 비늘(희소·날카로움), 검은 비늘 = 겹겹이 쌓인 묵은 비늘(흔함·묵직함)

### 명명 규칙 [확정]
- 소재 이름은 몬스터 헌터 방식을 따른다: "(몬스터명)의 비늘", "(몬스터명)의 발톱", "(몬스터명)의 보옥" 등

### 소재 목록 [확정] (하위 기준)
- 라이즈 하위처럼 접두어 없이 기본 소재 구성을 따른다
- 상위 소재는 이름 뒤에 + 를 붙인다(예: 투익룡의 비늘+)
| 소재 | 출처 | 설명 | 무기 쓰임 |
|---|---|---|---|
| 투익룡의 비늘 | 몸 바깥 | 빛을 잃은 검은 묵은 비늘 | 몸체, 칼등, 가드 (주 소재) |
| 투익룡의 갑각 | 등·어깨 | 검은 비늘이 겹겹이 굳은 판 | 하중부, 큰 판 |
| 투익룡의 발톱 | 날개 손목·뒷발 | 휘어진 검은 발톱 | 칼끝, 갈고리, 폼멜 |

| 투익룡의 꼬리 | 꼬리(절단 보상) | 마디 꼬리 | 칼 심, 손잡이 |

| 익막결정판 | 날개막 | 빛을 받아 모음, 비행면 | 단단하고 가벼움, 충격에 깨짐(취성) | 반투명 하늘·연보라, 판 경계에 어두운 납선 | 연마로 날 세우기 가능, 판 단위로만 사용 | 칼날 외판, 날 | 판 하나는 손바닥~팔 길이까지, 홀로는 충격에 약해 뼈대에 물려야 함 |

| 프리즘추 | 꼬리 끝 | 빛을 모아 쏨 | 매우 치밀, 무거움 | 여러 결정이 뭉친 덩어리 | 깎아서 렌즈 모양으로 | 속성 발현부(빛 코어) | 희소, 상위 소재 |
| 광낭막 | 가슴 광낭 | 빛 저장 | 얇고 질긴 막, 빛을 머금음 | 반투명, 안쪽이 은은히 빛남 | 금속 틀에 씌워 주머니로 | 모으기 시 빛나는 공명부 | 희소, 최상위 소재 |
| 꼬리뼈마디 | 꼬리 | 꼬리를 휘두르는 마디 뼈 | 짧고 굵은 마디, 압축에 강함 | 회백색, 마디마다 둥근 부풂 | 구멍을 뚫어 축에 꿸 수 있음 | 칼 심(마디를 꿴 축) | 마디 하나가 짧아 여러 개를 이어야 함 |
| 등결정가시 | 등~꼬리 | 위협, 빛 반사 | 단단, 밑동이 넓은 쐐기 | 앞으로 누운 결정 가시, 크기가 물결침 | 밑동을 소켓에 박아 고정 | 톱날, 날 보강 | 밑동이 아니면 고정이 어려움 |

## C. 대검 설계 [제안]

### 핵심 실루엣
- 두툼하고 넓은 단일 칼날. 칼등은 **익완골**이 곧게 받치고, 칼날은 **익막결정판**이 비늘처럼 겹쳐 날 쪽으로 계단을 이룬다(날개막의 판 배열을 따름).
- 칼끝은 **손목갈고리**가 앞으로 휘어 마무리한다. 실루엣만으로 "날개 한 짝"이 읽히도록 한다.

### 부품별 소재 배치와 이유

| 부품 | 소재 | 이유 |
|---|---|---|
| 칼등 뼈대 | 익완골 | 휨에 강한 긴 뼈라서 대검의 하중을 받는 축으로 적합. 관절 마디는 깎지 않고 남겨 출처를 보여 준다 |
| 칼날 외판 | 익막결정판 | 단단하고 가벼워 날로 좋지만 깨지기 쉬워, 뼈대 홈에 물리고 판끼리 겹쳐 충격을 나눈다 |
| 판 소켓 | 단조 금속 | 결정판을 뼈에 고정하는 구조 부품. 장식이 아니라 판을 잡는 집게 역할 |
| 날 | 익막결정판 연마면 | 판 끝을 갈아 맑은 날을 세운다 |
| 칼끝 | 손목갈고리 | 원형을 살려 걸어 당기는 끝. 베기 끝에 걸림을 준다 |
| 밑동 코어 | 프리즘추(상위형부터) | 빛을 모으는 렌즈. 모으기 단계마다 밝아짐(기믹 연결, 근거 있는 발광) |
| 가드 | 익완골 관절 + 금속 깃 | 날개 어깨 관절을 그대로 써서 칼날 뿌리를 받친다 |
| 손잡이 | 청회가죽 감개 + 뼈 폼멜 | 질긴 가죽으로 미끄럼 방지 |

### 강화 계보

| 단계 | 변화 | 근거 |
|---|---|---|
| 초기형 | 익완골에 거친 결정판 몇 장을 가죽끈으로 묶음. 판 크기가 들쭉날쭉 | 소재 원형이 많이 남음, 단순 가공 |
| 중간형 | 판을 금속 소켓으로 고정, 판 배열이 정돈되고 날을 연마 | 결합 방식 개선 |
| 상위형 | 밑동에 프리즘추 코어, 칼끝 손목갈고리 | 핵심 특수 소재 반영 |
| 최종형 | 광낭막을 코어에 씌워 모으기 시 칼날 전체 판이 순서대로 맑아짐. 판과 뼈가 매끄럽게 하나로 | 소재·구조·실루엣 통합 |

### 다른 대검 계보 [제안]
- **꼬리마디대검**: 꼬리뼈마디를 금속 축에 꿰어 칼 심으로, 등결정가시 밑동을 마디마다 소켓에 박아 톱날을 이룬다. 칼끝은 프리즘추. 압축에 강한 마디와 쐐기 가시 → 내려칠 때 충격을 받아내는 구조
- **부채볏대검**: 볏결정을 결 방향으로 쪼갠 쐐기 판을 익완골 칼등에 부채처럼 엇갈려 박는다. 판마다 방사형 결이 남고, 판 사이를 금속 꺾쇠로 잇는다. 가드는 볏 밑동 뼈(머리 통째 장식은 피함)
