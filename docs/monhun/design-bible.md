# 몬스터 헌터 오리지널 무기 디자인 바이블
> 작업 문서 · 기준 방향: **Monster Hunter Wilds의 시각 언어**  
> 목적: 오리지널 몬스터의 생태와 소재를 바탕으로, 공식 몬스터 헌터 장비 라인업에 추가되어도 이질감이 적은 무기를 설계한다.

---

## 0. 프로젝트 방향

이 프로젝트의 목표는 단순히 몬스터 부위를 붙인 판타지 무기를 만드는 것이 아니다.

**몬스터의 생태·해부학·소재 특성이 무기의 형태, 구조, 재질, 기능으로 자연스럽게 이어지는 것**이 핵심이다. 완성품은 해당 몬스터를 사냥하고 얻은 소재를 숙련된 가공 장인이 실제 사냥 도구로 제작한 것처럼 보여야 한다.

### 기준 스타일

- 기본 기준은 **Monster Hunter Wilds**.
- 자연스러운 생물학적 디테일과 설득력 있는 소재 표현을 중시한다.
- 월드·아이스본의 입체적인 재질감과 세밀한 가공 표현을 참고할 수 있지만, 최종적인 형태와 질감은 와일즈 쪽에 맞춘다.
- 구작의 과감한 개성은 필요한 경우 보조적으로 활용한다.
- 현실 무기처럼 지나치게 절제하거나, 일반 판타지 RPG처럼 장식적으로 과장하지 않는다.

### 디자인을 관통하는 한 문장

> 몬스터 헌터의 무기는 몬스터의 부산물을 장식으로 붙인 무기가 아니라, 그 생물의 일부를 이해하고 가공해 만든 사냥 도구다.

---

## 1. 핵심 디자인 철학

### 1.1 몬스터의 정체성이 무기에 남아 있어야 한다

무기를 봤을 때 원본 몬스터의 특징을 연상할 수 있어야 한다. 단순히 몬스터의 대표 색을 칠하거나 머리 모양 장식을 붙이는 것으로는 부족하다.

반영할 수 있는 요소:

- 신체 비율과 골격 구조
- 뿔, 발톱, 이빨, 꼬리, 날개, 갑각 등 해부학적 형태
- 비늘·가죽·뼈·각질·막 등 표면 재질
- 발광 기관, 발열 기관, 독샘, 전기 기관 등 특수 기관
- 공격과 방어 방식
- 서식 환경과 생태적 적응

### 1.2 소재에는 물성이 있어야 한다

소재를 색상이나 무늬로만 표현하지 않는다. 각 소재는 고유한 두께, 강도, 유연성, 표면, 파손 양상, 가공 흔적을 가져야 한다.

| 소재 | 시각적·구조적 해석 예시 |
|---|---|
| 뼈 | 골격 프레임, 손잡이 구조, 두꺼운 지지부, 절단면 |
| 뿔 | 칼날, 찌르기 끝, 타격부, 돌출 구조 |
| 발톱 | 절삭날, 갈고리, 톱니, 날의 일부 |
| 이빨 | 작은 절삭 요소, 톱니열, 날의 보강 |
| 갑각 | 외장판, 방패, 보호구조, 겹침 구조 |
| 비늘 | 층층이 겹친 표면, 방향성이 있는 장갑 |
| 가죽 | 손잡이 감개, 결속, 완충부 |
| 막·섬유 | 유연한 연결부, 장력 구조, 얇은 외피 |
| 특수 기관 | 속성 발현부, 공명부, 압력·열·전기 관련 장치 |

위 표는 고정된 배정표가 아니다. 실제 활용 방식은 몬스터의 생물학적 설정과 무기종에 따라 결정한다.

### 1.3 생물 소재와 가공품이 공존해야 한다

- 몬스터 소재만으로 이루어진 원시적인 무기와, 금속·목재·가죽 등을 결합한 정교한 무기 모두 가능하다.
- 금속은 단순한 장식이 아니라 연결, 지지, 날 세우기, 하중 분산 등 구조적 목적을 가져야 한다.
- 소재의 경계와 결합 방식이 납득되어야 한다.
- 가공 흔적, 리벳, 결속, 접합부, 연마면 등을 적절히 사용한다.

### 1.4 기능과 장식의 관계

- 장식은 무기의 구조나 몬스터의 정체성에서 파생되어야 한다.
- 근거 없는 보석, 금장, 문양, 발광 장식은 남발하지 않는다.
- 비대칭은 생물 소재의 형태나 기능에서 비롯될 때 적극 활용한다.
- 모든 무기를 일부러 거칠고 투박하게 만들 필요는 없다. 몬스터와 장인의 기술 수준에 맞춰 정교함을 조절한다.

### 1.5 실루엣이 먼저다

색상과 표면 디테일을 제거한 실루엣만으로도 무기종과 개성이 구분되어야 한다.

- 무기종의 기본 비례를 지킨다.
- 몬스터의 특징을 실루엣에 반영한다.
- 작은 장식으로 개성을 대신하지 않는다.
- 복잡한 부품을 더하기 전에 전체 외곽선이 설득력 있는지 확인한다.

## 2. 몬스터 설계와 무기 설계의 연결

무기부터 즉흥적으로 만들지 않는다. 아래 순서를 따른다.

1. 오리지널 몬스터의 생태와 외형을 확정한다.
2. 해부학적 특징과 특수 기관을 정리한다.
3. 획득 가능한 소재를 추출한다.
4. 각 소재의 물성과 가공 가능성을 정의한다.
5. 무기종별로 소재의 쓰임을 다르게 해석한다.
6. 무기 구조와 실루엣을 설계한다.
7. 강화 계보와 단계별 변화를 설계한다.
8. 디자인 검증 후 이미지 생성 또는 수정에 들어간다.

### 2.1 몬스터 분석 항목

- 명칭 및 분류
- 생태적 지위와 서식 환경
- 체형, 골격, 관절 구조
- 주요 외피와 내부 조직
- 뿔·발톱·이빨·꼬리·날개 등 특징 부위
- 특수 기관과 작동 원리
- 공격 방식과 방어 방식
- 소재별 희소성 및 획득 부위
- 소재의 물성 및 가공상의 특징

### 2.2 소재 데이터 항목

각 소재를 다음 형식으로 기록한다.

| 항목 | 기록 내용 |
|---|---|
| 소재명 | 게임 내 소재명 또는 작업용 명칭 |
| 신체 출처 | 어느 부위에서 얻는가 |
| 생물학적 기능 | 원래 몬스터에게 어떤 역할을 하는가 |
| 물성 | 단단함, 탄성, 취성, 무게, 열·전기·독성 특성 등 |
| 외관 | 색, 표면, 결, 층, 파손면 |
| 가공 가능성 | 절삭, 연마, 단조 보조, 결속, 성형 등 |
| 무기 활용 | 어떤 부품에 어울리는가 |
| 제약 | 가공 난이도, 취약점, 크기·형태 제한 |

## 3. 무기종별 설계 원칙

몬스터의 소재를 적용하더라도 무기종 고유의 정체성을 잃지 않는다. 모든 무기는 먼저 해당 무기종으로 읽혀야 한다.

| 무기종 | 유지해야 할 핵심 정체성 | 디자인에서 확인할 점 |
|---|---|---|
| 대검 | 거대한 단일 절단 무기 | 칼날의 질량감, 두께, 무게중심, 손잡이와 날의 연결 |
| 태도 | 길고 유려한 도검 | 긴 날, 베기 동작에 맞는 비례, 날의 흐름 |
| 한손검 | 검과 방패의 실용적 조합 | 한 손 조작, 방패의 방어 구조, 두 부품의 소재 관계 |
| 쌍검 | 한 쌍의 독립된 근접 무기 | 좌우의 관계, 손목 주변의 구조, 빠른 동작에 적합한 비례 |
| 해머 | 타격 중심의 둔기 | 타격부의 질량, 충격을 전달하는 축, 손잡이 결합 |
| 수렵피리 | 타격 무기와 악기의 결합 | 실제 공명·발성 구조를 연상시키는 형태, 연주 가능한 구조 |
| 랜스 | 방패와 장병기 | 찌르기 축, 창끝, 방패의 방어 면적과 연결부 |
| 건랜스 | 랜스와 포격 장치 | 포신, 약실·배기·장전 등을 연상시키는 기계 구조와 창의 결합 |
| 슬래시액스 | 도끼와 검의 변형 무기 | 두 형태의 정체성, 변형 축과 잠금 구조, 에너지 전달부 |
| 차지액스 | 검·방패·도끼의 복합 변형 무기 | 충전·결합·변형 구조, 방패와 도끼 형태의 관계 |
| 조충곤 | 봉과 사냥벌레 운용 | 봉의 길이와 균형, 곤충 운용과 관련된 장치 |
| 활 | 장력으로 발사하는 원거리 무기 | 활의 프레임, 시위, 장력 구조, 화살의 발사 방향 |
| 라이트보우건 | 경량 원거리 화기 | 총열, 조준·장전·그립, 휴대성 |
| 헤비보우건 | 중량 원거리 화기 | 총열과 본체의 질량감, 지지·반동·장전 구조 |

### 무기종 적용 규칙

- 소재를 적용하느라 무기의 기본 구조를 훼손하지 않는다.
- 같은 몬스터라도 무기종마다 소재를 다른 방식으로 활용한다.
- 모든 무기에 뿔·발톱·비늘을 똑같이 붙이지 않는다.
- 무기종의 기능과 몬스터의 생태적 특징이 만나는 지점을 찾는다.
- 변형 무기는 변형 전후의 구조가 모두 성립해야 한다.

## 4. 강화 계보와 단계별 디자인

강화는 단순히 장식이 많아지거나 크기가 커지는 과정이 아니다. 동일한 무기 계보가 더 좋은 소재와 가공 기술을 통해 발전하는 과정이어야 한다.

### 기본 단계

| 단계 | 디자인 목표 |
|---|---|
| 초기형 | 소재의 원형이 많이 남아 있고 가공이 단순한 무기 |
| 중간형 | 주요 소재가 추가되며 구조와 결합 방식이 개선된 무기 |
| 상위형 | 몬스터의 핵심 특징과 특수 소재가 뚜렷하게 반영된 무기 |
| 최종형 | 소재, 구조, 실루엣이 통합되어 몬스터의 정체성을 완성한 무기 |

### 계보 연속성 규칙

- 초기형의 핵심 실루엣이나 구조적 특징을 계승한다.
- 새 소재가 추가되면 그 소재가 어디에 어떻게 쓰였는지 설명한다.
- 단계별 변화는 소재와 가공 방식의 변화로 정당화한다.
- 최종형은 초기형과 무관한 별개의 무기처럼 보이지 않아야 한다.
- 색상 변경만으로 강화 단계를 구분하지 않는다.

## 5. Monster Hunter Wilds 기준의 시각 방향

### 우선 적용할 요소

- 자연스러운 생물학적 형태와 표면 디테일
- 재질에 따른 빛 반응과 표면 차이
- 소재가 실제로 결합된 듯한 구조
- 지나치게 장식적이지 않은 기능 중심의 디자인
- 몬스터의 생태에서 비롯된 독특한 형태
- 게임 내 장비로 구현할 수 있을 법한 비례와 복잡도

### 참고할 수 있는 보조 방향

- 월드·아이스본: 입체적인 소재 표현, 가공 흔적, 세밀한 구조
- 구작: 과감한 실루엣과 강한 개성

단, 다른 작품의 특징을 무분별하게 섞지 않는다. 최종 판단 기준은 와일즈의 장비 디자인과 자연스럽게 공존할 수 있는가이다.

### 피해야 할 방향

- 일반 판타지 RPG의 마법검처럼 보이는 디자인
- 의미 없이 금장과 보석을 과도하게 붙이는 방식
- 몬스터 소재와 무기 구조 사이에 인과관계가 없는 디자인
- 모든 부위가 같은 재질처럼 보이는 표현
- 기능을 설명할 수 없는 임의의 발광 장치
- 무기종의 기본 형태가 알아보기 어려울 정도로 변형된 디자인
- 장식만 복잡하고 실루엣은 평범한 디자인
- 몬스터의 머리나 몸통을 통째로 붙인 기념품 같은 디자인

## 6. 디자인 검증 체크리스트

완성된 디자인은 다음 기준으로 검토한다.

### 몬스터 연관성
- [ ] 원본 몬스터의 정체성이 무기에 드러나는가?
- [ ] 소재가 실제 신체 부위에서 유래했는가?
- [ ] 몬스터의 생태와 공격·방어 특성이 디자인에 반영되었는가?

### 소재와 제작 설득력
- [ ] 소재별 물성이 구분되는가?
- [ ] 소재가 해당 부품에 쓰인 이유를 설명할 수 있는가?
- [ ] 접합부와 결속 방식이 납득되는가?
- [ ] 실제 제작과 사용을 상상할 수 있는가?

### 무기종 정체성
- [ ] 한눈에 무기종을 알아볼 수 있는가?
- [ ] 무기종의 기능적 구조가 유지되는가?
- [ ] 변형·발사·연주 등 고유 기능이 구조적으로 표현되는가?

### 와일즈 스타일 적합성
- [ ] 생물학적 디테일이 자연스러운가?
- [ ] 재질 표현이 설득력 있는가?
- [ ] 과도한 판타지 장식에 의존하지 않는가?
- [ ] 기존 와일즈 장비와 함께 놓아도 이질감이 적은가?

### 계보와 완성도
- [ ] 강화 단계 사이에 형태적 연속성이 있는가?
- [ ] 강화에 따른 변화가 소재와 제작 과정으로 설명되는가?
- [ ] 색상과 장식을 제외해도 실루엣에 개성이 있는가?

검증에서 실패한 항목은 디자인을 수정한 뒤 다시 평가한다.

## 7. AI 협업 진행 방식

이 문서는 완성된 설정집이 아니라 사용자와 AI가 함께 갱신하는 프로젝트 기준 문서다.

### 협업 원칙

1. 사용자가 제공한 몬스터 설정과 디자인 의도를 최우선으로 한다.
2. 확정되지 않은 설정을 AI가 임의로 정식 설정처럼 확정하지 않는다.
3. 새로운 제안은 기존 설정과 구분해 제시한다.
4. 디자인 선택에는 이유를 붙인다. 특히 소재의 출처와 구조적 역할을 설명한다.
5. 사용자가 수정하거나 거부한 요소는 이후 설계에서 반복하지 않는다.
6. 한 번에 모든 것을 확정하지 않고, 몬스터 → 소재 → 무기종 → 계보 순서로 구체화한다.
7. 이미지 생성은 설계가 충분히 정리된 뒤 진행한다.
8. 결과물이 기준에서 벗어나면 무엇이 어긋났는지 체크리스트로 진단하고 수정한다.

### 권장 작업 순서

**A. 몬스터 원안**
- 외형과 실루엣
- 생태와 서식지
- 공격·방어 방식
- 특수 기관과 속성

**B. 소재 도감**
- 소재 목록
- 획득 부위
- 물성 및 외관
- 가공 방법과 활용 가능성

**C. 무기 설계**
- 대상 무기종 선택
- 핵심 실루엣
- 부품별 소재 배치
- 구조와 기능 설명
- 색상·표면·가공 디테일

**D. 강화 계보**
- 초기형
- 중간형
- 상위형
- 최종형

**E. 시각화 및 검수**
- 정면·측면·후면
- 소재 디테일
- 게임 내 장비로서의 비례
- 체크리스트 검증 및 수정

## 8. 아직 확정하지 않은 사항

아래 항목은 이후 대화에서 함께 결정한다.

- [ ] 첫 번째 오리지널 몬스터의 콘셉트
- [ ] 몬스터의 생태적 분류와 서식 환경

- [ ] 소재의 종류와 희소도 체계
- [ ] 첫 번째로 제작할 무기종
- [ ] 강화 계보의 단계 수와 명명 규칙
- [ ] 무기 설명문과 게임 내 장비 설정의 문체

## 9. 새 작업을 시작할 때 사용할 지시문

이 문서를 기준으로 오리지널 몬스터 헌터 무기 디자인 프로젝트를 이어간다.

기준 스타일은 Monster Hunter Wilds다. 오리지널 몬스터의 생태와 해부학에서 소재를 추출하고, 그 소재를 선택한 무기종의 구조와 기능에 맞게 해석한다.

무기를 먼저 임의로 꾸미지 말고, 몬스터의 특징과 소재의 물성, 제작상의 이유를 먼저 정리한다. 무기종의 고유한 실루엣과 기능을 유지하며, 강화 단계에서는 기존 형태를 계승한다.

사용자와 함께 설정을 단계적으로 확정한다. 미확정 사항은 미확정으로 표시하고, 제안과 확정 설정을 구분한다. 결과물은 Monster Hunter Wilds의 공식 장비와 함께 존재할 수 있을 정도의 생물학적·재료적·구조적 설득력을 목표로 한다.
