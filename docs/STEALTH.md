# 더스크 스텔스 모양 만드는 법 (2026-11-08, stealth 0.3.28 기준)

리스 채팅을 다른 AI 앱처럼 보이게 하는 애드온(`addons/stealth`). 클로드 모양을 실기기(포켓리스 PC·휴대폰)에서 맞춘 결과를 기준으로, 새 모양을 만들거나 고칠 때 따를 규칙을 적는다.
로고·상표 그림은 쓰지 않는다. 글자(앱 이름), 색, 배치, 일반 아이콘(선 그림)만 쓴다.

## 1. 한 모양 = 세 조각
| 조각 | 파일 | 하는 일 |
|---|---|---|
| 프리셋 | `src/data/stealth.js` `PRESETS[id]` | 색(light/dark), 글꼴, 둥글기, 본문 폭, 기본 문구(labels), `shell`(사이드바 종류) |
| 채팅 CSS | `stealth.js` `buildStealth` | 리스 커스텀 CSS로 들어간다. 채팅 래퍼(.st-msg), 입력창, 이미지 접기, 따옴표 회색, 사이드바 CSS(`SHELL_CSS`) |
| 사이드바 | `src/data/stealth-shell.js` `SHELL_KINDS[kind]` + `shellHtml`·`topHtml` | 왼쪽 사이드바·휴대폰 상단 줄. 리스 화면 문서에 직접 그린다 |

색은 전부 CSS 변수(`--st-bg` `--st-side` `--st-bubble` `--st-fg` `--st-fg2` `--st-dim` `--st-line` `--st-line2` `--st-accent`)로 쓴다. 사이드바 CSS는 모양마다 따로 쓰지 않고 변수만 바뀐다.

## 2. 호스트 제약 (실기기에서 확인한 것 — 어기면 포켓리스에서 깨진다)
1. **리스 화면에 `<style>`을 만들어 넣으면 안 먹는 판이 있다**(포켓리스). 화면 꾸밈 CSS는 전부 리스 설정의 커스텀 CSS(`buildStealth` 결과)로 넣는다. 런타임 `<style>`은 보조일 뿐.
2. **`setInnerHTML`은 호스트 소독기(DOMPurify)를 거친다.** 판에 따라 `x-*`뿐 아니라 `class`까지 지워진다 → 사이드바가 글자만 남는다.
   - 사이드바·상단 줄·알림 줄은 `mountHtml`로 붙인다. 우리 HTML 글을 iframe의 DOMParser로 읽고, 요소를 하나씩 `createElement` + `setAttribute("x-…")` + `setInnerText`로 만든다. 이 길은 어느 판에서나 남는다(이미지 접힘 상자도 같은 길).
   - HTML을 쓸 때는 `class="…"`·`data-st-*="…"`로 쓴다. `mountHtml`이 `x-c`·`x-st-*`로 바꿔 붙인다 → **CSS 선택자는 `[x-c~="…"]`, 코드에서 찾을 때는 `[x-st-…]`**.
   - `<svg>`만 통째로 `setInnerHTML`(소독기가 남긴다). 글과 요소가 섞인 자리는 글을 `<span>`으로 감싼다.
   - 체크·값이 필요한 설정 팝업만 `setInnerHTML`을 쓴다 → 그 CSS는 class 선택자 사본도 둔다.
3. `setAttribute`는 `x-`로 시작하는 이름만 허용된다(`style`은 `setStyleAttribute`).
4. 메시지 본문 안 class는 리스가 `x-risu-` 접두사를 붙인다. 따옴표는 리스가 `<mark risu-mark="quote1|quote2">`로 감싼다(설정 '따옴표 서식 끄기'면 없음).
5. 채팅 목록: 리스는 새 채팅을 **0번(맨 앞)**에 넣는다. 날짜가 없는 판(포켓리스)도 있으니 정렬은 날짜 내림차순 → 같으면 번호 오름차순.
6. Dusk 창 열림 판단: iframe 크기 + showContainer·hideContainer 감싸기 + Dusk 본체(.rb-root) 숨김 + **리스 화면 클릭**(포켓리스는 바깥을 눌러 닫아도 아무 신호가 없다).

## 3. 사이드바 동작 규칙 (사용자 확정)
- 리스 **원래 사이드바가 닫혀 있을 때만** 그 자리에 스텔스 사이드바를 띄운다. 원래 사이드바가 열리면 스텔스 쪽이 숨는다(`nativeSidebarOpen`). 원래 사이드바를 CSS로 숨기지 않는다.
- 접기(^) 버튼은 없다. 넓은 화면(>760px)은 늘 펼침, 휴대폰은 숨김 + 상단 줄(≡·제목·⋮).
- 채팅 화면이 아니거나 Dusk 창이 열려 있으면 숨긴다.
- 최근 항목 = 지금 봇의 채팅 목록(최신 30개, 누르면 그 채팅으로). 지금 채팅은 강조.
- 머리: 앱 이름 글자 + 앱의 머리 아이콘(장식). 발: 사용자 첫 글자 동그라미 · 이름 · 요금제 글 · 설정(봇 토글 팝업).

## 4. 채팅 쪽 규칙
- 본문은 가운데 정렬, 폭 `--st-w`(프리셋 `width`). `.st-msg`의 바로 위 상자를 꽉 채운다(포켓리스는 그 상자가 글 폭으로 줄었다).
- 큰 그림(짧은 변 ≥ 220px, `FOLD_MIN`)만 '파일 N개 읽음, 명령어 N개 실행함' 줄 아래로 접는다. 아이콘·봇 위젯·캐릭터 칸은 그대로. 재기 전에는 `visibility:hidden`(자리 유지)으로만 숨긴다.
- `"…"`·`'…'`는 `--st-dim` 회색.

## 5. 새 모양 만드는 순서
1. **실물 캡처를 본다**(사용자에게 받는다): 사이드바 머리·메뉴 줄·목록 제목·발, 입력창, 말풍선, 색.
2. `PRESETS[id]`: 색 두 벌, 글꼴, `radius`·`input`·`width`, `labels`, `shell: "<kind>"`.
3. `SHELL_KINDS[kind]`: 지금 있는 칸은 `word`(앱 이름 글자), `wordSerif`, `headSeg`(클로드식 머리 묶음), `items`([아이콘, 글] — 아이콘은 `ICON`에 선 그림으로), `recent`(목록 제목), `empty`, `plan`. 앱마다 머리·새 채팅 버튼 모양이 달라 칸을 늘려야 하면(예: 이름 왼쪽 아이콘, 오른쪽 아이콘들, 알약 '새 채팅' 버튼, 첫 줄 강조 여부) 7절 정리를 보고 그때 더한다.
   - 프리셋의 `shell`은 클로드식 입력창 배치까지 뜻한다. 다른 앱에 사이드바만 붙일 때는 따로 키(예: `sidebar`)를 두고, 입력창 배치는 그 앱 모양대로 둔다.
4. 필요한 아이콘은 `ICON`에 24×24 선 그림 path로 넣는다(상표 모양 금지).
5. 시험(아래 6) → 애드온 버전 올리기(`addons/addons.src.json`) → `node tools/build-addons.mjs` → `npm test` → `npm run build` → `npm run check` → `node tools/publish-addons.mjs`.

## 6. 확인
- 단위: `tests/stealth.test.js` — 모양마다 shell 종류가 있고 `shellHtml`이 그려지는지, 소독기가 지우는 속성을 쓰지 않는지, 접기·따옴표 CSS가 있는지.
- 눈: 브라우저에서 `class`·`x-*`·`data-*`를 다 지우는 소독기 흉내로 사이드바를 그려 본다(STATE.md 0.3.23 기록 참고). 라이트·다크 둘 다.
- 실기기: 작업실 → 더스크 스텔스 → '5초 뒤 진단' → 결과 복사. 사이드바 판단 근거·배치 추적·접힘 추적이 나온다.
