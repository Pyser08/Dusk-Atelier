# Dusk Atelier v1.9.0 안내

## 기억 탭 통합

- 기억 상태, 지난 대화 분석, 기억 설정, 최근 기록을 한 화면에서 확인합니다.
- 봇별 기억 상세 화면의 기존 ‘인물 위키’ 영역에 자동 기록 관리 박스를 추가했습니다. 수동 기록, 자동 기록 스위치, 캐릭터별 사용, 위키 기록·되돌리기, 고급 자동 기록 설정을 이곳에서 관리합니다.
- ‘상황·시간선·열린 항목·관계’ 영역은 기존대로 유지하며 별도 인물/리수폿 패널을 만들지 않습니다.
- 설정 탭의 `기억·리수폿 프롬프트`와 `임베딩(의미 검색)` 설정은 기억 탭에서 접근합니다.
- 인물·리수폿의 개별 설정과 기능은 기존 저장 구조를 유지합니다. 장기기억 스위치와 리수폿 자동 기록 스위치는 서로 독립입니다.

## BardWiki 선택

RisuBard의 BardWiki가 감지되고 아직 선택하지 않았다면 기억 탭에 처음 들어갈 때 저장소 선택 안내가 표시됩니다. 선택한 값은 저장되며, 기억 탭 상단의 `기억 방식`에서 나중에 변경할 수 있습니다. 저장소를 바꾼 뒤에는 안내에 따라 RisuAI를 새로고침해야 변경된 훅이 반영됩니다.

## 화면 배치

v1.7.2에서 수정한 넓은 화면의 인물 위키 전체 편집 배치를 유지했습니다. 기존 카드, 버튼, 접이식 영역과 반응형 목록·상세 화면을 재사용합니다.


## 작업실 메뉴와 홈 화면

- ‘꾸미기’ 메뉴를 ‘플러그인 꾸미기’로, 도구의 ‘채팅 테마’를 ‘채팅 테마 빌더’로 표시합니다.
- ‘AI로 페르소나 만들기’를 작업실의 ‘AI로 봇 만들기’ 아래에 배치하고 도구 화면에서는 제거했습니다.
- 홈의 최근 기록 아래에서 공정한 전개·유저 편향 없애기·이야기 시간 자동 삽입을 조절합니다.
- 설정은 기본 화면을 먼저 보여 주고, 고급 설정 데이터를 뒤에서 병렬로 불러오도록 바꿨습니다.
